## 1. 引言

### 1.1 背景

> **v1.4.0**：侧边栏恢复可见。应收目标改为「已确认销售结算单」一对一生成；不再由过磅自动生成。已核销金额由收付款回写，详情只读；不可在本页手工新建/删除目标（取消确认在结算单）。

应收账页用于查看销售结算确认后的客户应收目标，记录关联结算单、应收金额、已核销金额与余额，支撑收付款核销与资金概览。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面入口 | 侧边栏菜单 | 可见；权限挂 `payments` |
| 页面头部 | 页面标题 | 展示「应收帐」标题 |
| 页面头部 | 来源说明 | 提示目标来自已确认结算单，核销请在收付款登记 |
| 筛选区 | 关键词筛选 | 按结算单号、客户、合同模糊匹配 |
| 筛选区 | 状态筛选 | 按核销状态筛选，支持「全部」 |
| 数据列表 | 应收列表 | 结算单号、对方、合同、目标金额、已收、余额、状态 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开只读详情 |
| 数据列表 | 行操作 | 仅「详情」 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「BX / 客户」 | 对「关联磅单 BX 单号 + 客户名」拼接字符串做不区分大小写的包含匹配 |
| 状态 | 下拉单选 | 枚举：全部、未核销、部分核销、已结清、作废；默认「全部」 | 精确匹配 `status` 字段 |

### 3.2 数据列表

以表格形式展示应收记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 关联磅单 BX | 关联的过磅单号，加粗、等宽数字展示（列表中不含 `BX` 前缀） | 否 |
| 客户 | 客户名称 | 否 |
| 往来日期 | 应收业务日期（YYYY-MM-DD） | 否 |
| 金额 Amount ($) | 应收总金额，格式如 `HK$ 74,396.8` | 否 |
| 已核销 $ | 已核销金额 | 否 |
| 余额 $ | 未结余额，加粗展示 | 否 |
| 状态 | 未核销 / 部分核销 / 已结清 / 作废，以色块标签展示 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 状态标签色块（列表）

| 状态 | 标签色调 |
| --- | --- |
| 未核销（open） | 警告色 |
| 部分核销（partial） | 信息色 |
| 已结清（settled） | 成功色 |
| 作废（void） | 危险色 |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的应收排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「应收详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含 `BX{单号}`），确认后删除；若详情弹窗正在展示同一记录则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 往来生成规则（替代手工新建）

本页**不提供**「新建」入口。应收记录由过磅台账自动生成：

| 触发 | 规则 |
| --- | --- |
| 新建正常销售磅单并保存 | 自动创建 1 笔应收：`ticketBxNo`、客户、金额、往来日期取自磅单；已核销=0；状态=未核销 |
| 一磅单一笔 | 同一 BX 号不得重复生成有效应收（已作废除外） |
| 磅单改为作废 | 关联应收标记为作废 |
| 磅单从未核销删除 | 删除关联未核销应收；已有核销金额的往来改为作废 |
| 未核销应收同步 | 编辑磅单（金额/客户/日期）时同步未核销应收 |

已核销金额与核销状态由**收付款**登记后自动回写，详情中为只读；勿在往来页手填实收实付。

### 3.4 弹窗：应收详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「详情」、新建保存后自动打开 |
| 弹窗标题 | `应收详情 · BX{关联磅单号}` |
| 弹窗尺寸 | 大号（lg） |

#### 表单字段

与新建弹窗字段一致，另增加：

| 差异点 | 说明 |
| --- | --- |
| 状态选项 | 含全部 4 种：未核销、部分核销、已结清、**作废** |
| 状态控件 | 分段按钮（4 项） |
| 余额预览 | 表单底部展示只读摘要：「余额：HK$ {实时计算值}」 |
| 客户选项 | 若原客户已不在客户列表，仍保留原选项 |
| 保存行为 | 保存后不关闭弹窗，展示绿色「已保存」 |

余额预览实时计算规则与保存时相同：`max(0, 金额 − 已核销)`。

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |
| 保存 | 提交表单 |

#### 记录不存在

当传入的应收 ID 不存在时，弹窗内容区展示「未找到记录」，底部仅保留「关闭」。

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 含 `BX{关联磅单号}` 的危险确认框 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一记录则关闭 |

> 一期需求文档约定存在收付款核销时不应随意作废往来；当前原型删除为直接从 Mock 数据移除，**未实现**核销校验与冲销联动。

---

### 3.6 跨页面入口（合同全景）

合同全景页（`/transactions`）在销售类合同的「应收款」Tab 中可：

- 查看该合同下关联的应收列表（子表格）
- 点击行内「编辑」打开 `ReceivableDetailModal`
- **无**往来新建入口；需先在过磅 Tab 新建正常销售磅单，系统自动生成应收

该入口与本页共用同一套详情弹窗与数据模型。

## 5. 数据模型（页面涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 系统内部主键 |
| ticketBxNo | string | 关联磅单 BX 单号 |
| customerName | string | 客户名称 |
| amount | number | 应收总金额（HKD） |
| settledAmount | number | 已核销金额（HKD） |
| balance | number | 余额（HKD） |
| status | `open` \| `partial` \| `settled` \| `void` | 核销状态 |
| date | string | 往来业务日期（YYYY-MM-DD） |
| createdAt | string | 创建时间（ISO 8601） |
| updatedAt | string | 更新时间（ISO 8601） |

### 状态枚举与展示

| 值 | 展示文案 |
| --- | --- |
| open | 未核销 |
| partial | 部分核销 |
| settled | 已结清 |
| void | 作废 |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 销售磅单自动生成应收（R06）
- 一磅单对应一笔往来
- 收付款可核销多笔往来
- 未核销作废时应自动关闭往来（R08）

**当前原型实现：**

- 销售磅单保存后**自动生成**应收（一对一）
- 磅单作废/删除时联动作废或删除未核销往来
- 本页**无手工新建**；详情中关联磅单/客户/金额为只读
- 新建/编辑时**仍可手填**已核销金额与状态，未与收付款模块自动联动
- **未实现**核销记录校验、作废阻断、冲销流程
- **未实现**状态与金额/已核销的自动一致性校验（如已结清但余额不为 0）

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无应收 | 表格空态 | 可调整筛选；或先去过磅台账新建销售磅单 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 有核销仍删除 | 存在收付款核销 | 未在页面或资料中体现 | 当前允许直接删除 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏**不展示**「应收账」（菜单已隐藏）；直链 `/receivables` 仍可打开 |
| 无新建入口 | 页面无「新建」按钮 |
| 自动生成 | 新建正常销售磅单后，应收列表出现对应 BX 记录 |
| 列表展示 | 正确展示关联磅单、客户、往来日期、金额、已核销、余额、状态、创建/更新时间 |
| 列表排序 | 默认按创建时间倒序 |
| 关键词筛选 | 可按 BX 单号/客户名片段过滤 |
| 状态筛选 | 四种状态筛选准确 |
| 分页 | 超过 10 条时分页正常 |
| 详情只读字段 | 关联磅单、客户、金额不可改 |
| 详情可编辑 | 可改往来日期；已核销/状态只读（由收付款回写） |
| 余额预览 | 详情编辑时底部余额随已核销实时变化 |
| 磅单作废联动 | 作废销售磅单后，关联应收状态为作废 |
| 删除确认 | 删除前确认，确认后记录消失 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 侧边栏菜单隐藏；路由与数据模型保留
- 应收列表、即时筛选、创建时间倒序、分页
- 销售磅单保存后自动生成应收（一对一）
- 磅单作废/删除联动往来
- 弹窗式详情编辑（磅单/客户/金额只读）
- 收付款核销自动回写已核销/余额/状态；往来详情只读展示
- 单条删除与二次确认
- 合同全景页只读浏览 + 详情编辑（无新建往来入口）

### 8.2 本期不包含（页面或资料未体现）

- 本页手工新建应收
- 删除/作废前校验收付款核销记录（正式应先冲销）
- 状态与金额一致性自动校验
- 导出、批量操作、列头排序
- 后端 API、权限按钮级控制
- 客户维度应收汇总报表
