## 1. 引言

### 1.1 背景

当前登录用户可通过侧边栏头像菜单打开「修改密码」弹窗，维护本账号登录密码。一期演示环境以本地会话与浏览器本地存储模拟鉴权。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 入口 | 用户菜单 | 头像菜单点击「修改密码」打开弹窗（不跳转独立页） |
| 表单 | 当前密码 | 校验与账号已保存密码一致 |
| 表单 | 新密码 | 按密码规则校验（见 3.2） |
| 表单 | 确认新密码 | 须与新密码完全一致 |
| 操作区 | 更新密码 | 校验通过后保存新密码并清空表单 |
| 操作区 | 取消 / 关闭 | 关闭弹窗 |
| 登录联动 | 后续登录 | 改密成功后，该账号须使用新密码登录 |

## 3. 模块需求说明

### 3.1 弹窗结构

| 属性 | 说明 |
| --- | --- |
| 标题 | 修改密码 |
| 布局 | 居中弹窗 + 底部「取消 / 更新密码」 |
| 辅助说明 | 顶部展示密码规则提示文案 |

### 3.2 密码规则（核心）

| 规则项 | 要求 |
| --- | --- |
| 长度 | **6～20 位**（含边界） |
| 允许字符 | 数字、字母、符号（ASCII 可打印，不含空格） |
| 组合要求 | **不强制组合** |
| 禁止字符 | 空格、换行、制表等空白字符 |
| 新旧关系 | **允许新旧密码相同** |
| 确认一致性 | 新密码 = 确认新密码 |

### 3.3 表单字段

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 当前密码 | 密码输入 | 是 | 须与账号已保存密码一致 |
| 新密码 | 密码输入 | 是 | 见 3.2；`minLength=6`、`maxLength=20` |
| 确认新密码 | 密码输入 | 是 | 与新密码一致 |

### 3.4 校验与反馈

| 顺序 | 场景 | 提示文案（简体） |
| --- | --- | --- |
| 1 | 未登录 | 未登录 |
| 2 | 当前密码为空 | 请输入当前密码 |
| 3 | 当前密码不正确 | 当前密码不正确 |
| 4 | 新密码为空 | 请输入新密码 |
| 5 | 长度不合法 | 密码须为 6～20 位 |
| 6 | 字符不合法 | 密码仅支持数字、字母和符号，且不能包含空格 |
| 7 | 确认不一致 | 两次输入的新密码不一致 |
| — | 成功 | 密码已更新；清空三字段；不强制登出 |

### 3.5 登录联动（演示）

| 规则 | 说明 |
| --- | --- |
| 首次登录 | 该邮箱尚无本地密码时，任意非空密码可登录，并写入本地 |
| 已改密 / 已登录过 | 须与本地已保存密码一致 |
| 默认预填 | 登录页预填 `demo1234` |
| 改密后 | 旧密码无法登录；当前会话可不踢下线 |

## 4. 交互设计

- 弹窗打开时重置表单与提示
- Esc / 遮罩 / 取消关闭弹窗
- 成功后提示保留至下次提交或关闭；输入框清空
- 不提供「显示密码」切换（本期不做）
