## 1. 引言

### 1.1 背景

登录页为系统唯一对外鉴权入口，员工使用公司账号进入业务系统；本页不展示注册，账号由管理员在员工管理中维护。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 品牌展示区 | 产品标识 | 展示品牌角标文案、系统名称、产品标语 |
| 品牌展示区 | 公司信息 | 展示当前租户中英文公司名称（大屏在左侧底部，小屏在登录卡下方） |
| 登录表单 | 电邮输入 | 必填；邮箱格式；占位符引导 |
| 登录表单 | 密码输入 | 必填；默认密文；支持明文/密文切换 |
| 登录表单 | 提交登录 | 校验通过后建立会话并进入首页总览 |
| 登录表单 | 错误提示 | 在表单内展示失败原因；输入变更时清除旧错误 |
| 会话与拦截 | 已登录跳转 | 已有有效会话访问登录页时直接进入首页 |
| 会话与拦截 | 未登录拦截 | 访问业务壳内页面且无会话时跳转登录页 |
| 会话与拦截 | 会话失效踢出 | 账号停用或所属角色全部停用时清除会话 |

> 功能清单不包含：全局顶栏/侧栏样式（登录页无侧栏）。

## 2. 页面入口与权限规划

### 2.1 页面入口

**入口路径**：直接访问 `/login`；或未登录访问业务页被重定向至 `/login`

**路由地址**：`/login`

**登录成功默认落地**：`/dashboard`（首页总览）

> `/register` 本期不开放，访问时重定向至 `/login`。

### 2.2 权限规划

| 权限点 | 操作范围 | 数据范围 |
| --- | --- | --- |
| 匿名访问 | 打开登录页、提交登录表单 | 公开页面；不暴露其他租户/员工明细 |
| 登录成功 | 进入业务系统（后续菜单/按钮由角色权限控制） | 当前租户内、当前账号授权范围 |

> 本页不定义具体角色矩阵；角色权限在「角色权限 / 员工管理」中配置。登录成功仅表示通过身份校验。

## 3. 模块需求说明

### 3.1 首屏 / 品牌展示区

| 内容项 | 展示类型 | 展示规则 | 数据来源 | 操作 |
| :--- | :--- | :--- | :--- | :--- |
| 全幅背景图 | 图片 | 码头/回收站氛围全幅铺满；上覆暗色渐变以保证文字可读 | 静态资源 | 无 |
| 品牌角标 | 文本 | 展示 `METAL RECYCLE` | 文案配置 | 无 |
| 系统名称 | 标题 | 两行展示「金属回收 / 管理系统」（随语言切换） | i18n | 无 |
| 产品标语 | 文本 | 展示合同约束单价、过磅台账、往来与首页一体化等产品价值句 | i18n | 无 |
| 公司中文名 | 文本 | 当前租户公司中文名 | 租户资料 | 无 |
| 公司英文名 | 文本 | 当前租户公司英文名；大屏与中文名一并展示 | 租户资料 | 无 |

- **主操作按钮**：无（主 CTA 在登录卡内）
- **布局**：桌面端左右分栏（左品牌、右登录卡）；移动端上下堆叠，公司名可出现在登录卡下方

### 3.2 登录表单区

| 字段 | 控件 | 必填 | 默认值 | 校验 / 限制 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 电邮 | 文本输入（email） | 是 | 空 | 非空；符合邮箱格式；提交前 trim | 占位符：`name@company.com`；不预填演示账号 |
| 密码 | 密码输入 | 是 | 空 | 非空 | 默认密文；右侧眼睛图标切换明文/密文 |
| — | 登录按钮 | — | — | 表单校验通过后方可成功提交 | 主按钮文案：「登录 / 登入」 |

| 子模块 | 触发方式 | 字段/内容 | 校验/限制 | 操作按钮 | 关闭/完成规则 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 密码显隐 | 点击眼睛图标 | 密码框 type 在 `password` / `text` 间切换 | 不影响已输入内容 | 图标按钮（无独立文案，需无障碍标签） | 再次点击切回 |
| 错误提示 | 登录失败 | 行内错误文案 | 见 §3.4 | — | 用户修改电邮或密码时清除 |

### 3.3 用户操作流程

| 步骤 | 用户动作 | 系统响应 | 前置条件 | 后置结果 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 打开 `/login` | 渲染品牌区 + 登录卡；若会话已有效则跳转首页 | 无 | 可见登录页或已进入系统 |
| 2 | 输入电邮、密码 | 输入变更清除旧错误 | 无 | 表单值更新 |
| 3 | （可选）切换密码显隐 | 密文/明文切换 | 无 | 仅展示方式变化 |
| 4 | 点击「登录」 | 执行登录判定（§3.4） | 浏览器必填校验通过 | 成功进首页，或行内错误 |
| 5 | 登录成功 | 写入会话；跳转 `/dashboard` | 判定通过 | 可访问业务页 |
| 6 | 未登录访问业务页 | 重定向 `/login` | 无有效会话 | 停留在登录页 |

### 3.4 登录判定规则（正式口径）

> 以下为产品正式规则。部分校验应落在**前端**（体验与即时反馈），账号真实性、密码哈希比对、账号/角色状态等以**后端**为准；前端校验不可作为唯一安全关卡。

#### 3.4.1 判定总览

```text
提交登录
  → 电邮为空？ → 失败「请输入电邮」
  → 密码为空？ → 失败「请输入密码」
  → 电邮格式非法？ → 失败（前端拦截；文案可用浏览器默认或统一「电邮格式不正确」）
  → 账号不存在（非本租户员工）？ → 失败「电邮或密码不正确」（不暴露账号是否存在）
  → 账号已停用？ → 失败「该账号已停用，无法登录」
  → 账号无任一启用中的角色？ → 失败「所属角色已停用，无法登录」
  → 密码不正确？ → 失败「电邮或密码不正确」
  → 通过 → 建立会话 → 进入首页总览
```

#### 3.4.2 账号与密码业务规则（已确认）

| 编号 | 规则 | 说明 |
| --- | --- | --- |
| L01 | 仅已存在员工可登录 | 电邮必须匹配本租户员工主数据；未知电邮一律失败 |
| L02 | 电邮匹配忽略大小写 | 比对前 trim + 小写归一 |
| L03 | 初始密码 = 登录账号（电邮） | 与「新建员工」初始密码规则一致；管理员重置密码亦重置为电邮 |
| L04 | 修改密码后以新密码为准 | 用户在「修改密码」成功后，登录须使用新密码 |
| L05 | 不做失败次数锁定 | 连续错误不锁定账号；可后续迭代再加 |
| L06 | 会话保持现状 | 会话持久化于浏览器本地；关闭标签页后仍保持，直至主动退出，或因 L07 被踢出 |
| L07 | 运行中失效踢出 | 已登录期间若账号被停用，或所属角色全部停用，清除会话并回到登录页 |
| L08 | 错误文案防枚举 | 「账号不存在」与「密码错误」对外统一为「电邮或密码不正确」；停用类可单独提示 |

#### 3.4.3 前端 / 后端校验分工

| 校验项 | 前端 | 后端（正式） | 说明 |
| --- | --- | --- | --- |
| 电邮、密码非空 | ● | ● | 前端即时提示；后端仍须拒绝空值 |
| 电邮格式 | ● | ● | 前端 `type=email` / 格式校验；后端再验 |
| 账号是否存在 | ○（可做体验提示，不可仅靠前端） | ● | **必须以服务端员工库为准** |
| 账号停用 | ○ | ● | 服务端权威；前端可展示返回码文案 |
| 角色全部停用 | ○ | ● | 同上 |
| 密码正确性 | ○ | ● | 服务端比对（哈希）；禁止明文落库为正式方案 |
| 会话签发 / 失效 | ○（本地演示可模拟） | ● | 正式用服务端会话或 Token |
| 密码显隐切换 | ● | — | 纯 UI |
| 失败锁定 | — | — | 本期不做 |

> ● 必须　○ 可选辅助　— 不适用

#### 3.4.4 与当前前端实现的差异说明

| 项 | 正式口径（本 PRD） | 当前 Mock 实现 | 处理建议 |
| --- | --- | --- | --- |
| 未知电邮 | 拒绝登录 | 可能放行并建立临时会话 | 接 API 后按 L01 收敛；Mock 阶段可逐步收紧 |
| 初始密码 | 必须等于电邮（首次） | 未落库密码时可能接受任意密码并写回 | 接 API / 收紧 Mock：无存档时按电邮校验 |
| 密码存储 | 服务端哈希 | 浏览器 localStorage | 仅演示；正式禁止 |

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：鉴权未就绪，或已登录待跳转时，全屏展示「载入中…」类文案，避免闪现表单。
- **空状态**：不适用（登录页非列表）。
- **响应式**：桌面左右分栏；小屏品牌在上、表单在下；登录卡右侧需保留足够边距，避免贴边。
- **动效**：品牌区与登录卡可有入场过渡；须尊重 `prefers-reduced-motion`（降级为无动画或立即展示）。
- **输入框外观**：默认白底；覆盖浏览器自动填充带来的浅蓝底，保持白底可读。

### 4.2 特殊交互

- **已登录访问登录页**：检测有效会话后 `replace` 跳转 `/dashboard`，不展示登录表单。
- **登录成功跳转**：`push` 至 `/dashboard`。
- **未登录访问业务壳**：`AppShell` 拦截并 `replace` 至 `/login`。
- **无注册入口**：页面不展示注册链接；`/register` 重定向登录。

## 5. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| :--- | :--- | :--- | :--- |
| 加载中 | 会话恢复中 / 已登录待跳转 | 全屏加载文案 | 完成后展示表单或进入首页 |
| 电邮为空 | 提交时电邮为空 | 「请输入电邮」 | 停留本页，保留已填密码 |
| 密码为空 | 提交时密码为空 | 「请输入密码」 | 停留本页，保留已填电邮 |
| 电邮或密码不正确 | 账号不存在或密码错误 | 「电邮或密码不正确」 | 不清空电邮；密码是否清空未在页面强制规定，建议保留电邮、可选清空密码 |
| 账号停用 | 员工状态为停用 | 「该账号已停用，无法登录」 | 不建立会话 |
| 角色停用 | 无任一启用角色 | 「所属角色已停用，无法登录」 | 不建立会话 |
| 登录失败（兜底） | 其他失败 | 「登录失败」或服务端返回文案 | 停留本页 |
| 会话运行中失效 | 账号/角色被停用 | 退出至登录页 | 清除本地会话 |
| 网络异常 | 后端不可用（正式） | 未在当前 Mock 页面单独体现 | 正式应提示网络/服务异常且保留输入 |
| 重复提交 | 连续点击登录 | 未在页面或资料中体现防抖 | 建议提交中禁用按钮（正式增强） |

## 6. 验收标准

| 验收点 | 验收标准 |
| :--- | :--- |
| 首屏结构 | 可见品牌文案、系统名、标语、公司名与登录卡；无注册入口 |
| 必填校验 | 空电邮 / 空密码无法成功登录，并有对应提示 |
| 未知账号 | 正式口径下未知电邮登录失败，提示「电邮或密码不正确」 |
| 初始密码 | 新建员工首次可用「电邮=密码」登录成功 |
| 改密后登录 | 修改密码后须用新密码；旧密码失败 |
| 停用账号 | 停用员工无法登录；已登录被停用则踢出 |
| 角色停用 | 所属角色均停用时无法登录 / 被踢出 |
| 密码显隐 | 眼睛图标可切换密文与明文，内容不丢失 |
| 会话保持 | 刷新页面后仍保持登录（未退出且账号仍有效） |
| 已登录重入 | 已登录访问 `/login` 进入首页，不停留表单 |
| 未登录拦截 | 未登录访问业务页回到 `/login` |
| 无锁定 | 连续多次密码错误仍可继续尝试（本期） |
| 无障碍 | 密码显隐按钮具备可读的 aria 标签 |
| 响应式 | 小屏与桌面布局可用，登录卡不严重贴边 |

## 7. 范围边界

- **本期包含**：
  - 登录页 UI（品牌 + 公司信息 + 表单 + 密码显隐）
  - 正式登录判定口径 L01–L08 及前后端校验分工
  - 会话保持、已登录跳转、未登录拦截、停用踢出
  - 无注册入口；`/register` 重定向登录
- **本期不包含**：
  - 自助注册开户（产品一期总纲另有规划，本页暂不开放）
  - 忘记密码 / 邮箱验证码找回
  - 验证码、二次验证、SSO、扫码登录
  - 失败次数锁定、IP 限制
  - 会话绝对过期 / 滑动过期策略（保持「关闭浏览器仍登录」的现状）
  - 记住我勾选框、多因素认证
  - 跨租户统一登录门户（老板跨公司总览）
