## 1. 引言

### 1.1 背景

收付款页用于登记客户/供应商的**实际收款与付款**，支持两类业务：

- **往来核销**：选择已确认结算单对应的应收/应付目标登记收付；对方、合同由目标带出；展示目标金额 / 已收(付) / 余额；一笔只核一张结算单；可多次部分、禁止超额
- **杂项收支**：不关联往来，登记薪金、运费、水电燃油等现金流水

往来目标由结算单「确认结算」生成（销售→应收，采购→应付）；磅单不再自动产生往来。侧边栏「应收账」「应付账」展示目标台账。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「收付款」标题 |
| 页面头部 | 新建 | 单一「登记收付」入口 |
| 摘要区 | 收支摘要 | 默认展开；可收起/展开并用 `localStorage` 记住；展开时 4 张 StatCard（核销收/付、杂项收/支） |
| 筛选区 | 关键词 / 类别 / 类型 | 即时筛选；上方摘要随筛选结果重算 |
| 数据列表 | 收付列表 | 含类别、杂项类别、关联结算单等列 |
| 数据列表 | 行点击 / 操作 | 详情、删除（受权限控制） |
| 新建弹窗 | 类别 | 往来核销 / 杂项收支（分段选择） |
| 新建弹窗 | 往来核销字段 | 选择结算目标 → 带出对方/合同/余额；收付类型按目标锁定；金额/方式/时间 |
| 新建弹窗 | 杂项字段 | 分区「基本信息」+「补充信息」；说明为多行文本 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「对方 / 摘要」 | 对「对方 counterparty + 核销摘要 allocationSummary + 方式 method + 杂项类别 miscKind + 关联磅单 BX」拼接字符串做不区分大小写的包含匹配 |
| 类别 | 下拉单选 | 枚举：全部、往来核销、杂项收支；默认「全部」 | 精确匹配 `category` 字段（`settlement` / `misc`） |
| 类型 | 下拉单选 | 枚举：全部、收款、付款；默认「全部」 | 精确匹配 `type` 字段（`receipt` / `payment`） |

### 3.2 数据列表

以表格形式展示收付款记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 收付时间 | 收付款业务时间（YYYY-MM-DD HH:mm，精确到分钟） | 否 |
| 类别 | 往来核销 / 杂项收支，以色块标签展示 | 否 |
| 类型 | 收款 / 付款，以色块标签展示（收款成功色、付款警告色） | 否 |
| 杂项类别 | 仅杂项有值，否则「—」 | 否 |
| 关联合同 | 仅往来核销且填写了合同时有值，否则「—」 | 否 |
| 关联磅单 BX | 仅往来核销且填写了磅单时有值（`BX{单号}`），否则「—」 | 否 |
| 方式 | 现金 / 支票 / 转账（根据存储值本地化展示） | 否 |
| 金额 Amount ($) | 收付金额，加粗、等宽数字，格式如 `HK$ 66,224` | 否 |
| 对方 | 客户或供应商名称 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 3.2.1 核销摘要展示规则

核销摘要（`allocationSummary`）不在列表列中展示，但在详情弹窗与关键词筛选中可用。加载时对种子数据中繁体中文格式的摘要做本地化展示：

| 原始格式 | 展示转换 |
| --- | --- |
| `核銷 BX02513` / `核销 BX02513` | `核销 BX02513`（使用当前语言包的「核销」前缀） |
| `部分核銷 BX02474` / `部分核销 BX02474` | `部分核销 BX02474` |
| `合同 {合同编号}` | 原样展示 |
| 其他文本 | 原样展示 |
| 存储值为 `-` | 详情编辑框展示为空；列表关键词匹配时仍含 `-` |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新登记的收付排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「收付详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含「收款/付款 + 金额」），确认后删除；若详情弹窗正在展示同一记录则关闭详情；无删除权限时不展示 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「登记收付」按钮；亦可由合同全景页带预设参数打开（见 3.6） |
| 弹窗标题 | 登记收付 |
| 弹窗尺寸 | 大号（lg） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单分区

| 类别 | 分区结构 | 说明 |
| --- | --- | --- |
| 往来核销 | 单分区（无分区标题） | 类别、类型及业务字段在同一网格内连续排列 |
| 杂项收支 | **基本信息** + **补充信息** | 基本信息含类别、类型及杂项业务字段；补充信息仅含「说明」多行文本，全宽展示 |

#### 表单公共字段（首行）

两类类别共用，位于表单顶部：

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 类别 | 分段按钮 | 是 | 默认「往来核销」 | 往来核销 / 杂项收支；切换时清空业务字段 |
| 类型 | 分段按钮 | 否 | 默认「收款」；可由预设带入 | 枚举：收款（receipt）、付款（payment）；杂项切换类别时按杂项类别自动推断收/付 |

#### 往来核销字段

字段顺序与布局规律：**方式 → 金额 → 收付时间 → 对方 → 关联合同 → 关联磅单**。

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 枚举：现金、支票、转账（内部存值为 `現金`/`支票`/`轉賬`） |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 步进 `0.01` | 选磅单时默认带出待核销余额，可改 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻（精确到分钟） | 格式 YYYY-MM-DDTHH:mm，展示为 YYYY-MM-DD HH:mm |
| 对方 | 可搜索下拉 | 是 | 选项来自「客户管理」 | 选合同或磅单后自动带出并禁用编辑；可手动选择（未关联时） |
| 关联合同 | 可搜索下拉 | 否 | 可清空 | 收款列销售合同，付款列采购合同；选项格式 `{编号} · {对方名称}` |
| 关联磅单 BX | 可搜索下拉 | 否 | 可清空 | 见 **3.3.1 合同与磅单联动规则** |

选中磅单后，表单下方展示余额提示：「待核销余额 / 往来总额」。

#### 杂项收支字段

杂项收支分为两个分区，基本信息区字段顺序与往来核销保持同一规律：**方式 → 金额 → 收付时间 → 对方/用途 → 杂项类别**（类别、类型位于首行，同属基本信息区）。

**分区一：基本信息**

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 类别 | 分段按钮 | 是 | — | 与公共字段一致，位于基本信息区首行 |
| 类型 | 分段按钮 | 否 | — | 与公共字段一致，位于基本信息区首行 |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 同往来核销 |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 步进 `0.01` | 收付金额 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻（精确到分钟） | 同往来核销 |
| 对方/用途 | 文本输入 | 是 | 手填 | 占位符示例：「迅昇石油氣、员工姓名」 |
| 杂项类别 | 下拉 | 是 | 默认「其他开支」 | 见 **3.3.2 杂项类别枚举** |

**分区二：补充信息**

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 说明 | 多行文本（textarea） | 否 | 全宽展示，最小高度约 4.5rem，可纵向拖拽调整；存入 `allocationSummary`；占位符示例：「买石油气、仓间调拨」 |

#### 3.3.1 合同与磅单联动规则

| 场景 | 行为 |
| --- | --- |
| 未选合同 | 磅单下拉显示**全部**待核销应收/应付（含不关联合同的磅单） |
| 已选合同 | 磅单下拉**仅显示**该合同下、状态为 open/partial 的待核销磅单 |
| 切换合同 | 若当前已选磅单不属于新合同，**自动清空**磅单与金额 |
| 选磅单（未选合同） | 若磅单有关联合同，**自动填入**关联合同 |
| 提交校验 | 往来核销时**关联合同与关联磅单至少填一项**；两者都填时磅单必须属于该合同，否则阻止提交 |
| 仅选合同（预付款） | 允许保存；摘要生成为 `合同 {编号}`；**不回写**应收/应付余额 |
| 选磅单核销 | 摘要按金额生成 `核销 BX{no}` 或 `部分核销 BX{no}`；保存后回写对应往来 `settledAmount` / `balance` / `status` |

磅单字段提示文案：「可选；未选合同时可选任意待核销磅单；已选合同时仅显示该合同下磅单」。

#### 3.3.2 杂项类别枚举

| 存储值 | 展示文案（简体） | 默认收付类型 |
| --- | --- | --- |
| salary | 薪金 | 付款 |
| freight | 运费 | 付款 |
| petty_cash | PETTY CASH | 付款 |
| utilities | 水电燃油 | 付款 |
| other_expense | 其他开支 | 付款 |
| other_income | 其他收入 | 收款 |
| deposit | 账户存入/调拨 | 收款 |
| other | 其他 | 付款 |

切换杂项类别时，若当前为杂项收支，自动将「类型」调整为上表默认收付类型。

#### 保存规则

- 往来核销：`allocationSummary` 按 3.3.1 规则自动生成；无摘要时存 `-`
- 杂项收支：`allocationSummary` 取「说明」字段，留空存 `-`
- 杂项记录不写入 `contractNo`、`ticketBxNo`
- 保存成功后关闭弹窗，并自动打开该收付详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 危险确认框，文案中的标签为「收款 {金额}」或「付款 {金额}」 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一记录则关闭；若删除的是带磅单核销的往来收付，按 BX 重算应收/应付 |

> 一期需求文档约定一笔收付可核销多笔往来、冲销时按分配解除；当前原型删除为直接从 Mock 数据移除，**未实现**核销冲销与部分解除分配。

### 3.6 跨页面入口（合同全景）

合同全景页（`/transactions`）在「收付款记录」Tab 中可：

- 查看与该合同关联的收付款子列表（按 `contractNo` 或关联磅单匹配）
- 点击「新建」打开 `PaymentCreateModal`，预设：
  - `contractNo`：当前合同编号
  - `counterparty`：合同对方客户名
  - `type`：销售合同默认 `receipt`（收款），采购合同默认 `payment`（付款）
  - `ticketBxNo`：首张正常磅单 BX 号（若有）
- 列表列与收付款页一致（不含审计列）
- 点击行内「编辑」打开 `PaymentDetailModal`

## 4. 交互设计

### 4.2 特殊交互

| 交互名称 | 说明 |

| 列表默认排序 | 按创建时间倒序 |

| 字段名 | 类型 | 说明 |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 采购 → 应付、销售 → 应收（R06）
- 一笔收/付款可核销多笔往来
- 核销冲销只解除与本往来相关的分配
- 首页展示已收款、已付款、现金结余

**当前原型差异（须在验收时知晓）：**

- **已实现**往来核销：选择磅单 BX 后保存回写 `settledAmount` / `balance` / `status`
- **已实现**仅关联合同（预付款）：可登记，摘要为 `合同 {no}`，不回写往来
- **已实现**删除/修改带磅单核销的收付款后按 BX 重算往来
- **已实现**关联合同字段与合同-磅单联动筛选
- 一笔收付当前原型核销**一笔**往来（多笔往来分配仍简化）
- 杂项收支不关联往来、不回写应收应付
- **未实现**冲销流程与作废阻断
- 首页资金指标来自独立 Mock 统计，**未与本页保存实时联动**

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无记录 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 金额/时间/对方未填，或往来核销时合同与磅单均未填 | 浏览器原生校验或静默阻止提交 | 阻止提交 |
| 合同磅单不匹配 | 同时填写了合同与不属于该合同的磅单 | 切换合同时自动清空磅单；提交时阻止 | 见 3.3.1 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无删除权限 | 行操作不展示删除 | 演示环境已实现删除权限 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 单一新建入口；表单内选择类别（往来核销 / 杂项）
- 往来核销支持关联合同、关联磅单及其联动规则
- 仅合同登记（预付款）与仅磅单核销（无合同磅单）
- 列表展示类别、杂项类别、关联合同、关联磅单列
- 收付款列表、类别/类型/关键词筛选、创建时间倒序、分页
- 弹窗式登记 / 详情编辑
- 收款与付款两种类型；现金 / 支票 / 转账三种方式
- 杂项收支八类杂项类别；表单分「基本信息」「补充信息」两分区，说明为多行文本
- 单条删除与二次确认（含权限控制）
- 合同全景页复用同一套收付弹窗

### 8.2 本期不包含（页面或资料未体现）

- 一笔收付核销多笔往来的明细管理
- 冲销、作废、审批流
- 收付凭证附件上传
- 导出、批量操作、列头排序
- 后端 API
- 与首页资金 KPI 的实时联动计算
