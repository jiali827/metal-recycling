## 1. 引言

### 1.1 背景

收付款页用于登记客户/供应商的**实际收款与付款**，支持两类业务：

- **往来核销**：选择已确认结算单对应的应收/应付目标登记收付；对方、合同由目标带出；展示目标金额 / 已收(付) / 余额；一笔只核一张结算单；可多次部分、禁止超额
- **杂项收支**：不关联往来，登记运费、水电燃油等现金流水
- **员工薪资**：选择在职员工登记薪资付款；自动带出员工月薪；类型固定为付款

往来目标由结算单「确认结算」生成（销售→应收，采购→应付）；磅单不再自动产生往来。侧边栏「应收账」「应付账」展示目标台账。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「对方 / 摘要」 | 对「对方 counterparty + 核销摘要 allocationSummary + 方式 method + 杂项类别 miscKind + 关联结算单号 settlementDocNo + 关联合同 contractNo」拼接字符串做不区分大小写的包含匹配 |
| 类别 | 下拉单选 | 枚举：全部、往来核销、杂项收支、员工薪资；默认「全部」 | 精确匹配 `category` 字段（`settlement` / `misc` / `salary`） |
| 类型 | 下拉单选 | 枚举：全部、收款、付款；默认「全部」 | 精确匹配 `type` 字段（`receipt` / `payment`） |

### 3.2 数据列表

以表格形式展示收付款记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 收付时间 | 收付款业务时间（YYYY-MM-DD HH:mm，精确到分钟） | 否 |
| 类别 | 往来核销 / 杂项收支 / 员工薪资，以色块标签展示 | 否 |
| 类型 | 收款 / 付款，以色块标签展示（收款成功色、付款警告色） | 否 |
| 杂项类别 | 杂项收支展示杂项类别；员工薪资展示「员工薪资」；往来核销为「—」 | 否 |
| 关联合同 | 仅往来核销且结算目标带合同时有值，否则「—」 | 否 |
| 关联结算单 | 仅往来核销且有结算单号时有值，否则「—」 | 否 |
| 方式 | 现金 / 支票 / 转账（根据存储值本地化展示） | 否 |
| 金额 Amount ($) | 收付金额，加粗、等宽数字，格式如 `HK$ 66,224` | 否 |
| 对方 | 客户或供应商名称 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 3.2.1 核销摘要展示规则

核销摘要（`allocationSummary`）不在列表列中展示，但在详情弹窗与关键词筛选中可用。加载时对种子数据中繁体中文格式的摘要做本地化展示：

| 原始格式 | 展示转换 |
| --- | --- |
| `核销 {结算单号}` / `部分核销 {结算单号}` | 原样展示（当前主流程） |
| `核銷 BX02513` / `核销 BX02513` | `核销 BX02513`（历史/兼容格式） |
| `部分核銷 BX02474` / `部分核销 BX02474` | `部分核销 BX02474`（历史/兼容格式） |
| `合同 {合同编号}` | 原样展示（历史格式） |
| 其他文本 | 原样展示 |
| 存储值为 `-` | 详情编辑框展示为空；列表关键词匹配时仍含 `-` |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新登记的收付排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「收付详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含「收款/付款 + 金额」），确认后删除；若详情弹窗正在展示同一记录则关闭详情；无删除权限时不展示 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：登记收付（新建）

页头「登记收付」为**下拉菜单**，三类入口各自打开**独立弹窗**（标题不同，表单字段不共用「类别」切换）：

| 菜单项 | 弹窗标题 | 内部 `createKind` |
| --- | --- | --- |
| 往来核销 | 登记核销 | `settlement` |
| 杂项收支 | 登记杂项 | `misc` |
| 员工薪资 | 登记薪资 | `salary` |

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页头下拉三项；亦可由合同全景等带 `preset` 打开（见 3.6） |
| 弹窗尺寸 | 大号（lg） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭并打开详情 |

#### 3.3.1 往来核销（登记核销）

单分区（无分区标题），字段顺序：**类型 → 关联结算单 → 方式 → 金额 → 收付时间**。

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 类型 | 分段按钮 | 是 | 默认「收款」 | 收款（receipt）/ 付款（payment）；**须先选类型**，再筛选可选结算目标 |
| 关联结算单 | 可搜索下拉 | 是 | 空 | 选项仅含与当前类型匹配的待核销应收/应付（`open` / `partial`）；格式 `{结算单号} · {客户} · {余额}` |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 枚举：现金、支票、转账 |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 步进 `0.01`；上限为所选目标余额 | 选结算单后默认带出待核销余额，可改但不可超额 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻（精确到分钟） | 格式 YYYY-MM-DDTHH:mm |

选中结算单后，表单下方展示提示：客户名、关联合同（若有）、待核销余额 / 目标总额。

**类型与结算单联动：**

| 场景 | 行为 |
| --- | --- |
| 切换收/付类型 | **清空**已选结算单、金额；结算单下拉按新类型重算选项 |
| 选择结算单 | 自动带出对方（客户名）与默认金额（余额） |
| 清空结算单 | 清空金额 |
| 提交校验 | 须选择结算单；金额须 `> 0` 且 `≤` 目标余额 |

保存时 `allocationSummary` 按金额生成 `核销 {结算单号}` 或 `部分核销 {结算单号}`；同步回写对应应收/应付的 `settledAmount` / `balance` / `status`。

#### 3.3.2 杂项收支（登记杂项）

分为 **基本信息** + **补充信息** 两分区。

**分区一：基本信息**（字段顺序：**类型 → 方式 → 金额 → 收付时间 → 对方/用途 → 杂项类别**）

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 类型 | 分段按钮 | 否 | 默认「付款」 | 收款/付款；切换杂项类别时按默认收付类型自动推断 |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 同往来核销 |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 步进 `0.01` | 收付金额 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻 | 同往来核销 |
| 对方/用途 | 文本输入 | 是 | 手填 | 占位符示例：「迅昇石油氣、员工姓名」 |
| 杂项类别 | 下拉 | 是 | 默认第一个**启用**类别 | 选项来自「杂项类别」主数据（`/misc-categories`）；切换时按类别默认收/付类型推断 |

**分区二：补充信息**

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 说明 | 多行文本 | 否 | 存入 `allocationSummary`；留空存 `-` |

#### 3.3.3 员工薪资（登记薪资）

分为 **基本信息** + **补充信息** 两分区。

**分区一：基本信息**（字段顺序：**员工 → 类型 → 方式 → 金额 → 收付时间**）

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 员工 | 可搜索下拉 | 是 | 空 | 标签为「**员工**」（非侧边栏菜单名「员工管理」）；仅展示**在职**员工；选项格式 `{姓名} · HK$ {月薪}`（无月薪则仅姓名） |
| 类型 | 只读展示 | — | 固定「付款」 | 薪资登记不可改为收款 |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 同往来核销 |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 步进 `0.01` | 选择员工后自动带出 `monthlySalary`；可手动调整 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻 | 同往来核销 |

选择员工后，若该员工维护了 `salaryEffectiveDate`，基本信息区下方展示「生效日期：{日期}」提示（只读）。

字段下方提示文案（i18n `payments.salaryEmployeeHint`）：「选择员工后自动带出月薪；可手动调整金额」。

**分区二：补充信息**

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 说明 | 多行文本 | 否 | 存入 `allocationSummary`；留空存 `-` |

保存时写入 `category=salary`、`employeeId`、对方为员工姓名；不写入结算单、合同、杂项类别字段。

#### 3.3.4 杂项类别主数据

杂项类别在 **杂项类别** 页面（`/misc-categories`，主数据分组）维护，登记杂项时从此处选用。

| 规则 | 说明 |
| --- | --- |
| 新建杂项 | 下拉仅展示 **enabled=true** 的类别 |
| 保存快照 | 写入 `miscKindId` + `miscKindName`（保存时名称快照） |
| 删除类别 | 从主数据移除后，**已有收付记录**仍展示快照名称；统计仍计入该类别金额 |
| 编辑详情 | 若记录类别已删除/停用，下拉仍保留当前项（用快照名称展示） |

详见 `需求文档/杂项类别.md`。

#### 保存规则（通用）

- 往来核销：须选结算单；摘要按 3.3.1 规则生成
- 杂项收支：`allocationSummary` 取「说明」，留空存 `-`；不写入结算单/合同字段
- 员工薪资：类型固定付款；`employeeId` 必填
- 保存成功后关闭弹窗，并自动打开该收付详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.4 弹窗：收付详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「详情」、新建保存后自动打开 |
| 弹窗标题 | `收付详情` |
| 弹窗尺寸 | 大号（lg） |

#### 表单字段

详情弹窗**不展示「类别」**切换（类别由记录本身决定，与新建时入口一致，不可在详情中改为其它类别）。

各类别字段与对应**新建弹窗**对齐，差异如下：

| 类别 | 详情表单字段（相对新建） | 说明 |
| --- | --- | --- |
| 往来核销 | 结算单号 → 方式 → 金额 → 收付时间 | **不展示**「类型」（收款/付款）；类型由所选结算单自动带出（应收→收款、应付→付款），切换结算单时同步更新 |
| 杂项收支 | 类型 → 方式 → 金额 → 收付时间 → 对方/用途 → 杂项类别；补充信息含说明 | 与新建杂项一致，**保留**类型字段 |
| 员工薪资 | 员工 → 方式 → 金额 → 收付时间；补充信息含说明 | **不展示**类型字段（固定付款，与新建薪资一致且无只读类型行） |

| 差异点 | 说明 |
| --- | --- |
| 结算单选项池 | 编辑时除待核销目标外，包含当前记录已关联的结算单（即使已 settled）；下拉展示全部待核销应收/应付（不按类型分段筛选） |
| 核销摘要回填 | 若存储值为 `-`，编辑框展示为空 |
| 对方选项 | 若原对方已不在客户列表，仍保留原选项（杂项） |
| 保存行为 | 保存后不关闭弹窗，展示绿色「已保存」 |
| 只读模式 | `readOnly=true` 时不展示保存按钮（合同全景等场景） |

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |
| 保存 | 提交表单（非只读时展示） |

#### 记录不存在

当传入的收付 ID 不存在时，弹窗内容区展示「未找到记录」，底部仅保留「关闭」。

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 危险确认框，文案中的标签为「收款 {金额}」或「付款 {金额}」 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一记录则关闭；若删除的是带结算单核销的往来收付，按结算单重算应收/应付 |

> 一期需求文档约定一笔收付可核销多笔往来、冲销时按分配解除；当前原型删除为直接从 Mock 数据移除，**未实现**核销冲销与部分解除分配。

### 3.6 跨页面入口（合同全景）

合同全景页（`/transactions`）在「收付款记录」Tab 中可：

- 查看与该合同关联的收付款子列表（按 `contractNo` 或关联结算单匹配）
- 点击「新建」打开 `PaymentCreateModal`（往来核销），预设：
  - `settlementDocId`：首张待核销结算目标（若有）

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 采购 → 应付、销售 → 应收（R06）
- 一笔收/付款可核销多笔往来
- 核销冲销只解除与本往来相关的分配
- 首页展示已收款、已付款、现金结余

**当前原型差异（须在验收时知晓）：**

- **已实现**往来核销：选择结算单后保存回写 `settledAmount` / `balance` / `status`（按 `settlementDocId` 匹配）
- **已实现**删除/修改带结算单核销的收付款后按结算单重算往来
- **已实现**员工薪资独立类别；选员工带出月薪；摘要区将薪资计入杂项支出
- 一笔收付当前原型核销**一笔**结算目标（多笔分配仍简化）
- 杂项收支、员工薪资不关联往来、不回写应收应付
- **未实现**冲销流程与作废阻断
- 首页资金指标来自独立 Mock 统计，**未与本页保存实时联动**

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无记录 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 金额/时间未填，或往来核销未选结算单，或薪资未选员工 | 浏览器原生校验或静默阻止提交 | 阻止提交 |
| 核销超额 | 往来核销金额大于结算单余额 | 金额输入 `max` 限制；提交时校验 | 阻止提交 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无删除权限 | 行操作不展示删除 | 演示环境已实现删除权限 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 页头「登记收付」下拉三类入口（往来核销 / 杂项收支 / 员工薪资），各自独立弹窗与标题
- 往来核销：先选收/付类型，再选待核销结算单；按 `settlementDocId` 回写应收/应付
- 员工薪资：选员工（字段标签「员工」）带出月薪，固定付款
- 列表展示类别、杂项类别、关联合同、关联结算单列；类别筛选含员工薪资
- 收付款列表、类别/类型/关键词筛选、创建时间倒序
- 收支摘要四格 StatCard（员工薪资计入杂项支出）
- 弹窗式登记 / 详情编辑（详情类别不可改；往来/薪资详情不展示类型字段）
- 收款与付款两种类型；现金 / 支票 / 转账三种方式
- 杂项类别主数据页（`/misc-categories`）；收付款页头入口；登记杂项从主数据选用
- 杂项收支表单分「基本信息」「补充信息」两分区
- 单条删除与二次确认（含权限控制）
- 合同全景页复用同一套收付弹窗（只读详情）

### 8.2 本期不包含（页面或资料未体现）

- 一笔收付核销多笔往来的明细管理
- 冲销、作废、审批流
- 收付凭证附件上传
- 导出、批量操作、列头排序
- 后端 API
- 与首页资金 KPI 的实时联动计算
