## 1. 引言

### 1.1 背景

收付款页用于登记客户/供应商的**实际收款与付款**，并通过选择应收/应付完成核销回写。往来单据由过磅自动生成；钱的进出在本页登记。侧边栏「应收账」「应付账」菜单已隐藏，核销选单仍读取后台往来数据。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「收付款」标题 |
| 页面头部 | 新建 | 单一「登记收付」入口 |
| 摘要区 | 收支摘要 | 默认展开；可收起/展开并用 `localStorage` 记住；展开时 4 张 StatCard（核销收/付、杂项收/支） |
| 筛选区 | 关键词 / 类别 / 类型 | 即时筛选；上方摘要随筛选结果重算 |
| 数据列表 | 收付列表 | 含类别、杂项类别、关联磅单 BX 等列 |
| 数据列表 | 行点击 / 操作 | 详情、删除 |
| 新建弹窗 | 类别 | 往来核销 / 杂项收支（分段选择） |
| 新建弹窗 | 往来核销字段 | 必选关联磅单（应收/应付）；对方由磅单带出 |
| 新建弹窗 | 杂项字段 | 必选杂项类别；对方手填；可选备注 |
| 详情弹窗 | 收付编辑 | 可切换类别并维护对应字段；保存后重算往来核销 |
| 删除 | 删除确认 | 删除后按 BX 重算对应往来已核销 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「对方 / 摘要」 | 对「对方 counterparty + 核销摘要 allocationSummary + 方式 method」拼接字符串做不区分大小写的包含匹配 |
| 类型 | 下拉单选 | 枚举：全部、收款、付款；默认「全部」 | 精确匹配 `type` 字段（`receipt` / `payment`） |

### 3.2 数据列表

以表格形式展示收付款记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 收付时间 | 收付款业务时间（YYYY-MM-DD HH:mm，精确到分钟） | 否 |
| 类型 | 收款 / 付款，以色块标签展示（收款成功色、付款警告色） | 否 |
| 方式 | 现金 / 支票 / 转账（根据存储值本地化展示） | 否 |
| 金额 Amount ($) | 收付金额，加粗、等宽数字，格式如 `HK$ 66,224` | 否 |
| 对方 | 客户或供应商名称 | 否 |
| 杂项类别 | 仅杂项有值，否则「—」 | 否 |
| 关联磅单 BX | 仅往来核销有值（`BX{单号}`），否则「—」 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 3.2.1 核销摘要展示规则

列表与详情加载时，对种子数据中繁体中文格式的摘要做本地化展示：

| 原始格式 | 展示转换 |
| --- | --- |
| `核銷 BX02513` / `核销 BX02513` | `核销 BX02513`（使用当前语言包的「核销」前缀） |
| `部分核銷 BX02474` / `部分核销 BX02474` | `部分核销 BX02474` |
| 其他文本 | 原样展示 |
| 存储值为 `-` | 列表展示为 `-`（经本地化函数原样返回） |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新登记的收付排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「收付详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含「收款/付款 + 金额」），确认后删除；若详情弹窗正在展示同一记录则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：登记收付（新建）

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「登记收付」按钮；亦可由合同全景页带预设参数打开（见 3.6） |
| 弹窗标题 | 登记收付 |
| 弹窗尺寸 | 大号（lg） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单分区与字段

**分区一：基本信息**（网格布局）

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 金额 Amount ($) | 数字输入 + HK$ 单位 | 是 | 默认 `0`；步进 `0.01` | 收付金额 |
| 收付时间 | 日期时间选择器 | 是 | 默认当前时刻（精确到分钟） | 格式 YYYY-MM-DDTHH:mm，展示为 YYYY-MM-DD HH:mm |
| 对方 | 可搜索下拉 | 是 | 默认客户列表第一项；可由预设带入 | 选项来自「客户管理」 |
| 类型 | 分段按钮 | 否 | 默认「收款」；可由预设带入 | 枚举：收款（receipt）、付款（payment） |
| 方式 | 分段按钮 | 否 | 默认「现金」 | 枚举：现金、支票、转账（内部存值为 `現金`/`支票`/`轉賬`） |

**分区二：补充信息**

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 类别 | 分段按钮 | 是 | 默认「往来核销」 | 往来核销 / 杂项收支 |
| 关联磅单 BX | 可搜索下拉 | 类别=往来核销时必填 | 空 | 按收款/付款列出待核销应收或应付；选中带出对方与建议金额 |
| 杂项类别 | 下拉 | 类别=杂项时必填 | 其他开支等 | 仅杂项显示 |
| 对方 | 下拉/文本 | 是 | 核销时由磅单带出 | 杂项时手填 |

#### 保存规则

- `allocationSummary` 为空时存储为 `-`
- 保存成功后关闭弹窗，并自动打开该收付详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 危险确认框，文案中的标签为「收款 {金额}」或「付款 {金额}」 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一记录则关闭 |

> 一期需求文档约定一笔收付可核销多笔往来、冲销时按分配解除；当前原型删除为直接从 Mock 数据移除，**未实现**核销冲销与应收应付联动回滚。

### 3.6 跨页面入口（合同全景）

合同全景页（`/transactions`）在「收付款记录」Tab 中可：

- 查看与该合同关联磅单相关的收付款子列表
- 点击「新建」打开 `PaymentCreateModal`，预设：
  - `counterparty`：合同对方客户名
  - `type`：销售合同默认 `receipt`（收款），采购合同默认 `payment`（付款）
  - `ticketBxNo`：首张正常磅单 BX 号（若有）
- 列表列与收付款页一致（不含审计列）
- 点击行内「编辑」打开 `PaymentDetailModal`

关联收付款的筛选逻辑在合同全景组件内按磅单 BX 号匹配核销摘要，不属于本页列表逻辑。

| 存储值 | 展示文案（简体） |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 采购 → 应付、销售 → 应收（R06）
- 一笔收/付款可核销多笔往来
- 核销冲销只解除与本往来相关的分配
- 首页展示已收款、已付款、现金结余

**当前原型差异（须在验收时知晓）：**

- **已实现**往来核销：选择应收/应付（磅单 BX），保存后回写 `settledAmount` / `balance` / `status`
- **已实现**删除/修改收付款后按 BX 重算往来核销
- 一笔收付当前原型核销**一笔**往来（多笔往来分配仍简化）
- 杂项收支不关联往来、不回写应收应付
- **未实现**冲销流程与作废阻断
- 首页资金指标来自独立 Mock 统计，**未与本页保存实时联动**

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无记录 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 金额/日期/对方未填 | 浏览器原生校验 | 阻止提交 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 单一新建入口；表单内选择类别（往来核销 / 杂项）
- 列表同时展示杂项类别与关联磅单列
- 收付款列表、即时筛选、创建时间倒序、分页
- 弹窗式登记 / 详情编辑
- 收款与付款两种类型
- 现金 / 支票 / 转账三种方式
- 对方、金额、收付时间（精确到分钟）、核销摘要（文本）维护
- 单条删除与二次确认
- 合同全景页复用同一套收付弹窗

### 8.2 本期不包含（页面或资料未体现）

- 一笔收付核销多笔往来的明细管理
- 冲销、作废、审批流
- 收付凭证附件上传
- 导出、批量操作、列头排序
- 后端 API、权限按钮级控制
- 与首页资金 KPI 的实时联动计算
