## 1. 引言

### 1.1 背景

首页总览（`/dashboard`）是登录后的**交互式经营看板**，依赖时间范围筛选与明细钻取，服务于桌面端日常经营与资金核对。大屏驾驶舱是面向**电视 / 显示器**的独立展示页：深色主题、大字号、零交互、常驻自动刷新，供老板与现场人员在 3–5 米外一眼掌握经营态势、资金健康与目标达成。两者定位不同，大屏不是把首页总览搬上去，而是对其做**减法与重排**——去掉筛选器、明细表与敏感字段，强化"一眼可读"的 Hero 指标与实时动态。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面形态 | 独立全屏 | 脱离 AppShell 侧栏；固定 16:9；深色主题；无鼠标/键盘交互 |
| 头部条 | 公司标识 + 时钟 | Logo / 公司名 / 标题「经营驾驶舱」/ 实时时钟 / 日期 / 数据更新时间 |
| Hero KPI | 6 张主指标卡 | 本月销售额 / 采购额 / 毛利(含毛利率) / 现金结余 / 过磅吨位 / 过磅车次，含环比、同比 |
| 趋势区 | 销售 vs 采购趋势 | 本年逐月双折线 + 销售面积填充；金额 / 吨位 Tab |
| 目标区 | 年度目标达成 | 销售额 / 毛利 / 吨位 三进度（YTD vs 年目标）+ 同比 |
| 货类区 | 货物类型购销占比 | 本月横向条形占比；金额 / 净重 Tab（复用首页总览口径） |
| 行情区 | 金属行情走势 | 铜价 / 铝价近 N 日折线（需补数据源） |
| 风控区 | 风控预警 | 应收余额 / 逾期应收(高亮) / 应付到期 / 合同履约预警 |
| 渠道区 | 渠道 Top | 本月 Top 采购来源 / Top 销售客户 + 集中度；对方名称脱敏 |
| 实时区 | 实时过磅流水 | 第三行右侧、与风控并列的滚动 ticker：今日磅单 时间/车牌/货类/净重/金额/方向 |
| 运行 | 自动刷新 | 默认每 60s 重算；全屏防休眠；可选 kiosk 自动登录 |

### 1.3 与首页总览的差异（设计取舍）

| 维度 | 首页总览 | 大屏驾驶舱 |
| --- | --- | --- |
| 交互 | 时间范围分段 + 自定义日历驱动全看板 | 零交互；每个组件**固定各自时间视角**（本月 / 本年 / 今日）同屏呈现 |
| 环比定义 | 所选区间日序列前后半段 | 本月 vs 上月合计；同比 = 本月 vs 去年同月合计（更贴合固定周期） |
| 明细 | 近日过磅摘要表 | 改为**滚动 ticker**，远处可读 |
| 敏感字段 | 含员工薪资、客户全名 | **不展示薪资**；对方名称**脱敏/代号**，避免公开屏泄密 |
| 目标/行情 | 无 | 新增「经营目标」「行情价」数据源（见 §5.3、§8.2） |

## 2. 页面菜单与权限规划

### 2.1 页面菜单

**菜单路径**：大屏驾驶舱（独立分组；侧栏可选隐藏，支持直链 `/big-screen` 投屏）

**路由地址**：`/big-screen`

> 大屏为展示用途，不进入业务侧栏主流程；通过独立链接或投屏设备访问。

### 2.2 权限规划

| 权限点 | 操作范围 | 数据范围 |
| --- | --- | --- |
| 查看 | 浏览大屏全部指标（只读展示） | 当前租户业务数据（演示环境未隔离） |
| 配置 | 设置经营目标、账期、行情参考价、是否展示精确现金 | 租户级配置 |
| 交互 | **无**（无筛选、无钻取、无编辑） | — |

> 大屏为只读展示，不提供任何写操作入口。

## 3. 模块需求说明

### 3.1 头部条（固定）

| 元素 | 说明 |
| --- | --- |
| 左侧 | 公司 Logo + 公司名（取自租户配置） |
| 中部 | 标题「经营驾驶舱」+ 副标题（如公司 Slogan，可空） |
| 右侧 | 实时时钟（HH:MM:SS，每秒跳动）+ 日期（YYYY 年 MM 月 DD 日 星期X）+ 数据更新时间「数据更新于 HH:MM:SS」 |

> 时钟由前端定时器驱动；数据更新时间随自动刷新（§4.1）刷新。

### 3.2 Hero KPI（第一排，全宽 6 卡，最大字号）

数据来源：Mock Store 中 `status === "normal"` 且业务日落在**本月**（自然月，含今日）的磅单；现金结余为时点值。

| 指标卡 | 主值 | 辅助信息 | 环比 | 同比 |
| --- | --- | --- | --- | --- |
| 本月销售额 | 销售方向 `amount` 合计 | — | vs 上月销售合计 | vs 去年同月销售合计 |
| 本月采购额 | 采购方向 `amount` 合计 | — | vs 上月采购合计 | vs 去年同月采购合计 |
| 本月毛利 | 销售额 − 采购额 | 「毛利率 = 毛利 / 销售额」 | vs 上月毛利 | vs 去年同月毛利 |
| 现金结余 | `openingCash` + 收款(日≤今日) − 付款(日≤今日) | 可配置是否展示精确值 | — | — |
| 本月过磅吨位 | `netKg` 合计（KG，大数转 T） | 副：采购净重 / 销售净重 | vs 上月吨位 | vs 去年同月吨位 |
| 本月过磅车次 | 正常磅单条数 | 副：采购车次 / 销售车次 | vs 上月车次 | vs 去年同月车次 |

- 环比 / 同比以彩色百分比呈现（涨绿跌红，遵循境内 convention）；基数为 0 且本期 > 0 计 100%。
- 现金结余为**时点指标**（截至今日），不随"本月"区间截断。
- 演示锚点：以磅单 / 收付款业务数据**最晚业务日**为「今日」，避免种子数据与真实日历错位导致空白（同首页总览）。

### 3.3 销售 vs 采购趋势（第二排左，宽栏）

| 属性 | 说明 |
| --- | --- |
| 标题 | 销售 vs 采购趋势（本年） |
| 周期 | **本年逐月**（1 月 – 当前月），每自然月一笔 |
| 类型 | SVG 双折线 + 销售面积填充 |
| 图例 | 销售（品牌色）、采购（强调色） |
| Tab | 金额（默认）/ 吨位（`netKg` 合计） |
| 数据源 | 正常磅单，按自然月聚合 `amount` / `netKg` |

### 3.4 年度目标达成（第二排中）

| 属性 | 说明 |
| --- | --- |
| 标题 | 年度目标达成 |
| 周期 | **YTD**（1/1 – 今日）vs 年目标 |
| 指标 | 销售额完成率 / 毛利完成率 / 吨位完成率（三进度环或进度条） |
| 摘要 | 各指标 YTD 实际值 / 目标值 + 同比（YTD vs 去年同期） |

| 指标 | 公式 |
| --- | --- |
| 销售额完成率 | YTD 销售 `amount` 合计 / `targets.salesTarget` × 100% |
| 毛利完成率 | YTD 毛利 / `targets.profitTarget` × 100% |
| 吨位完成率 | YTD `netKg` 合计 / `targets.tonnageTarget` × 100% |

> ⚠️ **需补能力**：系统当前无「经营目标」模块（合同仅有约定重量/履约进度，无公司级年度目标）。须新增 `targets` 配置（销售额 / 毛利 / 吨位 年目标，建议在基础设置或独立配置页维护）。本 PRD 将其列为必补项（见 §8.2）。

### 3.5 货物类型购销占比（第二排右）

| 属性 | 说明 |
| --- | --- |
| 标题 | 货物类型购销占比 |
| 周期 | **本月** |
| 数据 | 本月正常磅单，按 `materialSummary` 汇总；排除空 / `—`；复合名整串不拆 |
| 指标 | Tab「金额」：销售+采购 `amount` 合计占比；Tab「净重」：销售+采购 `netKg` 合计占比；默认金额 |
| 排序 | 按金额合计降序；超过 8 类时 Top 7 +「其他」 |
| 图示 | 横向条形占比：色点 + 货类名（16px）+ 粗进度条 + 大字百分比（19px）；大屏远处可读，原型已验证优于环图 |
| 口径 | 与首页总览 §3.4 完全一致，可复用同一聚合函数 |

### 3.6 金属行情走势（第三排左）

| 属性 | 说明 |
| --- | --- |
| 标题 | 金属行情走势 |
| 周期 | 近 30 / 90 日（可配置） |
| 数据 | 铜价 / 铝价 双折线 |
| 数据源 | ⚠️ **需补**：系统当前无行情模块。`项目资料/06_市场价记录` 仅为样例静态数据；正式须新增行情数据源——方案 A：后台手工录入内部参考价；方案 B：接入外部金属行情接口。本 PRD 列为需补项（见 §8.2） |

> 行情对回收老板属高价值（囤货即赌行情），但属新增数据能力，不在一期现有数据源内。

### 3.7 风控预警（第三排中）

| 属性 | 说明 |
| --- | --- |
| 标题 | 风控预警 |
| 应收余额 | 区间内应收 `balance` 合计（status ∈ {open, partial}） |
| 逾期应收 | 应收 `balance > 0` 且 `status ∈ {open, partial}` 且（今日 − 往来 `date`）> **账期**（默认 60 天，可配置）的 `balance` 合计；超过阈值**红色高亮** |
| 应付到期 | 应付 `balance > 0` 且未结清且距往来 `date` 超过账期的 `balance` 合计 |
| 合同履约预警 | 合同 `fulfilledKg / plannedKg ≥ 0.9` 且 `< 1`（进行中）或超约重，列出预警合同数 |

| 指标 | 公式 / 口径 |
| --- | --- |
| 应收余额 | Σ 应收 `balance`（正常，排除 void） |
| 逾期应收 | Σ 应收 `balance`，满足未结清且账期外（见上） |
| 应付到期 | Σ 应付 `balance`，满足未结清且账期外 |
| 合同履约预警数 | 满足 `fulfilledKg/plannedKg ≥ 0.9` 且状态为履约中的合同数 |

> ⚠️ **数据现状**：往来（`ArApItem`）字段为 `amount / settledAmount / balance / status / date / customerName`，**无独立到期日字段**。逾期以「往来 `date` + 可配置账期」估算，须新增**账期**配置（默认 60 天，建议在基础设置维护）。本 PRD 列为必补项（见 §8.2）。

### 3.8 渠道 Top（第三排右）

| 属性 | 说明 |
| --- | --- |
| 标题 | 渠道 Top（本月） |
| 数据 | 本月正常磅单，按 `customerName` + 方向汇总 `amount` 降序 |
| 展示 | Top 采购来源（供应商）Top 3–5；Top 销售客户 Top 3–5；各自占比进度条 |
| 集中度 | 来源/客户 Top1 或 Top3 占本期往来比例 |
| 脱敏 | ⚠️ 公开屏不展示对方全名；以「来源 A / 客户 B」代号或仅显示首尾字符展示（见 §3.10） |

### 3.9 实时过磅流水（第三行右侧，与风控并列）

| 属性 | 说明 |
| --- | --- |
| 标题 | 今日实时过磅流水 |
| 周期 | **今日**（锚点日当天） |
| 数据 | 今日正常磅单，按 `date` 降序，滚动展示 |
| 列 | 时间 / 车牌 `plate` / 货类 `materialSummary` / 净重 `netKg` / 金额 `amount` / 方向（采购 / 销售） |
| 滚动 | 自下而上或横向无缝滚动；新磅单进入时高亮 |
| 计数器 | 今日累计车次、今日累计吨位（跳动数字，随刷新更新） |

> 这是大屏的"生意还活着"脉搏，电视端效果最佳。

### 3.10 数据安全与脱敏（全局约束）

大屏为办公室 / 厂区**公开显示屏**，可见对象含员工、访客、送货司机，须规避敏感信息：

| 项 | 规则 |
| --- | --- |
| 员工薪资 | **不展示**（首页总览资金快览含薪资，大屏移除） |
| 客户 / 供应商全名 | 默认**脱敏**（代号或首尾字符）；精确名可在"仅内网/带登录"模式下开启 |
| 精确现金结余 | 可配置是否展示具体数值；公开屏可仅展示"充裕 / 偏紧"分级或隐藏 |
| 个人 / 审计信息 | 不展示创建人、IP 等 |

## 4. 交互与布局

### 4.1 全局

- **形态**：独立路由 `big-screen`，脱离 `(app)` 侧栏壳，全屏深色。
- **自动刷新**：默认每 **60s** 重算一次（接 API 后改为轮询或 WebSocket 推送）；刷新即更新「数据更新于」时间。
- **零交互**：无筛选、无钻取、无 hover 详情；不支持键盘/鼠标操作（投屏场景）。
- **防休眠 / 全屏**：建议页面请求全屏并禁用屏保（浏览器全屏 API + 定时心跳）；kiosk 自动登录可后置（见 §8.2）。
- **可读性**：大字号、高对比、关键数字 ≥ 一定尺寸以 3–5 米可读；深色背景配品牌色强调。
- **加载**：首屏 `PageSkeleton`；`ssr: false` 或静态壳 + 客户端拉取。

### 4.2 布局（16:9 栅格）

| 行 | 内容 |
| --- | --- |
| 头部条 | Logo / 公司名 · 标题 · 时钟 + 日期 + 更新时间 |
| 第一排 | Hero KPI × 6（全宽等分） |
| 第二排 | 左宽：销售 vs 采购趋势 ｜ 中：年度目标达成 ｜ 右：货类购销占比 |
| 第三排 | 左：金属行情走势 ｜ 中：风控预警 ｜ 右：渠道 Top |
| 第四排 | 全宽：今日实时过磅流水 ticker + 今日累计计数器 |

- 同行卡片等高；小屏（非 16:9 电视）可纵向堆叠但保持可读性。
- 深色主题：背景近黑/深蓝，卡片半透明描边，数字品牌色/涨绿跌红。

## 5. 数据模型与计算依赖

### 5.1 输入数据源（复用现有）

| 数据源 | 用途 | 现有字段 |
| --- | --- | --- |
| `weighTickets`（磅单） | Hero KPI、趋势、货类、渠道、实时流水 | `status`、`amount`、`netKg`、`materialSummary`、`bxNo`、`customerName`、`plate`、`contractNo`、方向、`date` |
| `receivables` / `payables`（往来） | 风控应收/应付余额、逾期 | `amount`、`settledAmount`、`balance`、`status`、`date`、`customerName` |
| `payments`（收付款） | 现金结余 | `type`（receipt/payment）、`category`（misc/salary）、`amount`、`date` |
| `contracts`（合同） | 合同履约预警 | `plannedKg`、`fulfilledKg`、`status`、`no` |
| `tenant.openingCash` | 现金结余 | 期初现金 |

### 5.2 磅单口径

- 仅 `status === "normal"`；作废磅单不计入任何 KPI / 图表 / 排名 / 流水。
- 金额单位为 **HKD**（系统默认单一币种）。

### 5.3 需新增数据源（必补项，见 §8.2）

| 数据源 | 用途 | 建议字段 |
| --- | --- | --- |
| `targets`（经营目标） | 年度目标达成 | `year`、`salesTarget`、`profitTarget`、`tonnageTarget` |
| `creditPeriod`（账期） | 逾期应收 / 应付到期估算 | `days`（默认 60） |
| `marketPrices`（行情价） | 金属行情走势 | `date`、`metal`（铜/铝）、`price` |
| 展示配置 | 脱敏 / 现金展示开关 | `maskCounterparty`、`showExactCash` |

### 5.4 与各期业务需求的对应

一期约定首页含经营概览与资金概览。大屏在其上：新增年度目标、行情、风控预警与实时流水视角；移除筛选/明细/薪资/敏感名。趋势、货类、应收应付、现金沿用现有聚合口径。

## 6. 状态与异常场景

| 场景 | 表现 / 规则 |
| --- | --- |
| 首次加载 | `PageSkeleton` → 大屏 |
| 本月无正常磅单 | Hero KPI 为 0；货类/渠道空态；趋势按自然月轴展示（可能全 0） |
| 无应收/应付 | 风控区余额为 0；逾期为 0 |
| 未配置经营目标 | 目标区显示「未配置目标」占位，完成率不计算 |
| 未接入行情 | 行情区空态「暂无行情数据」 |
| 实时流水为空 | ticker 显示「今日暂无过磅」 |
| 刷新失败（接 API 后） | 顶部提示「数据更新失败，展示上次数据」；保留上次快照 |
| 时钟漂移 | 以客户端时间为准；可校时 |

## 7. 验收标准

| 验收点 | 标准 |
| --- | --- |
| 独立形态 | 脱离侧栏，全屏深色，16:9 布局 |
| 头部 | Logo/公司名/标题/实时时钟(秒级)/日期/更新时间 均显示且时钟跳动 |
| Hero 6 卡 | 数值与本月 Mock 一致；含环比/同比；现金结余为时点值；吨位/车次含净重/车次辅助 |
| 趋势图 | 本年逐月双折线 + 销售面积；金额/吨位 Tab 切换 |
| 目标区 | 三进度（销售/毛利/吨位）YTD vs 年目标；未配置目标时占位 |
| 货类占比 | 本月金额/净重 Tab；与首页总览口径一致；大屏用横向条形（非环图） |
| 行情区 | 铜/铝双折线；未接入时空态（接入后正常） |
| 风控区 | 应收余额、逾期应收(超阈值红)、应付到期、合同履约预警数 正确 |
| 渠道 Top | 本月来源/客户 Top；占比进度条；名称脱敏 |
| 实时流水 | 底部滚动 ticker 含 6 列；今日累计车次/吨位计数器 |
| 自动刷新 | 每 60s 重算并更新「数据更新于」 |
| 脱敏 | 不展示薪资；对方名称默认脱敏 |
| 零交互 | 无筛选/钻取/编辑入口 |

## 8. 范围边界

### 8.1 本期包含（以当前原型 + 必补配置为准）

- 独立深色全屏大屏，16:9 布局，脱离侧栏
- 头部实时时钟 / 日期 / 数据更新时间
- Hero KPI（6 卡，本月 + 环比/同比，现金时点）
- 销售 vs 采购趋势（本年）、货类购销占比（本月，复用口径）
- 实时过磅流水 ticker + 今日累计计数器
- 风控预警（应收余额 / 逾期 / 应付到期 / 合同履约预警）
- 渠道 Top（脱敏）
- 自动刷新（60s）、全屏防休眠、零交互只读
- 脱敏与现金展示开关

### 8.2 本期需补能力（列为必补，非现有数据源）

| 能力 | 必要性 | 说明 |
| --- | --- | --- |
| 经营目标配置 `targets` | **必补** | 年度目标达成依赖；建议在基础设置新增年目标录入 |
| 账期配置 `creditPeriod` | **必补** | 逾期应收/应付到期估算依赖（往来无到期日字段） |
| 行情数据源 `marketPrices` | **必补或手工** | 金属行情走势依赖；先支持后台手工录入参考价，二期再接外部接口 |
| 展示配置（脱敏/现金开关） | 建议 | 控制公开屏敏感信息 |

### 8.3 本期不包含

- 库存吨位 / 估值 / 周转（架构明确为**二期**：分拣入库 / 精细库存成本）；现阶段可用"未结算磅单净重"做粗略在途库存代理（可选，非必做）
- 过磅设备实时状态（二期 串口接入）；现仅静态
- 时间范围筛选器、明细钻取、导出 / 打印
- kiosk 自动登录（可后置，依赖设备/认证方案）
- 后端 API、真实多端一致（依赖 `data/client` 接入）
- 跨租户老板总览（一期明确不做）
