## 1. 引言

### 1.1 背景

基础设置页用于维护租户级基础参数，包括公司名称、英文名称及期初现金，为首页资金结余计算、侧边栏租户展示及登录页品牌信息提供数据来源。同模块相关的个人资料与密码修改通过侧边栏用户菜单以弹窗完成。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 租户信息表单 | 公司名称 | 编辑租户中文名称 |
| 租户信息表单 | 英文名称 | 编辑租户英文名称 |
| 租户信息表单 | 币种 | 只读展示当前币种 |
| 租户信息表单 | 期初现金 | 编辑期初现金金额（数字输入） |
| 租户信息表单 | 已保存提示 | 展示当前已保存的期初现金格式化金额 |
| 操作区 | 保存 | 提交表单，更新租户信息 |
| 操作区 | 重置期初现金 | 演示用，将期初现金重置为 100000 |
| 操作区 | 保存反馈 | 保存成功后展示「已保存」，约 2 秒后自动消失 |
| 关联能力 | 修改资料 | 用户菜单弹窗更新显示姓名与头像；邮箱只读（详见 `修改资料.md`） |
| 关联能力 | 修改密码 | 用户菜单弹窗修改密码（详见 `修改密码.md`） |

| 权限点 | 操作范围 | 数据范围 |

## 3. 模块需求说明

### 3.1 主页面：租户信息与期初现金

页面标题为「基础设置」，主体为单卡片表单，最大宽度约 `max-w-2xl`。

#### 卡片分组

**分组标题**：租户信息

#### 表单字段

| 字段 | 控件类型 | 必填 | 可编辑 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 公司名称 | 文本输入 | 否 | 是 | 演示：`寶新金屬回收有限公司` | 租户中文名称 |
| 英文名称 | 文本输入 | 否 | 是 | 演示：`BAO XIN METAL RECYCLE LIMITED` | 租户英文名称 |
| 币种 | 文本输入 | — | **否**（禁用） | 固定 `HKD` | 类型约束为港币，页面不可修改 |
| 期初现金 | 数字输入 | 否 | 是 | 演示：`100000` | `type="number"`；非数字保存时按 `0` 处理 |

#### 辅助信息

表单下方展示一行提示：

> 当前已保存期初：**{格式化金额}**

金额通过 `formatMoney` 格式化展示（与系统其他金额字段一致）。

#### 操作按钮

| 按钮 | 类型 | 行为 |
| --- | --- | --- |
| 保存 | 主按钮（提交） | 调用 `updateTenant` 更新 `name`、`nameEn`、`openingCash`；展示「已保存」约 2 秒后消失 |
| 重置期初现金 | 次按钮 | 弹出浏览器原生确认框「将期初现金重置为 100000？」；确认后仅将期初现金设为 `100000` 并更新输入框与存储，同时展示「已保存」 |

> 主页面**无**「取消」按钮；重置操作**仅影响期初现金**，不重置公司名称与英文名称。

#### 保存规则

```text
openingCash = Number(输入值) || 0
```

- 空值或非数字输入保存为 `0`
- 保存后 `tenant` 状态立即更新，侧边栏租户名、首页现金结余等联动刷新

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：当前为前端 Mock 数据，未体现独立 Loading
- **布局**：主页面单卡片表单；子页面使用 `FormCard` 卡片布局
- **响应式**：主表单最大宽度 `max-w-2xl`

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 保存反馈（主页面） | 「已保存」展示约 2 秒后自动消失 |
| 保存反馈（子页面） | 成功/错误提示持续展示直至下次提交 |
| 重置确认 | 使用浏览器原生 `window.confirm`，非统一 `ConfirmDialog` 组件 |
| 币种只读 | 币种字段禁用，不可编辑 |
| 子页面取消 | （已改为弹窗关闭，无独立子页取消跳转） |

## 5. 数据模型（页面涉及字段）

### 5.1 租户（Tenant）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 租户唯一标识 |
| name | string | 公司名称（中文） |
| nameEn | string | 公司名称（英文） |
| currency | `"HKD"` | 币种，固定港币 |
| openingCash | number | 期初现金（HKD） |

### 5.2 演示种子数据

| 字段 | 值 |
| --- | --- |
| id | `t-baoxin` |
| name | 寶新金屬回收有限公司 |
| nameEn | BAO XIN METAL RECYCLE LIMITED |
| currency | HKD |
| openingCash | 100000 |

### 5.3 与业务需求文档的对应关系

一期项目需求文档约定：

- 基础参数包含客户、货物类型、收付方式、**期初现金**等
- 期初现金：启用时录入一次（HKD）；调整记审计日志
- 现金结余 ≈ 期初 + 本期收款 − 本期付款

**当前原型差异（须在验收时知晓）：**

- 期初现金**可反复修改**，无「仅录入一次」限制
- 调整**无**审计日志记录
- 币种**不可配置**，固定 HKD
- **无**收付方式等其余基础参数的配置入口（收付方式未在本页体现）
- 租户信息修改**无**二次确认
- 个人资料为演示级本地会话能力（姓名、头像可改，邮箱只读）；匹配员工库时同步姓名与头像；修改密码见 `修改密码.md`

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 保存成功（主页面） | 点击保存或重置确认 | 绿色「已保存」 | 2 秒后自动隐藏 |
| 重置取消 | 重置确认框点取消 | 无变化 | 数据不变 |
| 期初现金非法输入 | 输入非数字后保存 | 保存为 0 | `Number(x) \|\| 0` |
| 子页面校验失败 | 必填项为空等 | 红色错误文案 | 阻止提交 |
| 子页面保存成功 | 资料/密码更新成功 | 绿色成功文案 | 密码页清空输入 |
| 未登录访问子页面 | 无会话用户 | 提交时报「未登录」 | 未在页面或资料中体现路由拦截 |
| 权限不足 | 非管理员访问 | 未在页面或资料中体现 | 演示环境未实现 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏「基础设置」可进入 `/settings/cash`，标题为「基础设置」 |
| 租户字段展示 | 正确展示并可编辑公司名称、英文名称、期初现金 |
| 币种只读 | 币种显示 HKD 且不可编辑 |
| 已保存提示 | 展示当前已保存期初的格式化金额 |
| 保存联动 | 保存后侧边栏公司名、首页现金结余随期初现金更新 |
| 重置期初 | 确认后将期初现金重置为 100000 |
| 保存反馈 | 主页面保存/重置后展示「已保存」并约 2 秒消失 |
| 个人资料入口 | 用户菜单打开修改资料弹窗；邮箱只读 |
| 资料保存 | 可修改姓名、上传/移除头像并成功提示；侧边栏头像联动 |
| 密码入口 | 用户菜单打开修改密码弹窗 |
| 密码能力 | 以 `修改密码.md` 验收标准为准 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 租户公司名称、英文名称、期初现金的编辑与保存
- 币种只读展示（HKD）
- 期初现金演示重置（100000）
- 期初现金与首页资金结余联动
- 用户菜单弹窗：修改资料（姓名、头像）、修改密码（详见独立文档）

### 8.2 本期不包含（页面或资料未体现）

- 收付方式、多币种、汇率等其余基础参数
- 期初现金一次性录入限制与审计日志
- 租户停用/启用（平台超管能力）
- 真实后端密码哈希与服务端鉴权（演示本地规则见 `修改密码.md`）
- 修改登录邮箱
- 头像服务端存储、手动裁剪框
- 后端 API、权限按钮级控制
