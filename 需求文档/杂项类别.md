## 1. 引言

### 1.1 背景

收付款模块中「杂项收支」需选择杂项类别（如水电燃油、运费、其他收入等）。类别由本页作为**主数据**维护，替代原先固定枚举；登记杂项时从**启用**的类别中选择，并自动带出默认收/付类型。删除或停用类别不影响已有收付记录及其统计口径。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 入口 | 侧栏主数据 | 「杂项类别」菜单进入列表（`menu.miscCategories`，图标 receipt） |
| 入口 | 收付款页头 | 按钮「杂项类别」跳转本页（需 `miscCategories` 模块查看权限） |
| 页面头部 | 页面标题 | 展示「杂项类别」 |
| 页面头部 | 新建杂项类别 | 打开新建弹窗（受 `canCreate` 控制） |
| 筛选区 | 关键词 | 按类别名称即时模糊筛选 |
| 筛选区 | 启用状态 | 分段选择：全部 / 启用 / 停用，即时筛选 |
| 数据列表 | 类别列表 | 名称、默认收/付、关联记录数、启用状态、创建/更新时间 |
| 数据列表 | 行点击 | 点击行打开详情弹窗 |
| 数据列表 | 行操作 | 详情、删除（删除受 `canDelete` 控制） |
| 新建弹窗 | 录入类别 | 名称（必填）、默认收/付类型、启用状态 |
| 详情弹窗 | 编辑类别 | 修改名称、默认类型、启用状态；展示关联收付笔数 |
| 详情弹窗 | 只读模式 | 无编辑权限时字段只读，仅展示关闭按钮 |
| 删除 | 删除确认 | 无关联记录时标准删除确认；有关联记录时额外警告 |
| 跨模块 | 收付款登记 | 杂项下拉仅展示启用类别；切换类别自动带出默认收/付类型 |
| 跨模块 | 历史数据 | 收付记录保存 `miscKindId` + `miscKindName` 快照；删除类别不改写历史 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。多条件之间为 **AND** 组合。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入（`TextInput size="sm"`） | 占位符复用 `form.keywordProject`（文案为「项目类型名称」，与项目类型页一致） | 对类别 `name` 做不区分大小写的包含匹配 |
| 启用状态 | 分段控件 `SegmentedControl size="sm"` | 枚举：全部（`all`）、启用（`enabled`）、停用（`disabled`）；默认「全部」 | 精确匹配 `enabled` 布尔值 |

- **操作按钮**：未在页面或资料中体现独立的「查询」「重置」按钮。

### 3.2 数据列表

以 `DataTable` 展示，占满列表区域高度（`fillHeight`）。默认排序：**创建时间倒序**（`sortByCreatedAtDesc`）。

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 类别名称 `name` | 加粗展示 | 否（整体按创建时间倒序） |
| 默认收/付 `defaultType` | `receipt` 显示「收款」绿色徽章；`payment` 显示「付款」橙色徽章 | 否 |
| 记录数 | 统计 `category === "misc"` 且 `miscKindId` 等于该行 `id` 的收付款笔数；为 0 时显示「—」 | 否 |
| 启用状态 `enabled` | 启用蓝色徽章 / 停用红色徽章 | 否 |
| 创建时间 `createdAt` | 审计列，格式化日期时间 | 默认列表倒序依据 |
| 更新时间 `updatedAt` | 审计列，格式化日期时间 | 否 |
| 操作 | `RowActions`：详情、删除 | — |

- **分页规则**：未在页面或资料中体现（一次展示全部过滤结果）。
- **批量操作**：未在页面或资料中体现。
- **行操作**：
  - **详情**：`setDetailId(r.id)`，打开详情弹窗。
  - **删除**：弹出确认框后调用 `removePaymentMiscCategory`；若当前详情弹窗正展示被删行，自动关闭详情。
- **行点击**：与详情等效，打开详情弹窗。
- **排序**：列头不可点击排序；列表整体按 `createdAt` 倒序。
- **导出**：未在页面或资料中体现。

**删除确认规则**

| 场景 | 确认文案 | 行为 |
| --- | --- | --- |
| 无关联收付记录 | 标准删除确认（`deleteConfirmMessage`，含类别名称） | 确认后从主数据移除 |
| 有关联收付记录（`recordCount > 0`） | `miscCategories.deleteHasRecordsWarning`：「该类别下有 {count} 笔收付款记录，删除后已有记录将保留其类别名称，但新建时将不再可选。确定删除？」（危险样式） | 确认后仍允许删除；**不**修改已有 `payments` 记录 |

**记录数统计口径**

- 仅统计 `payments` 中 `category === "misc"` 且 `miscKindId === 类别.id` 的记录。
- 员工薪资（`category === "salary"`）不计入杂项类别记录数。

### 3.3 弹窗：新建杂项类别

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页头「新建杂项类别」按钮 |
| 组件 | `MiscCategoryCreateModal` |
| 标题 | `miscCategories.new`（新建杂项类别） |

| 字段 | 控件 | 输入限制 | 校验 |
| --- | --- | --- | --- |
| 名称 | 文本输入 | 占位符 `form.miscKind`；`required` | 提交前 `name.trim()` 非空；HTML `required` |
| 默认收/付 | 下拉 `Select` | 枚举：`receipt`（收款）、`payment`（付款）；默认 `payment` | — |
| 启用状态 | 开关 `Switch` | 默认 `true`（启用）；标签随状态显示「启用」/「停用」 | — |

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单；调用 `addPaymentMiscCategory`；成功后关闭弹窗并打开新建行的详情弹窗（`onCreated`） |

弹窗打开时重置表单：名称清空、默认类型 `payment`、启用 `true`。

**主键生成**：`uid("pmc")` 前缀（如 `pmc-xxxxx`）。

### 3.4 弹窗：杂项类别详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 行点击、行操作「详情」 |
| 组件 | `MiscCategoryDetailModal` |
| 标题 | `form.miscDetail`（杂项详情） |

| 字段 | 控件 | 可编辑条件 |
| --- | --- | --- |
| 名称 | 文本输入 | `!readOnly`；`required` |
| 默认收/付 | 下拉 `Select` | `!readOnly` |
| 启用状态 | 开关 `Switch` | `!readOnly` |

| 附加信息 | 说明 |
| --- | --- |
| 关联记录提示 | 当 `recordCount > 0` 时，底部展示关联收付笔数（小字灰色） |
| 保存成功提示 | 编辑保存后展示 `common.saved`（已保存），弹窗**不自动关闭** |

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |
| 保存 | 仅可编辑模式展示；调用 `updatePaymentMiscCategory`；成功后 `setSaved(true)` |

**记录不存在**：当 `id` 对应行已从列表删除时，展示 `common.notFoundHint`，footer 仅「关闭」。

**只读模式**（`readOnly=true`，即无 `canEdit`）：

- 所有字段 `readOnly` / `disabled`。
- Footer 仅「关闭」，无「保存」。

## 4. 与收付款模块的关系

### 4.1 入口联动

| 入口 | 位置 | 条件 |
| --- | --- | --- |
| 收付款页头按钮 | `/payments` 页头 actions 区，文案 `payments.manageMiscCategories`（杂项类别） | 用户具备 `miscCategories` 的 `view` 权限 |
| 侧栏菜单 | 主数据分组 | 用户具备 `miscCategories` 菜单可见权限 |

### 4.2 杂项登记选用规则

| 项 | 规则 |
| --- | --- |
| 下拉选项来源 | `miscCategorySelectOptions(paymentMiscCategories)` |
| 新建可选范围 | 仅 `enabled === true` 的类别 |
| 编辑兜底 | 若当前记录的 `miscKindId` 已停用或已从主数据删除，仍补入选项（标签优先 `miscKindName` 快照） |
| 切换类别 | `handleMiscKindChange`：自动将收/付 `type` 设为该类别的 `defaultType` |
| 保存字段 | `miscKindId` + `miscKindName`（`resolveMiscCategoryForSave`）；清除废弃字段 `miscKind` |

### 4.3 展示与统计

| 场景 | 规则 |
| --- | --- |
| 列表杂项类别列 | `paymentMiscCategoryLabel`：优先 `miscKindName` 快照 → 主数据名称 → 旧枚举兼容 |
| 收支摘要杂项汇总 | `paymentMiscCategoryKey` 按 ID/旧枚举键分组；已删除类别仍计入历史统计 |
| 关键词搜索（收付款列表） | 可匹配 `miscKindId`、`miscKindName` |

### 4.4 删除 / 停用后的影响

| 操作 | 对已有收付记录 | 对新建杂项登记 | 对统计 |
| --- | --- | --- | --- |
| 停用（`enabled=false`） | 记录仍展示快照名称 | 下拉不再出现 | 历史金额仍按记录 ID/名称计入 |
| 删除主数据 | 记录保留 `miscKindId` + `miscKindName` | 下拉不再出现（编辑时靠快照补项） | 统计键仍有效，名称来自快照 |

## 5. 数据模型

### 5.1 杂项类别主数据 `PaymentMiscCategory`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 主键；新建时 `uid("pmc")` |
| `name` | string | 类别名称（展示与登记快照来源） |
| `defaultType` | `receipt` \| `payment` | 登记杂项时默认收/付类型 |
| `enabled` | boolean | 是否可在新建杂项时下拉选用 |
| `createdAt` | string | 创建时间（审计） |
| `updatedAt` | string | 更新时间（审计） |

**演示种子数据（8 条）**

| id | name | defaultType | enabled |
| --- | --- | --- | --- |
| pmc-salary | 薪金 | payment | true |
| pmc-freight | 运费 | payment | true |
| pmc-petty-cash | PETTY CASH | payment | true |
| pmc-utilities | 水电燃油 | payment | true |
| pmc-other-expense | 其他开支 | payment | true |
| pmc-other-income | 其他收入 | receipt | true |
| pmc-deposit | 账户存入/调拨 | receipt | true |
| pmc-other | 其他 | payment | true |

> 种子 ID 与旧 `PaymentMiscKind` 枚举通过 `legacyMiscKindId` 映射，用于历史数据迁移兼容。

### 5.2 收付款记录关联字段（`category === "misc"` 时）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `miscKindId` | string? | 类别主键 |
| `miscKindName` | string? | **保存时写入**的名称快照 |
| `miscKind` | `PaymentMiscKind`? | `@deprecated` 旧枚举，保存时置 `undefined` |

**名称唯一性**：未在页面或资料中体现强制唯一校验；一期不阻止同名类别。

## 6. 交互设计

### 6.1 全局交互

- **加载状态**：演示环境为本地 Mock Store，无异步 Loading；未在页面或资料中体现独立 Loading 骨架。
- **空状态**：过滤结果为空时，`DataTable` 展示 `common.empty` 统一空态文案。
- **响应式**：列表页使用 `ListPageLayout` + `FilterBar` 弹性布局；未在页面或资料中体现专项移动端适配说明。

### 6.2 特殊交互

| 交互名称 | 触发条件 | 系统处理 | 结果反馈 |
| --- | --- | --- | --- |
| 即时筛选 | 修改关键词或启用状态分段 | 前端 `useMemo` 重算 `rows` | 列表即时刷新 |
| 新建后跳转详情 | 新建保存成功 | `onCreated(id)` → `setDetailId(id)` | 新建弹窗关闭，详情弹窗打开 |
| 删除时关闭详情 | 删除行且 `detailId === row.id` | `setDetailId(null)` | 详情弹窗关闭 |
| 详情保存不关闭 | 编辑模式点击保存 | `updatePaymentMiscCategory` | 弹窗内展示「已保存」 |
| 收付款切换杂项类别 | 登记杂项时改下拉 | `setType(defaultTypeForMiscCategory(cat))` | 收/付类型自动切换 |

## 7. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无匹配类别 | 表格空态 `common.empty` | 可调整筛选或新建 |
| 名称未填 | 新建/编辑提交时名称为空 | HTML `required` 阻止提交；JS `if (!name.trim()) return` | 不调用 Store |
| 详情目标不存在 | 打开详情时 ID 已删除 | 文案 `common.notFoundHint` | 仅可关闭 |
| 删除有关联记录 | `recordCount > 0` | 危险样式二次确认，展示笔数 | 确认后仍删除主数据；历史记录不变 |
| 无删除权限 | `!perm.canDelete` | 行操作不展示删除 | 不可删除 |
| 无编辑权限 | `!perm.canEdit` | 详情只读 | 不可保存 |
| 无新建权限 | `!perm.canCreate` | 页头无新建按钮 | 不可新建 |
| 无查看权限 | 菜单不可见 | 侧栏不展示；收付款页头无跳转按钮 | 不可进入本页 |
| 查询失败 / 网络异常 | 未在页面或资料中体现 | — | 演示环境无远程请求 |
| 重复提交 | 连续点击保存 | 未在页面或资料中体现防抖 | — |

## 8. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 菜单入口 | 具备权限的用户可在侧栏「主数据 → 杂项类别」进入 `/misc-categories` |
| 收付款入口 | 具备 `miscCategories.view` 的用户在收付款页头可见「杂项类别」并跳转本页 |
| 列表展示 | 列表展示名称、默认收/付、记录数、启用状态、创建/更新时间；默认创建时间倒序 |
| 筛选 | 关键词模糊匹配名称；启用状态分段筛选即时生效 |
| 新建 | 可新建类别并设置默认收/付与启用状态；保存后自动打开详情 |
| 编辑 | 详情弹窗可修改字段；保存后提示「已保存」且不关闭弹窗 |
| 只读 | 无编辑权限时详情只读且无保存按钮 |
| 删除无记录 | 无关联收付时出现标准删除确认，确认后从列表移除 |
| 删除有记录 | 有关联收付时出现带笔数的警告确认；确认删除后主数据移除，收付款记录名称与金额不变 |
| 停用 | 停用后新建杂项下拉不可选；已有记录编辑时仍可展示（靠快照补项） |
| 收付款登记 | 杂项新建下拉仅启用项；切换类别自动带出默认收/付类型 |
| 统计不丢失 | 删除类别后，收付款列表杂项列、收支摘要杂项汇总仍包含该类别历史数据 |

## 9. 范围边界

- **本期包含**：
  - 杂项类别主数据 CRUD（列表、筛选、新建、编辑、删除）
  - 与收付款杂项登记的选用、默认类型联动、名称快照
  - 删除/停用后历史记录与统计口径保护
  - 收付款页头快捷入口
  - 角色权限控制（查看/新建/编辑/删除）
- **本期不包含**：
  - 列表分页、排序列头、导出/导入
  - 类别名称强制唯一校验
  - 删除时阻止（仅警告，不硬阻止）
  - 类别排序号、图标、颜色等扩展属性
  - 与员工薪资（`category=salary`）的类别关联（薪资为独立登记流程）
