## 1. 引言

### 1.1 背景

项目全景页以**合同（项目）为中心**，默认以卡片形式浏览全部项目；点击卡片进入**全屏详情页**，查看合同、客户、过磅、结算及收付款的关联数据与业务链路。详情页各 Tab **仅供查看**，不支持在本页新建、编辑或删除业务数据；增删改请前往对应业务模块（合同管理、过磅台账、结算单、收付款等）。应收/应付为后台自动生成数据，**本页不展示往来 Tab**（菜单亦已隐藏）。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 列表页 | 页面标题 | 展示「项目全景」 |
| 列表页 | 关键词筛选 | 按合同编号、客户名称、单价摘要模糊匹配 |
| 列表页 | 合同状态筛选 | 按合同状态筛选，支持「全部」 |
| 列表页 | 类型筛选 | 筛选区内分段控件：全部 / 销售 / 采购，展示各类型数量 |
| 列表页 | 项目卡片 | 网格展示项目卡片（响应式 1–3 列） |
| 列表页 | 进入详情 | 点击卡片进入项目详情页（同一路由全屏展示） |
| 详情页 | 返回列表 | 合同编号前的图标返回按钮，回到卡片页 |
| 详情页 | 合同摘要头 | 展示合同号、类型、状态、客户、日期、履约进度 |
| 详情页 | 业务链路步骤 | 合同 → 过磅 → 收付款三步进度指示（数字 1–3） |
| 详情页 | 指标摘要 | 过磅单数、过磅金额、过磅净重、往来余额 |
| 详情页 | 详情 Tab | **基本信息**、过磅情况、结算记录、收付款记录（共 4 个 Tab，均为只读） |

| 详情 Tab | 过磅情况 | 关联磅单表格（只读）；可打开详情弹窗查看，不可编辑/删除/新建 |

| 详情 Tab | 应收/应付款 | **已隐藏**；往来仍由过磅自动生成，核销在收付款 |
| 详情 Tab | 收付款记录 | 关联收付表格（只读）；可打开详情弹窗查看，不可编辑/删除/新建 |

## 3. 模块需求说明

### 3.1 列表页：筛选与项目卡片

#### 布局

- 全宽页面：标题 + 筛选区（含类型分段控件）+ 结果计数 + 卡片网格
- 卡片网格：小屏 1 列（`sm` 起 2 列）、大屏 3 列（`xl`）
- 列表与详情为**两态切换**：列表态不展示详情；详情态不展示卡片网格

#### 项目卡片展示项

| 展示项 | 说明 |
| --- | --- |
| 类型 | 顶部 `StatusBadge`（采购靛蓝 / 销售橙色） |
| 合同编号 | 主标题 |
| 客户名称 | 副标题 |
| 合同状态 | 右上角状态标签 |
| 过磅金额 | 大号金额展示 |
| 履约进度 | 百分比 + 底部进度条（采购蓝 / 销售橙） |

> 卡片**无**左侧色条样式；类型以徽章展示。

#### 交互

- 点击整张卡片进入详情页
- **无**默认选中第一项；列表页不展示详情

#### 筛选查询区

筛选条件变更后**即时生效**；无独立「查询/重置」按钮。

| 筛选字段 | 类型 | 占位符 / 选项 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 「合同编号 / 客户」 | 对 `合同编号 + 客户名称 + 单价摘要` 拼接字符串做不区分大小写包含匹配 |
| 合同状态 | 下拉单选 | 全部、草稿、生效、履约中、已完成、已关闭 | 精确匹配 `contract.status` |

> 页面**无**结算状态、往来状态等筛选。

#### 类型筛选（筛选区内）

使用 `SegmentedControl`（`size="sm"`），与关键词、合同状态同处 `FilterBar`；控件宽度**随选项内容自适应**（不拉满整列，避免右侧留白）。

| 选项 | 内部值 | 说明 |
| --- | --- | --- |
| 全部 | `all` | 展示全部合同；标签含总数 |
| 销售 | `sale` | 仅展示销售合同；标签含该类型总数 |
| 采购 | `purchase` | 仅展示采购合同；标签含该类型总数 |

默认选中「全部」。在列表页切换类型仅过滤卡片；**当前原型未**在详情页切换类型时自动返回列表（若详情中合同被删除则会清空选中回到列表）。

#### 列表展示

列表上方展示：`共 {n} 条`（使用 `pagination.total` 文案）。

#### 列表排序

合同卡片按 **合同创建时间倒序**；创建时间相同时按 **合同编号倒序**（`buildContractTraces` 排序）。

#### 进入详情

| 行为 | 说明 |
| --- | --- |
| 点击卡片 | 进入该项目详情页（全宽 `ContractTracePanel`） |
| 默认选中 | **无**；列表页不自动进入详情 |
| 选中失效 | 若详情中合同被删除，展示未找到提示并可返回列表 |

#### 空列表

筛选后无合同时，展示统一空态「暂无数据」。

> 列表页**无分页**，超出区域随页面纵向滚动（`ui-page-scroll`，半透明 overlay 滚动条）。

### 3.2 详情页：合同全景（ContractTracePanel）

点击卡片进入详情页；摘要头合同编号**左侧**为图标返回按钮（样式对齐结算单预览页返回按钮）。切换合同时，详情 Tab **重置为「基本信息」**。

#### 3.2.1 摘要头部

全宽卡片：渐变顶栏 + 下方四列指标。

| 展示项 | 说明 |
| --- | --- |
| 返回 | 名称前方形边框图标按钮，返回项目列表 |
| 合同编号 | 主标题 |
| 合同类型 | 采购 / 销售标签 |
| 合同状态 | 状态徽章 |
| 客户名称 | 副标题 |
| 签订日期 | 右上 |
| 履约进度 | 右上百分比 |

#### 3.2.2 业务链路步骤条

三步水平进度指示（应收/应付步骤已隐藏）；步骤圆点之间为**连续连接线**（线自圆点中心贯通，圆点叠于线之上）。

| 步骤 | 标签 | 展示 | 完成条件 |
| --- | --- | --- | --- |
| 1 | 合同 | 圆圈内数字 **1** | 始终为已完成（实心品牌色） |
| 2 | 过磅 | 圆圈内数字 **2** | 存在至少 1 张**正常**磅单 |
| 3 | 收付款 | 圆圈内数字 **3** | 全部往来已结清 **或** 存在至少 1 条关联收付款 |

当前进行中步骤以描边高亮（`active`）展示；未完成步骤为灰色底。

#### 3.2.3 指标摘要行

四列指标：

| 指标 | 计算口径 |
| --- | --- |
| 过磅单数 | 正常状态磅单数量 `normalTicketCount` |
| 过磅金额 | 正常磅单 `amount` 合计 |
| 过磅净重 | 正常磅单 `netKg` 合计 |
| 余额 | 关联往来 `balance` 合计 |

### 3.3 详情 Tab：基本信息（只读）

合同信息与客户信息合并为单一 Tab「基本信息」，卡片**左对齐**、`max-w-3xl` 宽度限制；字段为**标签左、值右**的双列只读网格。

#### 工具栏

| 控件 | 说明 |
| --- | --- |
| 标题区 | 图标 +「基本信息」 |
| 编辑入口 | **无**（不提供「合同信息」「客户信息」编辑按钮） |

#### 区块一：合同信息

| 字段 | 说明 |
| --- | --- |
| 合同编号 | `contract.no` |
| 签订日期 | `contract.date` |
| 类型 | 采购 / 销售 |
| 合同状态 | 本地化状态名 |
| 约定重量 | `plannedKg` |

| 合同附件 | 有 `attachmentName` 时展示，否则不显示该行 |

#### 区块二：客户信息

与客户信息分标题展示，上方有分隔线。

**未关联客户主数据时**：虚线空态 + 说明文案（**无**「去关联客户」按钮；关联须在合同管理中完成）。

| 字段 | 说明 |

| 地址 | `customer.address`，无则 `-` |
| 关联合同数 | 该客户 ID 下合同总数 |

## 4. 交互设计

### 4.1 全局交互

- **布局**：卡片列表与详情**全屏切换**（同一路由两态），非左右分栏
- **滚动**：列表页与详情页内容区使用 `ui-page-scroll` 纵向滚动；滚动条为细窄半透明 overlay 样式
- **加载状态**：当前为前端 Mock 聚合，未体现独立 Loading
- **响应式**：卡片网格响应式列数；详情摘要头全宽，基本信息卡片限宽左对齐

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 即时筛选 | 关键词、状态、类型变更后立即过滤列表卡片 |
| 类型切换 | 列表页切换类型仅过滤结果；详情页切换类型**不自动**返回列表 |
| 无默认详情 | 进入页面不自动打开任一项目详情 |
| 切换合同重置 Tab | 选中不同合同时详情 Tab 回到「基本信息」 |
| Tab 角标 | 过磅、结算、收付款 Tab 展示关联条数 |
| 步骤条状态 | 根据磅单、往来、收付数据动态计算完成/进行中 |
| 详情只读 | 各 Tab **不可**增删改；仅可查看只读详情 / 预览 |

## 5. 数据模型与关联规则

### 5.1 核心聚合对象（ContractTrace）

| 字段 | 说明 |
| --- | --- |
| contract | 合同主记录 |
| customer | 匹配 `contract.customerId` 的客户，可为 null |
| tickets | 关联磅单列表 |
| settlements | 关联应收或应付列表 |
| settlementKind | `receivable`（销售）或 `payable`（采购） |
| payments | 通过核销摘要 / ticketBxNo 关联的收付款 |
| summary | 汇总指标（磅单数、金额、净重、往来合计、余额、履约百分比等） |

> 结算单列表由详情面板另行从 `weighSettlementDocs` 按合同过滤，不强制写入 `ContractTrace`。

### 5.2 关联规则一览

```text
磅单.contractNo = 合同.no
往来.ticketBxNo ∈ 合同下磅单.bxNo
收付款.ticketBxNo = bxNo 或 allocationSummary 包含 BX{bxNo}
结算单.contractId = 合同.id 或 contractNo = 合同.no
客户.id = 合同.customerId
```

### 5.3 指标计算口径

| 指标 | 公式 |
| --- | --- |
| 过磅金额 | Σ 正常磅单.amount |
| 过磅净重 | Σ 正常磅单.netKg |
| 往来总额 | Σ 关联往来.amount |
| 已结金额 | Σ 关联往来.settledAmount |
| 余额 | Σ 关联往来.balance |
| 履约进度 | min(100, fulfilledKg / plannedKg × 100)；plannedKg 为 0 时为 0% |

### 5.4 与业务需求文档的对应关系

一期项目需求文档约定以**合同为中心**串联过磅、往来、收付的端到端流程。

**当前原型差异（须在验收时知晓）：**

- 往来、收付款与磅单的关联为**演示级规则**（BX 号文本匹配），非严格业务核销引擎
- 磅单 → 往来**已自动**生成；收付 → 往来核销回写仍为演示级（未自动联动）
- 本页**不可**新建或编辑合同；仅只读展示
- 收付款关联依赖 `allocationSummary` / `ticketBxNo`，格式不一致时可能关联不到
- 作废磅单计入列表展示，但**不计入**过磅金额/净重汇总

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 列表态 | 未点击卡片 | 仅展示卡片网格与筛选 | — |
| 列表为空 | 筛选后无合同 | 空态「暂无数据」 | 调整筛选条件 |
| 详情合同不存在 | 选中 ID 无匹配合同 | 详情区「合同未找到」提示 | 可返回列表 |
| 客户未关联主数据 | customerId 无匹配 | 基本信息内客户区块空态（无跳转编辑） | 前往合同管理关联 |
| 无磅单 | 合同下无磅单 | 过磅 Tab 空态；步骤 2 为进行中 | 前往过磅台账新建 |
| 无结算单 | 合同下无结算单 | 结算 Tab「暂无结算记录」 | 前往结算单模块生成 |
| 无收付款 | 无匹配记录 | 收付款 Tab「暂无关联资料」 | 前往收付款模块新建 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏「项目全景」可进入 `/transactions` |
| 列表布局 | 卡片网格展示，非左右分栏 |
| 关键词筛选 | 可按合同编号、客户名、单价摘要片段过滤 |
| 状态筛选 | 合同状态下拉筛选准确 |
| 类型筛选 | 全部/销售/采购切换正确，数量准确 |
| 列表排序 | 按合同创建时间倒序 |
| 进入详情 | 点击卡片进入全屏详情，列表隐藏 |
| 无默认详情 | 进入页面不自动打开详情 |
| 返回列表 | 名称前返回按钮恢复卡片页 |
| 步骤条 | 三步完成/进行中状态与数据一致；连接线连续无大空隙 |
| 指标摘要 | 过磅单数、金额、净重、余额计算正确 |
| 基本信息 Tab | 合同 + 客户分区只读展示；无编辑按钮 |
| 过磅 Tab | 列与过磅台账一致；仅可查看，无新建/编辑/删除 |
| 结算 Tab | 展示本合同结算单；仅可查看预览，无新建/编辑/删除 |
| 收付款 Tab | 列与收付款页一致；仅可查看，无新建/编辑/删除 |
| 往来 Tab | **不存在**（已隐藏） |
| 切换合同 | 切换后详情 Tab 回到「基本信息」 |
| 只读约束 | 具备其他模块写权限的用户，在本页仍无法增删改 |
