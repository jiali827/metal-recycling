## 1. 引言

### 1.1 背景

项目全景页以**合同（项目）为中心**，默认以卡片形式浏览全部项目；点击卡片进入**全屏详情页**，查看合同、客户、过磅及收付款的关联数据与业务链路。应收/应付为后台自动生成数据，**本页不展示往来 Tab**（菜单亦已隐藏）。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 列表页 | 页面标题 | 展示「项目全景」 |
| 列表页 | 关键词筛选 | 按合同编号、客户名称、单价摘要模糊匹配 |
| 列表页 | 合同状态筛选 | 按合同状态筛选，支持「全部」 |
| 列表页 | 类型筛选 | 筛选区内分段控件：全部 / 销售 / 采购，展示各类型数量 |
| 列表页 | 项目卡片 | 网格展示项目卡片（响应式 1–3 列） |
| 列表页 | 进入详情 | 点击卡片进入项目详情页（同一路由全屏展示） |
| 详情页 | 返回列表 | 「返回项目列表」按钮回到卡片页 |
| 详情页 | 合同摘要头 | 展示合同号、类型、状态、客户、日期、履约进度 |
| 详情页 | 业务链路步骤 | 合同 → 过磅 → 收付款三步进度指示（数字 1–3） |
| 详情页 | 指标摘要 | 过磅单数、过磅金额、过磅净重、往来余额 |
| 详情页 | 详情 Tab | **基本信息**、过磅情况、收付款记录（共 3 个 Tab） |
| 详情 Tab | 基本信息 | 合并展示合同信息 + 客户信息，可分别打开编辑弹窗 |
| 详情 Tab | 过磅情况 | 关联磅单表格（字段与过磅台账列表一致），可新建/编辑/删除 |
| 详情 Tab | 应收/应付款 | **已隐藏**；往来仍由过磅自动生成，核销在收付款 |
| 详情 Tab | 收付款记录 | 关联收付表格（字段与收付款列表一致），可新建/编辑/删除 |

## 3. 模块需求说明

### 3.1 列表页：筛选与项目卡片

#### 布局

- 全宽页面：标题 + 筛选区（含类型分段控件）+ 结果计数 + 卡片网格
- 卡片网格：小屏 1 列（`sm` 起 2 列）、大屏 3 列（`xl`）
- 列表与详情为**两态切换**：列表态不展示详情；详情态不展示卡片网格

#### 项目卡片展示项

| 展示项 | 说明 |
| --- | --- |
| 类型 | 顶部 `StatusBadge`（采购靛蓝 / 销售橙色） |
| 合同编号 | 主标题 |
| 客户名称 | 副标题 |
| 合同状态 | 右上角状态标签 |
| 过磅金额 | 大号金额展示 |
| 履约进度 | 百分比 + 底部进度条（采购蓝 / 销售橙） |

> 卡片**无**左侧色条样式；类型以徽章展示。

#### 交互

- 点击整张卡片进入详情页
- **无**默认选中第一项；列表页不展示详情

#### 筛选查询区

筛选条件变更后**即时生效**；无独立「查询/重置」按钮。

| 筛选字段 | 类型 | 占位符 / 选项 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 「合同编号 / 客户」 | 对 `合同编号 + 客户名称 + 单价摘要` 拼接字符串做不区分大小写包含匹配 |
| 合同状态 | 下拉单选 | 全部、草稿、生效、履约中、已完成、已关闭 | 精确匹配 `contract.status` |

> 页面**无**结算状态、往来状态等筛选。

#### 类型筛选（筛选区内）

使用 `SegmentedControl` 分段控件，与关键词、合同状态同处 `FilterBar`。

| 选项 | 内部值 | 说明 |
| --- | --- | --- |
| 全部 | `all` | 展示全部合同；标签含总数 |
| 销售 | `sale` | 仅展示销售合同；标签含该类型总数 |
| 采购 | `purchase` | 仅展示采购合同；标签含该类型总数 |

默认选中「全部」。在列表页切换类型仅过滤卡片；**当前原型未**在详情页切换类型时自动返回列表（若详情中合同被删除则会清空选中回到列表）。

#### 列表展示

列表上方展示：`共 {n} 条`（使用 `pagination.total` 文案）。

#### 列表排序

合同卡片按 **合同创建时间倒序**；创建时间相同时按 **合同编号倒序**（`buildContractTraces` 排序）。

#### 进入详情

| 行为 | 说明 |
| --- | --- |
| 点击卡片 | 进入该项目详情页（全宽 `ContractTracePanel`） |
| 默认选中 | **无**；列表页不自动进入详情 |
| 选中失效 | 若详情中合同被删除，展示未找到提示并可返回列表 |

#### 空列表

筛选后无合同时，展示统一空态「暂无数据」。

> 列表页**无分页**，超出区域随页面纵向滚动（`ui-page-scroll`，半透明 overlay 滚动条）。

### 3.2 详情页：合同全景（ContractTracePanel）

点击卡片进入详情页；顶部有「返回项目列表」按钮。切换合同时，详情 Tab **重置为「基本信息」**。

#### 3.2.1 摘要头部

全宽卡片：渐变顶栏 + 下方四列指标。

| 展示项 | 说明 |
| --- | --- |
| 合同编号 | 主标题 |
| 合同类型 | 采购 / 销售标签 |
| 合同状态 | 状态标签 |
| 客户名称 | 副标题 |
| 签订日期 | 右上 |
| 履约进度 | 右上百分比 |

#### 3.2.2 业务链路步骤条

三步水平进度指示（应收/应付步骤已隐藏）：

| 步骤 | 标签 | 展示 | 完成条件 |
| --- | --- | --- | --- |
| 1 | 合同 | 圆圈内数字 **1** | 始终为已完成（实心品牌色） |
| 2 | 过磅 | 圆圈内数字 **2** | 存在至少 1 张**正常**磅单 |
| 3 | 收付款 | 圆圈内数字 **3** | 全部往来已结清 **或** 存在至少 1 条关联收付款 |

当前进行中步骤以描边高亮（`active`）展示；未完成步骤为灰色底。

#### 3.2.3 指标摘要行

四列指标：

| 指标 | 计算口径 |
| --- | --- |
| 过磅单数 | 正常状态磅单数量 `normalTicketCount` |
| 过磅金额 | 正常磅单 `amount` 合计 |
| 过磅净重 | 正常磅单 `netKg` 合计 |
| 余额 | 关联往来 `balance` 合计 |

### 3.3 详情 Tab：基本信息

合同信息与客户信息合并为单一 Tab「基本信息」，卡片**左对齐**、`max-w-3xl` 宽度限制；字段为**标签左、值右**的双列只读网格。

#### 工具栏

| 控件 | 说明 |
| --- | --- |
| 标题区 | 图标 +「基本信息」 |
| 「合同信息」 | 文本按钮，打开 `ContractDetailModal` 编辑当前合同 |
| 「客户信息」 | 仅当已关联客户主数据时显示，打开 `CustomerDetailModal` |

> 本 Tab **无**「+」新建客户；未关联客户时通过「去关联客户」引导打开合同编辑弹窗选择客户。

#### 区块一：合同信息

| 字段 | 说明 |
| --- | --- |
| 合同编号 | `contract.no` |
| 签订日期 | `contract.date` |
| 类型 | 采购 / 销售 |
| 合同状态 | 本地化状态名 |
| 约定重量 | `plannedKg` |
| 已履约重量 | `fulfilledKg` |
| 剩余约重 | `max(0, plannedKg - fulfilledKg)` |
| 单价摘要 | `unitPriceSummary` |
| 履约进度 | 细进度条 + 百分比 |
| 合同附件 | 有 `attachmentName` 时展示，否则不显示该行 |

#### 区块二：客户信息

与客户信息分标题展示，上方有分隔线。

**未关联客户主数据时**：虚线空态 + 说明文案 +「去关联客户」按钮（打开合同编辑）。

**已关联时只读字段**：

| 字段 | 说明 |
| --- | --- |
| 名称 | `customer.name` |
| 分类 | `customer.category` |
| 联系方式 | `customer.contact`，无则 `-` |
| 关联合同数 | 该客户 ID 下合同总数 |

> 客户区块**不展示**过磅单数、过磅金额、余额、对方客户等汇总字段（与 v1.3.0 文档不同）。

## 4. 交互设计

### 4.1 全局交互

- **布局**：卡片列表与详情**全屏切换**（同一路由两态），非左右分栏
- **滚动**：列表页与详情页内容区使用 `ui-page-scroll` 纵向滚动；滚动条为细窄半透明 overlay 样式
- **加载状态**：当前为前端 Mock 聚合，未体现独立 Loading
- **响应式**：卡片网格响应式列数；详情摘要头全宽，基本信息卡片限宽左对齐

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 即时筛选 | 关键词、状态、类型变更后立即过滤列表卡片 |
| 类型切换 | 列表页切换类型仅过滤结果；详情页切换类型**不自动**返回列表（与早期设计稿不同） |
| 无默认详情 | 进入页面不自动打开任一项目详情 |
| 切换合同重置 Tab | 选中不同合同时详情 Tab 回到「基本信息」 |
| Tab 角标 | 过磅、收付款 Tab 展示关联条数 |
| 步骤条状态 | 根据磅单、往来、收付数据动态计算完成/进行中 |
| 内嵌 CRUD | 详情 Tab 内可直接增删改关联业务，无需跳转独立列表页 |

## 5. 数据模型与关联规则

### 5.1 核心聚合对象（ContractTrace）

| 字段 | 说明 |
| --- | --- |
| contract | 合同主记录 |
| customer | 匹配 `contract.customerId` 的客户，可为 null |
| tickets | 关联磅单列表 |
| settlements | 关联应收或应付列表 |
| settlementKind | `receivable`（销售）或 `payable`（采购） |
| payments | 通过核销摘要 / ticketBxNo 关联的收付款 |
| summary | 汇总指标（磅单数、金额、净重、往来合计、余额、履约百分比等） |

### 5.2 关联规则一览

```text
磅单.contractNo = 合同.no
往来.ticketBxNo ∈ 合同下磅单.bxNo
收付款.ticketBxNo = bxNo 或 allocationSummary 包含 BX{bxNo}
客户.id = 合同.customerId
```

### 5.3 指标计算口径

| 指标 | 公式 |
| --- | --- |
| 过磅金额 | Σ 正常磅单.amount |
| 过磅净重 | Σ 正常磅单.netKg |
| 往来总额 | Σ 关联往来.amount |
| 已结金额 | Σ 关联往来.settledAmount |
| 余额 | Σ 关联往来.balance |
| 履约进度 | min(100, fulfilledKg / plannedKg × 100)；plannedKg 为 0 时为 0% |

### 5.4 与业务需求文档的对应关系

一期项目需求文档约定以**合同为中心**串联过磅、往来、收付的端到端流程。

**当前原型差异（须在验收时知晓）：**

- 往来、收付款与磅单的关联为**演示级规则**（BX 号文本匹配），非严格业务核销引擎
- 磅单 → 往来**已自动**生成；收付 → 往来核销回写仍为演示级（未自动联动）
- 本页**不可新建合同**，仅可编辑已有合同
- 收付款关联依赖 `allocationSummary` / `ticketBxNo`，格式不一致时可能关联不到
- 作废磅单计入列表展示，但**不计入**过磅金额/净重汇总

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 列表态 | 未点击卡片 | 仅展示卡片网格与筛选 | — |
| 列表为空 | 筛选后无合同 | 空态「暂无数据」 | 调整筛选条件 |
| 详情合同不存在 | 选中 ID 无匹配合同 | 详情区「合同未找到」提示 | 可返回列表 |
| 客户未关联主数据 | customerId 无匹配 | 基本信息内客户区块空态 + 去关联 | 打开合同编辑选客户 |
| 无磅单 | 合同下无磅单 | 过磅 Tab 空态；步骤 2 为进行中 | 可点击 + 新建 |
| 无收付款 | 无匹配记录 | 收付款 Tab「暂无关联资料」 | 可点击 + 新建 |
| 删除确认取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 权限不足 | 只读角色访问 | 未在页面或资料中体现 | 演示环境未实现 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |
