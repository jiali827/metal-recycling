## 1. 引言

### 1.1 背景

项目类型用于维护采购合同可选的「项目」主数据（名称 + 启用状态），替代原自由文本录入，统一口径并支持停用后不再新选。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「项目类型」 |
| 页面头部 | 新建项目类型 | 打开新建弹窗 |
| 筛选区 | 关键词 / 启用状态 | 即时组合筛选 |
| 数据列表 | 列表 | 名称、启用状态、审计时间；创建时间倒序 |
| 数据列表 | 行点击 / 行操作 | 详情、删除 |
| 新建弹窗 | 录入 | 名称（必填）、启用（默认启用） |
| 详情弹窗 | 编辑 | 弹窗内编辑；保存后提示「已保存」，不自动关闭 |
| 删除 | 确认后删除 | 允许删除；**不**改写已有采购合同的项目名称快照 |

### 2.1 页面菜单

## 3. 模块需求说明

### 3.1 筛选查询区

筛选即时生效；多条件 AND。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本 | 占位符「项目类型名称」 | 名称模糊、不区分大小写 |
| 启用状态 | 分段 | 全部 / 启用 / 停用 | 精确匹配 `enabled` |

### 3.2 数据列表

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 名称 | 加粗 | 否（整体按创建时间倒序） |
| 启用状态 | 启用蓝 / 停用红徽章 | 否 |
| 创建时间 / 更新时间 | 审计列 | 默认创建倒序 |
| 操作 | 详情、删除 | — |

- **分页**：未在页面或资料中体现（一次展示过滤结果）
- **批量操作**：未在页面或资料中体现
- **行操作**：详情打开弹窗；删除二次确认（文案含名称）后直接删除，不清空合同 `project`
- **行点击**：等效详情

### 3.3 新建 / 详情弹窗

| 子模块 | 触发 | 字段 | 按钮 | 关闭规则 |
| --- | --- | --- | --- | --- |
| 新建 | 页头按钮 | 名称*、启用（默认开） | 取消、保存 | 保存成功关闭并打开详情 |
| 详情 | 行点击/详情 | 同上 | 关闭、保存 | 保存后留在弹窗并提示已保存 |

**不含**采购/销售适用标志（与货物类型不同）。一期不强制名称唯一；下拉以名称为 value，运营应避免同名。

## 4. 与采购合同的关系

| 项 | 规则 |
| --- | --- |
| 控件 | 采购新建/编辑弹窗「项目」为可搜索下拉，选填 |
| 选项 | 仅 `enabled === true` |
| 存储 | `PurchaseContract.project?: string` 名称快照；无 `projectId` |
| 历史兜底 | 已选名称被停用或删除后，编辑该合同时仍补入选项以便展示/原样保存 |
| 销售合同 | 无项目字段 |

详见 `需求文档/合同管理.md`。

## 5. 状态与异常

| 场景 | 表现 |
| --- | --- |
| 空列表 | 公共表格空态 |
| 名称未填 | HTML required，不可提交 |
| 删除有引用 | 仍可删除；合同保留原项目文本 |

---

## 6. 验收标准

| 验收点 | 标准 |
| --- | --- |
| 菜单入口 | 主数据可见「项目类型」，可 CRUD |
| 启用筛选 | 停用项不出现在采购新建可选列表（历史兜底除外） |
| 删除策略 | 删除后已引用合同仍显示原名称 |
| 字段范围 | 仅名称 + 启用；无层级、无销售字段 |

---

## 7. 范围边界

- **本期包含**：列表、新建/详情、启用、删除策略 B、采购合同下拉数据源
- **本期不包含**：层级树、强制唯一、销售合同项目、删除拦截、OCR、导出分页
