## 1. 引言

### 1.1 背景

结算单按合同汇总未结算磅单，生成采购/销售结算快照，供打印签字；确认后锁定并作为收付款核销目标，列表直接展示核销进度。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「结算单」；**无副标题** |
| 页面头部 | 新建结算单 | 下拉选择「采购单 / 销售单」后打开对应新建弹窗 |
| 筛选区 | 单号 | 按结算单号模糊筛选，可清空 |
| 筛选区 | 类型 | 分段 Tab：全部 / 采购单 / 销售单；默认全部 |
| 筛选区 | 确认状态 | 分段 Tab：全部 / 待确认 / 已确认；默认全部 |
| 筛选区 | 核销状态 | 分段 Tab：全部 / 未核销 / 部分核销 / 已结清；默认全部 |
| 筛选区 | 客户 | 下拉筛选客户名称 |
| 筛选区 | 日期区间 | 按单据日期筛选，可清空 |
| 数据列表 | 结算单列表 | 单号、合同、类型、客户、日期、确认状态、净重/金额、已核销、余额、核销状态、附件、审计时间、操作 |
| 数据列表 | 行点击 | 进入预览打印页 |
| 数据列表 | 行操作（待确认） | 编辑、确认结算（审批印章图标）、删除 |

| 数据列表 | 附件列 | 弹窗上传/下载/替换/删除签字备份（单文件、不预览）；已确认仍可维护附件 |

| 核销进度 | 列表展示 | 已核销 / 余额 / 核销状态来自对应应收或应付目标；待确认显示 `—` |
| 新建弹窗 | 保存 / 保存并预览 | 保存回列表；保存并预览入库并进预览页 |
| 编辑弹窗 | 保存 / 保存并预览 | 仅待确认可编辑；已确认不可打开编辑 |
| 预览打印页 | 返回 / 打印 | 顶栏返回 + 打印；可重复打印，不因打印改确认状态 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需「查询」按钮；无独立「重置」按钮。单号与客户、日期等有值时可在控件内清空（分页条数下拉除外）。类型 / 确认状态 / 核销状态为分段 Tab，选项按文字自适应宽度，避免挤在固定窄栏内。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 单号 | 文本输入 | 可清空 | 结算单号不区分大小写包含匹配 |
| 类型 | 分段 Tab | 全部 / 采购单 / 销售单；默认全部 | 精确匹配 `kind` |
| 确认状态 | 分段 Tab | 全部 / 待确认 / 已确认；默认全部 | 精确匹配 `status`（`pending` / `confirmed`） |
| 核销状态 | 分段 Tab | 全部 / 未核销 / 部分核销 / 已结清；默认全部 | 精确匹配对应应收/应付目标的 `status`；无目标（待确认）的单据在选具体核销态时不命中 |
| 客户 | 下拉单选 | 全部 + 客户主数据与已有结算单客户并集 | 精确匹配 `customerName` |
| 日期区间 | 日期范围 | 可选、可清空 | 按单据日期 `docDate` 落在区间内 |

### 3.2 数据列表

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 单号 | 结算单号，加粗等宽数字 | 否 |
| 合同编号 | 绑定合同号；无则 `—` | 否 |
| 类型 | 采购单 / 销售单标签 | 否 |
| 客户 | 客户名称 | 否 |
| 日期 | 单据日期 | 否 |
| 确认状态 | 待确认 / 已确认 | 否 |
| 总净重 | 千分位格式化 | 否 |
| 总金额 | 金额格式（如 `HK$ …`） | 否 |
| 已核销 $ | 对应应收/应付目标已核销金额；无目标显示 `—` | 否 |
| 余额 $ | 对应目标余额；无目标显示 `—` | 否 |
| 核销状态 | 未核销 / 部分核销 / 已结清（及作废若有）；无目标显示 `—` | 否 |
| 附件 | 点击打开附件弹窗 | 否 |
| 创建时间 | 审计字段 | 是（默认倒序） |
| 更新时间 | 审计字段 | 否 |
| 操作 | 见行操作 | — |

#### 默认排序

筛选结果按 **创建时间倒序**。

#### 分页规则

- 列表底部统一分页控件
- 默认可切换每页条数：`10 / 20 / 50 / 100`（条/页下拉**无清空 X**）

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 确认状态 | 行操作 | 行为说明 |
| --- | --- | --- |
| 待确认 | 编辑 | 有编辑权限时打开编辑弹窗；图标为铅笔 |
| 待确认 | 确认结算 | 有编辑权限；审批印章图标；二次确认后锁定并生成应收或应付目标 |
| 待确认 | 删除 | 有删除权限；二次确认后删除；所含磅单可再次被汇总 |
| 已确认 | 查看 | 进入预览打印页；图标为眼睛 |
| 已确认 | 取消确认 | 有编辑权限且**尚无任何往来核销收付款**时展示；二次确认后恢复待确认并移除目标；有核销时**不展示**该按钮 |

无编辑权限时：待确认行可进预览查看；附件仅可下载（若有）。

#### 交互说明

- **行点击**（非操作列、非附件列）：进入 `/settlement-docs/[id]` 预览打印
- **附件列**：`stopPropagation`，不触发行跳转
- **导出**：未在页面或资料中体现

### 3.3 确认结算 / 取消确认

| 操作 | 前置 | 结果 |
| --- | --- | --- |
| 确认结算 | `status === pending`；有编辑权限 | `status → confirmed`；写入确认人/时间（演示）；销售生成应收目标、采购生成应付目标；金额 = 结算单合计；已核销初始为 0 |
| 取消确认 | `status === confirmed`；无关联往来核销收付款；有编辑权限 | `status → pending`；清除确认信息；移除对应未核销目标 |
| 取消确认失败 | 已有往来核销收付款 | 提示「该结算单已有收付款核销，无法取消确认」；状态不变 |

- **不强制**财务签字附件即可确认。
- 已确认后业务字段与磅单不可编辑；附件仍可上传/替换/删除。
- 打印与确认状态无关，两态均可打印。

### 3.4 弹窗：新建结算单

| 属性 | 说明 |
| --- | --- |
| 触发 | 页头「新建结算单」→ 下拉选采购单或销售单 |
| 标题 | 「新建采购单」或「新建销售单」（类型由入口决定，表单内不再展示类型字段） |
| 底部按钮 | 取消；**保存**（白底）；**保存并预览**（主题色） |

#### 基本信息

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 日期 | 日期选择 | 是 | 默认今天；用于单号日期段与打印抬头 |

#### 选择磅单

| 项 | 说明 |
| --- | --- |
| 筛选：合同 | 可搜索下拉，**非必填**；位于过磅日期区间**之前**；可清空表示「全部」；仅列出该方向下仍有可结算磅单的合同；展示 `合同编号 · 客户名` |
| 筛选：过磅日期区间 | 可选；控件内可清空；切换区间会清空已勾选并重置分页 |
| 默认列表 | 未选合同时展示该方向**全部**可结算磅单（正常、未占用、已挂合同） |
| 分页 | 每页 **10** 条；超过 10 条时表格底部分页翻页 |
| 列表列 | 勾选、磅单编号、过磅时间、车牌、货品描述、净重、金额 |
| 勾选 | 支持行点击整行勾选/取消；支持「全选当前列表」（跨页全选筛选结果） |
| 可结算磅单 | `status === normal`；未占用；方向与类型一致；已关联合同 |
| 汇总 | 已选张数、总净重、总金额 |

成单时根据**所选磅单**自动锚定合同（须同合同）；筛选区的合同选择仅用于缩小列表，**非保存必填**。

#### 成单规则

1. 一张结算单只绑**一个**合同；无合同磅单不可结算  
2. 所选磅单同方向、同客户，且与合同对方客户一致  
3. 同一磅单不可进入多张未删除结算单  
4. 单号：`PO-BX-yyyyMMddNN`（采购）/ `INV-BX-yyyyMMddNN`（销售）  
5. 成单默认确认状态为 **待确认**  
6. 校验失败用统一确认/提示弹窗，非 `window.alert`

#### 保存行为

| 按钮 | 行为 |
| --- | --- |
| 保存 | 校验通过 → 入库 → 关闭弹窗 → **停留列表** |
| 保存并预览 | 校验通过 → 入库 → 关闭弹窗 → 跳转 `/settlement-docs/{id}` |

## 4. 交互设计

### 4.1 全局交互

- 列表与弹窗基于本地 Mock 状态，无独立 Loading 骨架（除全局应用加载）
- 空列表展示统一空态
- 预览页主区贴顶无内边距，适配打印

### 4.2 特殊交互

- 新建入口先选采购/销售，弹窗标题体现类型，表单不再展示类型字段  
- 切换合同或过磅日期区间会清空磅单勾选并重置分页  
- 删除结算单后，原磅单可再次进入新结算单  
- 确认后列表即时出现应收/应付进度列；收付款登记核销后已核销/余额/核销状态回写  
- 有核销的已确认单不展示「取消确认」按钮

## 5. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空列表 | 无数据或筛选为空 | 表格空态 | 调整筛选或新建 |
| 无可结算磅单 | 筛选后无候选 | 「暂无未结算磅单」等 | 调整合同/日期筛选 |
| 校验失败 | 未选磅单/跨合同等同客户规则不符 | 提示弹窗 | 阻止保存 |
| 删除取消 | 确认框取消 | — | 数据不变 |
| 取消确认被拦 | 已有往来核销 | 提示无法取消确认 | 状态不变（按钮通常已隐藏） |
| 附件超限 | 文件 > 10MB | 提示 | 不写入 |
| 预览不存在 | id 无效 | 找不到提示 | 可回列表 |
| 无查看权限 | `canView` 为假 | 列表提示文案 | 无操作 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock |

## 6. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 入口 | 侧栏「结算单」进入列表；无单独应收应付菜单 |
| 筛选 Tab | 类型、确认状态、核销状态为分段 Tab，即时筛选 |
| 新建下拉 | 可选采购单/销售单并打开对应标题弹窗 |
| 成单 | 「保存」回列表；「保存并预览」入库并进预览；默认待确认 |
| 编辑 | 仅待确认可编辑；「保存」回列表，「保存并预览」进预览 |
| 确认结算 | 二次确认后锁定；销售出应收、采购出应付；列表出现核销进度 |
| 取消确认 | 无核销可取消并恢复可编辑；有核销不展示按钮（或提示拦截） |
| 列表列 | 含已核销、余额、核销状态；待确认为 `—` |
| 附件 | 列表上传/下载/替换/删除；不预览；不卡确认 |
| 预览 | 顶栏仅返回 + 打印；可重复打印不改确认状态 |
| 新建磅单区 | 默认展示全部可结算磅单；合同为可选筛选；每页 10 条可翻页 |
| 成单合同 | 保存时从所选磅单解析合同，无需先选筛选合同 |
| 删除 | 仅待确认可删；确认后磅单可再结算 |
| 过磅台账 | **无**多选生成结算单入口；正常磅单**不**再自动产生应收/应付 |

## 7. 范围边界

### 7.1 本期包含

- 侧栏结算单列表、分段 Tab 筛选、分页  
- 弹窗新建 / 编辑（合同 → 磅单）；保存与保存并预览  
- 确认结算 / 有条件取消确认；列表展示核销进度  
- 签字附件备份（单文件）  
- 预览打印版式（不记录打印状态）  
- 删除后磅单可再汇总  

### 7.2 本期不包含

- 独立应收账 / 应付账台账页（进度并入结算单）  
- 一笔收付款拆核多张结算单、超额收付
