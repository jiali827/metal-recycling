## 1. 引言

### 1.1 背景

客户页用于维护供应商与买家主数据，为合同、过磅、应收应付及收付款等模块提供统一的对方主体选择来源。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「客户」标题 |
| 页面头部 | 分类管理 | 跳转至 `/customers/categories` 客户分类管理页 |
| 页面头部 | 新建客户 | 打开「新建客户」弹窗 |
| 摘要条 | 往来摘要 | 默认展开；可收起/展开；状态写入 `localStorage`（`bx-customers-summary-expanded`）并在下次进入时恢复；展开时 6 卡同一行 |
| 筛选区 | 关键词筛选 | 按客户名称、联系方式模糊匹配 |
| 筛选区 | 分类筛选 | 按客户分类筛选，支持「全部」 |
| 数据列表 | 客户列表 | 表格展示客户核心字段、往来余额、结清状态与审计时间 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开客户详情/编辑弹窗 |
| 数据列表 | 行操作 | 支持「详情」「删除」 |
| 新建弹窗 | 客户录入 | 录入名称、联系方式、分类 |
| 新建弹窗 | 保存 | 校验必填项后保存，关闭弹窗并打开详情 |
| 详情弹窗 | 往来结清 | 只读展示该客户应收/应付余额与结清状态 |
| 详情弹窗 | 客户编辑 | 在弹窗内查看并编辑客户各字段 |
| 详情弹窗 | 保存反馈 | 保存成功后展示「已保存」提示，弹窗不自动关闭 |
| 删除 | 删除确认 | 删除前二次确认，确认后从列表移除 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「名称」 | 对「客户名称 + 联系方式」拼接字符串做不区分大小写的包含匹配 |
| 分类 | 下拉单选 | 选项：「全部」+ 分类主数据名称 + 客户记录中的孤立分类值（动态合并） | 精确匹配 `category` 字段；选「全部」时不限制 |

> 分类筛选项优先来自分类主数据（见 `需求文档/客户分类.md`）；若存在历史客户使用了不在主数据中的分类名称，筛选项仍会保留该名称以兼容孤立值。

### 3.2 数据列表

以表格形式展示客户记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 客户名称 | 客户/供应商名称，加粗展示 | 否 |
| 分类 | 客户分类，以色块标签展示 | 否 |
| 联系方式 | 联系人或电话等；无值时展示 `—` | 否 |
| 应收余额 | 该客户非作废应收 `balance` 合计 | 否 |
| 应付余额 | 该客户非作废应付 `balance` 合计 | 否 |
| 结清状态 | 无往来 / 未核销 / 部分核销 / 已结清 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的客户排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「客户详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含客户名称），确认后删除；若详情弹窗正在展示同一客户则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建客户

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建客户」按钮；亦可由合同全景页打开（见 3.6） |
| 弹窗标题 | 新建客户 |
| 弹窗尺寸 | 默认尺寸（未指定 `size` 属性） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 名称 Name | 文本输入 | 是 | 空 | 客户/供应商名称 |
| 联系方式 Contact | 文本输入 | 否 | 空 | 留空时不写入 `contact` 字段 |
| 分类 | 下拉单选 | 否 | 空（占位符「请选择」） | 选项来自分类主数据，见 `需求文档/客户分类.md` |

> 分类选项由「客户分类管理」页维护；本页**不提供**在弹窗内新增分类选项的入口，需通过「分类管理」按钮进入子页面维护。

#### 字段顺序

表单自上而下顺序为：**名称 → 联系方式 → 分类**。

#### 保存规则

- `contact` 为空时不保存该字段（`undefined`）
- 保存成功后关闭弹窗，并自动打开该客户详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

---

### 3.4 弹窗：客户详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「详情」、新建保存后自动打开 |
| 弹窗标题 | `客户详情 · {客户名称}` |
| 弹窗尺寸 | 默认尺寸 |

#### 表单字段

与新建弹窗相同（名称、联系方式、分类），无额外字段。

| 差异点 | 说明 |
| --- | --- |
| 数据回填 | 从已有客户记录加载；`contact` 为空时编辑框展示为空 |
| 保存行为 | 保存后不关闭弹窗，展示绿色「已保存」 |

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |
| 保存 | 提交表单 |

#### 记录不存在

当传入的客户 ID 不存在时，弹窗内容区展示「未找到记录」，底部仅保留「关闭」。

---

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 含客户名称的危险确认框 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一客户则关闭 |

> 当前原型删除客户**未校验**是否被合同、磅单、往来等引用；一期需求未在本页体现级联处理规则。

---

### 3.6 跨页面引用

客户主数据被以下模块只读引用（下拉选择），不在本页展示：

| 引用模块 | 用途 |
| --- | --- |
| 合同管理 | 对方客户选择 |
| 过磅台账 | 客户名称选择 |
| 应收账 | 客户选择 |
| 应付账 | 供应商选择（同一客户库） |
| 收付款 | 对方选择 |

项目全景页「基本信息」Tab 内客户区块可打开 `CustomerDetailModal` 查看/编辑当前合同关联客户，不在本页路由内。

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：当前为前端 Mock 数据，未体现独立 Loading
- **空状态**：筛选后无数据时表格展示统一空态
- **响应式**：弹窗为单列表单布局

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 即时筛选 | 关键词、分类变更后立即过滤列表 |
| 列表默认排序 | 按创建时间倒序 |
| 分类筛选项动态生成 | 合并分类主数据与客户记录中的孤立分类值 |
| 新建默认分类 | 每次打开新建弹窗，分类默认为空，需用户选择 |
| 删除与详情联动 | 删除当前查看的客户后，详情弹窗自动关闭 |

## 5. 数据模型（页面涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 系统内部主键 |
| name | string | 客户/供应商名称 |
| category | string | 分类名称（引用分类主数据 `name`） |
| contact | string? | 联系方式，可选 |
| createdAt | string | 创建时间（ISO 8601） |
| updatedAt | string | 更新时间（ISO 8601） |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 客户/供应商：名称、分类（出口/船/大判/分判/中商/行家等，可配）、联系方式
- 作为基础参数，供全业务链路引用

**当前原型差异（须在验收时知晓）：**

- 分类已通过「客户分类管理」子页面维护，**非**固定枚举下拉（详见 `需求文档/客户分类.md`）
- **无**客户编码、地址、税号等扩展字段
- **无**启用/停用状态
- 删除时**无**引用检查与级联保护

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无客户 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 名称为空保存 | 浏览器原生校验 | 阻止提交 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 删除被引用客户 | 客户已被合同等引用 | 未在页面或资料中体现 | 当前允许直接删除 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏「客户」可进入 `/customers`，标题为「客户」 |
| 列表展示 | 正确展示客户名称、分类、联系方式、应收/应付余额、结清状态、创建/更新时间 |
| 联系方式空值 | 无联系方式时列表显示 `—` |
| 列表排序 | 默认按创建时间倒序 |
| 关键词筛选 | 可按名称/联系方式片段过滤 |
| 分类筛选 | 动态分类选项筛选准确；「全部」显示全部 |
| 分类管理入口 | 点击「分类管理」进入 `/customers/categories` |
| 分页 | 超过 10 条时分页正常 |
| 新建默认值 | 分类为空，名称与联系方式为空 |
| 新建必填 | 名称为空无法保存 |
| 分类选项 | 新建/编辑下拉选项与分类主数据一致 |
| 新建保存 | 保存后自动打开详情 |
| 详情编辑 | 可修改各字段并保存，展示已保存提示 |
| 删除确认 | 删除前确认，确认后记录消失 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 客户列表、即时筛选、创建时间倒序、分页
- 弹窗式新建 / 详情编辑
- 名称、分类、联系方式三个核心字段
- 分类主数据联动（维护入口见 `需求文档/客户分类.md`）
- 单条删除与二次确认
- 作为其他业务模块的下拉数据源

### 8.2 本期不包含（页面或资料未体现）

- 客户编码、地址、银行账户等扩展信息
- 启用/停用、黑名单状态
- 删除前引用检查
- 客户维度往来余额/统计视图
- 导出、批量操作、列头排序
- 后端 API、权限按钮级控制
