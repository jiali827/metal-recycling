## 1. 引言

### 1.1 背景

客户分类页用于维护客户分类主数据，为客户的建档、编辑与列表筛选提供统一的分类名称来源。分类重命名时同步更新已引用该名称的客户记录；当分类仍被客户引用时禁止删除。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面导航 | 面包屑 | 展示「客户 / 分类管理」，「客户」可返回客户列表页 |
| 页面头部 | 新建分类 | 打开「新建分类」弹窗 |
| 数据列表 | 分类列表 | 表格展示分类名称、客户数、审计时间，默认按创建时间倒序 |
| 数据列表 | 客户数统计 | 展示当前 `category` 字段等于该分类名称的客户数量 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开「编辑分类」弹窗 |
| 数据列表 | 行操作 | 支持「编辑」「删除」 |
| 新建弹窗 | 分类录入 | 录入分类名称 |
| 新建弹窗 | 保存 | 校验必填项与重名后保存，关闭弹窗并刷新列表 |
| 编辑弹窗 | 分类编辑 | 修改分类名称；有关联客户时提示将同步更新 |
| 编辑弹窗 | 重命名联动 | 保存成功后批量更新引用该分类名称的客户记录 |
| 删除 | 引用校验 | 有关联客户时弹出「无法删除」说明，不执行删除 |
| 删除 | 删除确认 | 无关联客户时二次确认，确认后从列表移除 |

## 2. 页面菜单与权限规划

### 2.1 页面菜单

**菜单路径**：客户 → 分类管理（二级功能页，不在侧边栏单独展示）

**路由地址**：`/customers/categories`

**入口**：客户列表页（`/customers`）右上角「分类管理」按钮

> 说明：侧边栏主数据分组仅展示「客户」菜单项；分类管理作为客户模块的子页面，通过面包屑与按钮进入。

### 2.2 权限规划

| 权限点 | 操作范围 | 数据范围 |
| --- | --- | --- |
| 查看 | 查看分类列表、客户数、创建/更新时间 | 全量（演示环境未做租户/个人隔离） |
| 编辑 | 新建分类、编辑分类名称、删除无引用分类 | 全量 |
| 导出 | 未在页面或资料中体现 | — |

> 一期项目需求文档约定合同管理员、过磅人员对客户主数据为只读；分类管理与客户页同属客户主数据维护范畴。当前原型未在页面层实现按钮级权限控制，登录用户均可编辑。

## 3. 模块需求说明

### 3.1 筛选查询区

未在页面或资料中体现。

本页不提供关键词筛选、查询/重置按钮。

### 3.2 数据列表

以表格形式展示客户分类主数据，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 分类名称 | 分类主数据名称，加粗展示 | 否 |
| 客户数 | 当前 `category` 字段等于该分类名称的客户记录数量 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 编辑、删除 | — |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的分类排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 分页文案包含总条数、当前展示范围、当前页/总页数

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 编辑 | 打开「编辑分类」弹窗，回显当前分类名称 |
| 删除 | 先校验客户数；有引用则弹出「无法删除」说明；无引用则弹出危险确认框（确认文案含分类名称），确认后删除；若编辑弹窗正在展示同一分类则关闭编辑态 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「编辑」
- **操作列固定**：操作列固定在表格右侧；仅当表格产生横向滚动时，操作列左侧显示分隔竖线与阴影
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建分类

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建分类」按钮 |
| 弹窗标题 | 新建分类 |
| 弹窗尺寸 | 默认尺寸（未指定 `size` 属性） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 分类名称 | 文本输入 | 是 | 空 | 提交前去除首尾空格；不能与已有分类名称重复 |

#### 字段顺序

表单仅包含 **分类名称** 一个字段。

#### 校验规则

- 名称 trim 后不能为空，否则提示「请输入分类名称」
- 不能与已有分类名称重复，否则提示「分类名称已存在」

#### 保存规则

- 保存成功后关闭弹窗，新记录插入列表并按创建时间倒序展示

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.4 弹窗：编辑分类

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「编辑」 |
| 弹窗标题 | `编辑分类 · {分类名称}` |
| 弹窗尺寸 | 默认尺寸 |

#### 表单字段

与新建弹窗相同（分类名称），无额外字段。

| 差异点 | 说明 |
| --- | --- |
| 数据回填 | 从已有分类记录加载当前名称 |
| 关联提示 | 当客户数 > 0 时，表单下方展示：「修改名称将同步更新 {count} 个客户的分类」 |
| 重命名联动 | 保存且名称变更时，将所有客户记录中 `category` 等于旧名称的记录批量更新为新名称 |

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗 |
| 保存 | 提交表单 |

### 3.5 删除确认与拦截

#### 无法删除（客户数 > 0）

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」，且该分类下客户数 > 0 |
| 弹窗标题 | 无法删除分类 |
| 弹窗内容 | 该分类下还有 {count} 个客户，无法删除。请先将这些客户改到其他分类。 |
| 按钮 | 关闭、确定（均为关闭说明，不执行删除） |

#### 删除确认（客户数 = 0）

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」，且该分类下客户数 = 0 |
| 确认内容 | 含分类名称的危险确认框 |
| 确认后 | 从列表移除；若编辑弹窗正在展示同一分类则关闭 |

> 当前策略为 **禁止删除有引用的分类**，不会自动清空客户的 `category` 字段。

### 3.6 跨页面引用

客户分类主数据被以下场景引用：

| 引用模块 | 用途 | 规则 |
| --- | --- | --- |
| 客户列表 | 分类筛选项 | 来源于分类主数据；若存在历史客户使用了不在主数据中的分类名称，筛选项仍会保留该名称（兼容孤立值） |
| 客户新建/编辑 | 分类下拉选项 | 仅来自分类主数据；新建客户时分类默认为空（需用户选择） |
| 客户记录 | `category` 字段 | 存储分类名称字符串；分类重命名时由本页保存逻辑级联更新 |

详见 `需求文档/客户.md`。

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：当前为前端 Mock 数据，未体现独立 Loading
- **空状态**：分类列表为空时表格展示统一空态
- **响应式**：表格容器支持横向滚动；操作列在滚动时固定于右侧

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 面包屑返回 | 点击「客户」返回 `/customers` 客户列表页 |
| 重命名级联 | 编辑保存成功后，关联客户的 `category` 字段同步变更，无需逐条修改 |
| 删除拦截 | 删除有关联客户的分类时，不弹出删除确认，而是弹出「无法删除」说明框 |
| 操作列分隔线 | 仅表格出现横向滚动时，在操作列左侧显示分隔竖线与阴影 |
| 编辑与删除联动 | 删除当前正在编辑的分类后，编辑弹窗自动关闭 |

## 5. 数据模型（页面涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 系统内部主键 |
| name | string | 分类名称（唯一） |
| createdAt | string | 创建时间（ISO 8601） |
| updatedAt | string | 更新时间（ISO 8601） |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 客户分类：出口/船/大判/分判/中商/行家等，**可配**
- 作为基础参数，供客户建档与筛选引用

**当前原型差异（须在验收时知晓）：**

- **无**分类编码、排序号、启用/停用状态、备注等扩展字段
- **无**筛选查询区、列头排序、导出/导入、批量操作
- 删除有引用分类时**禁止删除**，而非自动清空客户分类字段
- 侧边栏**无**独立「客户分类」菜单项

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 分类主数据为空 | 表格空态 | 可通过「新建分类」新增 |
| 名称为空 | 保存时分类名称 trim 后为空 | 红色提示「请输入分类名称」 | 阻止保存 |
| 名称重复 | 保存时与已有分类重名 | 红色提示「分类名称已存在」 | 阻止保存 |
| 删除被拦截 | 删除时客户数 > 0 | 「无法删除分类」说明弹窗 | 不删除分类记录 |
| 删除确认 | 删除时客户数 = 0 | 标准危险确认框 | 用户确认后删除 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 客户列表页点击「分类管理」进入 `/customers/categories`；面包屑显示「客户 / 分类管理」 |
| 列表展示 | 正确展示分类名称、客户数、创建/更新时间 |
| 客户数 | 「客户数」等于当前系统中 `category` 字段匹配该分类名称的客户数量 |
| 列表排序 | 默认按创建时间倒序 |
| 分页 | 超过 10 条时分页正常，文案正确展示总数与范围 |
| 新建分类 | 名称为空不可保存；重名提示「分类名称已存在」；保存成功后列表出现新记录 |
| 编辑分类 | 点击行或编辑打开弹窗并回显名称；有关联客户时展示同步更新提示 |
| 重命名联动 | 修改分类名称并保存后，所有原使用该分类的客户记录 `category` 同步为新名称 |
| 删除拦截 | 客户数 > 0 时点击删除，弹出「无法删除分类」说明，分类不被删除 |
| 删除成功 | 客户数 = 0 时，确认删除后该分类从列表消失，且不再出现在客户表单的分类下拉中 |
| 操作列样式 | 表格无横向滚动时操作列前无竖线；产生横向滚动时操作列固定且显示分隔竖线 |
| 与客户模块联动 | 客户新建/编辑页的分类下拉与分类主数据一致；客户列表分类筛选项包含主数据分类 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 客户分类主数据的列表、新建、编辑、删除（含引用校验）
- 分类重命名对客户记录的同步更新
- 与客户新建/编辑/筛选的分类数据联动
- 面包屑导航、分页、行操作、编辑/删除确认弹窗

### 8.2 本期不包含（页面或资料未体现）

- 筛选查询区、列头排序切换、导出/导入、批量操作
- 分类启用/停用、排序权重、分类编码、备注
- 侧边栏独立菜单项（分类管理仅作为客户模块子页面）
- 删除有引用分类后自动清空客户分类字段
- 权限按钮级控制、后端 API 错误处理
