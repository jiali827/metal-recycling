## 1. 引言

### 1.1 背景

过磅台账页用于录入与管理电子磅单，对齐现场纸质 BX 单号与重量数据，并支持关联合同自动带出客户、方向、货物类型与单价。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「过磅台账」标题 |
| 页面头部 | 新建磅单 | 打开「新建磅单」弹窗 |
| 筛选区 | 关键词筛选 | 按 BX 单号、客户、车牌、货物类型模糊匹配 |
| 筛选区 | 方向筛选 | 按采购/销售筛选，支持「全部」 |
| 筛选区 | 状态筛选 | 按正常/作废筛选，支持「全部」 |
| 数据列表 | 磅单列表 | 表格展示磅单核心字段与审计时间，默认按创建时间倒序 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开磅单详情/编辑弹窗 |
| 数据列表 | 行操作 | 支持「详情」「删除」 |
| 新建弹窗 | 基本信息 | 展示系统自动生成的单号 BX；录入车牌、关联合同、客户、货物类型、方向 |
| 新建弹窗 | 过磅数据 | 录入总重/皮重/扣减/单价，自动计算净重与金额，录入过磅时间 |
| 新建弹窗 | 合同联动 | 关联有效合同时自动带出并锁定部分字段 |
| 新建弹窗 | 补充备注 | 可选填写货柜号、付款状态等自由文本备注 |
| 新建弹窗 | 保存 | 校验必填项后保存，状态默认为「正常」，并打开详情 |
| 详情弹窗 | 磅单编辑 | 在弹窗内查看并编辑磅单各字段 |
| 详情弹窗 | 作废 | 可将状态改为「作废」 |
| 详情弹窗 | 保存反馈 | 保存成功后展示「已保存」提示，弹窗不自动关闭 |
| 删除 | 删除确认 | 删除前二次确认，确认后从列表移除 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「BX / 客户 / 车牌」 | 对「BX 单号 + 客户名 + 车牌 + 货物类型摘要」拼接字符串做不区分大小写的包含匹配 |
| 方向 | 下拉单选 | 枚举：全部、采购、销售；默认「全部」 | 精确匹配 `direction` 字段 |
| 状态 | 下拉单选 | 枚举：全部、正常、作废；默认「全部」 | 精确匹配 `status` 字段 |

### 3.2 数据列表

以表格形式展示磅单记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 单号 BX | 磅单业务编号，加粗、等宽数字展示 | 否 |
| 方向 | 采购 / 销售，以色块标签展示 | 否 |
| 过磅时间 | 过磅具体时间，精确到分钟（如 `2026-07-23 09:15`） | 否 |
| 客户 | 客户名称 | 否 |
| 车牌 | 车牌号；未填时存储为 `-` | 否 |
| 货物类型 | 货物类型摘要文本 | 否 |
| 净重 KG | 净重，千分位格式化整数 | 否 |
| 金额 ($) | 金额，格式如 `HK$ 41,478.5` | 否 |
| 合同编号 | 关联合同编号；未关联时显示 `-` | 否 |
| 状态 | 正常 / 作废，以色块标签展示 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

> 列表**不展示**备注字段；备注仅在新建/详情弹窗中维护。

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的磅单排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「磅单详情」弹窗 |
| 删除 | 弹出危险确认框（标题含 `BX{单号}`），确认后删除；若详情弹窗正在展示同一磅单则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建磅单

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建磅单」按钮；亦可由合同全景页带预设参数打开（见 3.6） |
| 弹窗标题 | 新建磅单 |
| 弹窗尺寸 | 超大号（xl） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单分区与字段

**分区一：基本信息**

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 单号 BX | 只读展示 | — | 打开弹窗时按流水号规则预分配；保存时再次取号 | 系统自动生成 5 位流水号，不可修改；与纸质单号对齐核对 |
| 车牌 Truck No. | 文本输入 | 否 | 空；占位符如 `SD3117` | 保存时空值记为 `-` |
| 关联合同 | 可搜索下拉 | 否 | 默认「不关联合同」 | 选项含全部合同，格式 `{编号} · {客户名}` |
| 客户 | 可搜索下拉 | 是 | 默认客户列表第一项 | 关联合同时禁用并自动带出 |
| 货物类型 | 下拉单选 | 是 | 默认货物类型列表第一项（如 AA） | 关联合同时禁用并自动带出 |
| 方向 | 分段按钮 | 否 | 默认「采购」 | 采购/销售；关联合同时禁用并自动带出 |

选择有效关联合同后，基本信息区下方展示提示文案：「已关联合同，客户、方向、货物类型与单价由合同带出且不可修改」。

**分区二：过磅数据**

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 总重 Gross (KG) | 数字输入 + KG 单位 | 是 | 默认 `30000` | 可编辑 |
| 皮重 Tare (KG) | 数字输入 + KG 单位 | 是 | 默认 `20000` | 可编辑 |
| 扣减 Deduction (KG) | 数字输入 + KG 单位 | 否 | 默认 `0` | 取绝对值参与计算 |
| 单价 Unit Price ($) | 数字输入 + HK$/KG 单位 | 是 | 默认 `2.3`；步进 `0.01` | 关联合同时禁用并自动带出 |
| 净重 Net (KG) | 只读展示区 | — | 实时计算 | 展示净重，千分位格式化 |
| 金额 Amount ($) | 只读展示区 | — | 实时计算 | 展示金额，格式 `HK$ {amount}` |
| 过磅时间 | 日期时间选择器 | 是 | 默认当前本地时间（精确到分钟） | 格式 `YYYY-MM-DDTHH:mm`，可修改 |

**净重与金额计算规则（前端实时）：**

```
净重 = max(0, 总重 − 皮重 − |扣减|)
金额 = 净重 × 单价
```

**分区三：补充信息**

| 字段 | 控件类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 备注（可选） | 多行文本 | 否 | 自由文本；占位符示例：「已付现金、货柜号 FCIU6185730、PNS:218050 KG」 |

#### 合同联动规则

当用户选择列表中存在的合同时：

| 自动带出字段 | 来源 | 是否锁定 |
| --- | --- | --- |
| 方向 | 合同类型（采购/销售） | 是 |
| 客户 | 合同对方客户名 | 是 |
| 货物类型 | 合同单价摘要第一段解析出的货物类型名 | 是 |
| 单价 | 合同单价摘要第一段解析出的数值 | 是 |

解析规则示例：`工字 $2.45` → 货物类型「工字」、单价 `2.45`；`AA $2.30 / AA+A $2.20` → 取第一段。

切换为「不关联合同」后，上述字段恢复可编辑，但**不自动清空**已填内容。

#### 单号 BX 生成规则

| 规则项 | 说明 |
| --- | --- |
| 格式 | 5 位数字字符串，不足前补零（如 `02514`） |
| 分配算法 | 取当前租户内全部磅单 `bxNo` 可解析数字的最大值 +1，格式化为 5 位 |
| 新建弹窗 | 打开时预展示下一流水号；提交保存时再次计算，避免长时间打开弹窗导致重复 |
| 详情弹窗 | 只读展示，保存时不提交 `bxNo`，不可修改 |
| 唯一性 | 租户内 BX 单号唯一（与一期 R05 一致） |
| 作废重录 | 作废单保留原 BX 号；重录新单使用新的流水号（与纸质新单一致） |

字段下方提示文案（i18n `form.bxNoAutoHint`）：「系统自动生成 5 位流水号，不可修改」。

#### 保存规则

- 新建磅单 `status` 固定为 **正常（normal）**
- `contractNo` 未关联时存为 `-`
- 保存成功后关闭弹窗，并自动打开该磅单详情弹窗
- **同时自动生成往来**：销售方向 → 应收；采购方向 → 应付（一对一，已核销=0，状态=未核销）

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：当前为前端 Mock 数据，未体现独立 Loading
- **空状态**：筛选后无数据时表格展示统一空态
- **响应式**：弹窗表单采用网格布局，大屏多列、小屏自适应

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 即时筛选 | 关键词、方向、状态变更后立即过滤列表 |
| 列表默认排序 | 按创建时间倒序；新建磅单出现在列表最前（符合当前筛选时） |
| 净重金额联动 | 修改总重/皮重/扣减/单价时，净重与金额字段实时刷新 |
| 合同锁定 | 仅当所选合同编号在合同库中存在时触发锁定；手工输入无效编号不锁定 |
| 过磅时间默认值 | 每次打开新建弹窗重置为当前本地时间（精确到分钟） |
| 单号 BX 自动生成 | 新建弹窗打开时预分配下一流水号；保存时再次取号；详情不可改单号 |
| 删除与详情联动 | 删除当前查看的磅单后，详情弹窗自动关闭 |

### 状态枚举

| 值 | 展示文案 |
| --- | --- |
| normal | 正常 |

### 与业务需求文档的对应关系

一期项目需求文档（`docs/金属回收管理系统-一期项目需求文档.md`）中约定：

- 过磅须挂合同，单价来自合同且过磅页不可改
- 净重 = 总重 − 皮重 − |扣减|
- 采购/销售方向决定应付/应收类型
- 已保存磅单改关键字段须作废重录；备注可改
- 仅「生效/履约中」合同可被选入过磅

**当前原型差异（须在验收时知晓）：**

- **BX 单号**由系统按 5 位流水号自动生成，新建/详情均不可手改；一期项目文档中「手工录入纸质单号对齐」在正式环境可能仍需支持覆盖录入
- **允许不关联合同**保存（`contractNo` 为 `-`），未强制 R01
- 关联合同后锁定单价，但**未关联时单价可手填**
- **未实现**多货物类型明细行，仅单一货物类型摘要 + 单一单价
- **已实现**保存正常磅单后自动生成应收（销售）/应付（采购），一对一
- **已实现**作废/删除磅单时联动作废或删除未核销往来（演示简化，未做核销阻断）
- **未实现**更新合同履约量
- **未实现**作废前校验收付款核销并阻断
- **未实现**仅允许选择「生效/履约中」合同
- **未实现**地磅 COM 读数、纸质单打印对接

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无磅单 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 保存时必填为空 | 浏览器原生校验 | 阻止提交 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 无合同保存 | 未选关联合同点保存 | 允许保存 | 与一期 R01 目标不一致，属原型简化 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |
