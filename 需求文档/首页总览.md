## 1. 引言

### 1.1 背景

首页总览为登录后的默认经营看板，聚合过磅、应收应付、收付款及租户期初现金数据，以 KPI 指标卡、趋势图、排行榜与摘要表格等形式，为老板与财务提供经营与资金的一屏总览。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「首页总览」 |
| 页面头部 | 时间范围分段 | 自定义 / 今日 / 本周 / 本月（自定义在前；默认本月） |
| 页面头部 | 自定义区间 | 仅选「自定义」时显示双月 `DateRangePicker`，一次点选起止 |
| KPI 指标卡 | 销售额 / 采购额 / 毛利 / 过磅车次 | 按所选区间过滤正常磅单；含环比与同比，标签区分 |
| 趋势图 | 销售 vs 采购 | 所选区间逐日销售/采购金额双折线 |
| 饼图 | 货物类型购销 | 按货类合计占比（销售+采购）；金额/净重 Tab；与趋势图并排 |
| 排行榜 | 客户往来 Top | 区间内正常磅单金额 Top 5 + 蓝色进度条 |
| 仪表盘 | 结算概况 | 结清率环图 + 已结/总额 + 应付结清率条 + 应收/应付余额 |
| 摘要表 | 近日过磅摘要 | 区间内按日期降序最多 6 条正常磅单 |
| 资金快览 | 资金指标 | 结余主指标 + 区间收付 2×2（现金流） |
| 展示动效 | 入场 / 计数 / 图表 | 切换区间时重播；尊重 `prefers-reduced-motion` |

## 3. 模块需求说明

### 3.1 页面头部与时间范围

| 元素 | 说明 |
| --- | --- |
| 标题 | 「首页总览」 |
| 分段控件 | 顺序：**自定义 → 今日 → 本周 → 本月**；默认选中**本月** |
| 区间选择器 | 仅「自定义」时出现在分段**左侧** |
| 联动 | 点「自定义」：以当前区间初始化选择器；点预设 Tab：隐藏选择器并按规则重算 |

#### 时间范围规则

| 预设 | 起止规则 |
| --- | --- |
| 今日 | 锚点日当天 |
| 本周 | 锚点日所在自然周（周一至周日） |
| 本月 | 锚点日所在自然月 |
| 自定义 | 用户选定起止日（含边界）；图表逐日展开最长约 **93** 天 |

> **演示锚点**：以过磅/收付款业务数据的**最晚业务日**为「今日」，避免种子数据与真实日历错位导致空白。

#### DateRangePicker 交互（自定义）

| 项 | 说明 |
| --- | --- |
| 形态 | 双月并排；周一起始；支持 `<< < > >>` 翻年/翻月 |
| 选区 | 第一次点开始，第二次点结束；起止可对调；同日可选 |
| 高亮 | 起止实心品牌色，中间浅色填充；**格子无缝，区间色带连续** |
| 提示 | 选开始前：「先点选开始日期」；选结束后：「再点选结束日期」 |
| 完成 | 选定结束日后关闭面板并驱动看板重算 |

实现：`web/src/components/ui/forms/DateRangePicker.tsx`

#### 范围对指标的影响

| 模块 | 过滤规则 |
| --- | --- |
| KPI（销售/采购/毛利/车次） | 正常磅单，业务日落在 `[start, end]` |
| 趋势图 / 客户 Top / 近日过磅 / 货类饼图 | 同上（趋势用逐日序列） |
| 已收款 / 已付款 / 杂项收付 | 收付款业务日落在区间内 |
| 现金结余 | `openingCash` + 业务日 **≤ end** 的累计收款 − 同期累计付款 |
| 应收/应付余额、结清率 | 往来单据业务日落在区间内 |

### 3.2 KPI 指标卡（第一行，4 列）

数据来源：Mock Store 中 `status === "normal"` 且落在区间内的磅单。

| 指标卡 | 主值 | 辅助信息 | 环比 | 同比 |
| --- | --- | --- | --- | --- |
| 销售额 | 销售方向 `amount` 合计 | — | 区间日序列**后半段 vs 前半段**金额变化率 | 当前区间合计 vs **去年同日起止**销售合计 |
| 采购额 | 采购方向 `amount` 合计 | — | 同上（采购序列） | 同上（采购） |
| 毛利概览 | 销售额 − 采购额 | 「销售 − 采购」 | 同上（毛利序列） | 同上（毛利） |
| 过磅车次 | 正常磅单条数 | `{采购净重} / {销售净重} KG` | 区间日车次前后半段变化率 | 同上（车次） |

#### 环比 / 同比展示

- 卡片底部独立对比条：顶部分隔线 + **两列等分**（左环比、右同比）
- 列内结构：上方灰色小标签（环比 / 同比 或 MoM / YoY），下方彩色百分比（正绿负红），右列右对齐，避免两枚同形徽章难以分辨
- 辅助说明（如「销售 − 采购」、净重）放在主值下方，不与对比条混排
- 对比基数为 0 且本期 > 0 → 按 100%
- **环比**基于当前所选区间展开的日序列前后半段，而非固定近 7 日
- **同比**为所选 `[start, end]` 与 `[start-1年, end-1年]` 的 KPI 合计变化率；Mock 含少量 2025-07 磅单供演示

#### 展示动效

| 区域 | 动效 |
| --- | --- |
| KPI | 错落入场；主值计数；图标轻弹；悬停微抬 |
| 折线 | 描边绘制 + 区域淡入 + 端点弹出 |
| 货类饼图 | 入场缩放 |
| 客户 Top | 进度条自左生长 |
| 结算仪表盘 | 环形扫弧 |
| 资金快览 | 区块错落入场 |
| 卡片 | `dash-reveal` 上浮，延迟递增 |

**重播**：区间起止变化时以 `{start}_{end}` 为 key 重播。  
**无障碍**：`prefers-reduced-motion: reduce` 时直接终态。

### 3.3 销售 vs 采购趋势

| 属性 | 说明 |
| --- | --- |
| 标题 | 销售 vs 采购趋势 |
| 图例 | 销售（品牌色）、采购（强调色） |
| 类型 | SVG 双折线 + 销售区域填充 |
| 区间 | 跟随头部所选区间逐日展开 |
| X 轴 | `月/日`；天数多时抽稀标签 |
| 样式 | 细线（约 1.6）、小圆点；与右侧货类饼图并排（左宽右窄） |

#### 数据聚合

- 按磅单日期归入自然日
- 销售累加 `amount` → sales；采购累加 → purchase

#### 演示补全

当区间天数 > 1 且**有实际数据的天数 ≤ 1** 时：用稳定伪随机将区间内销售/采购总额分摊到各日，并归一化使加总接近真实总额；同日 `count` 一并补全（供 KPI 车次环比等使用）。

### 3.4 货物类型购销

| 属性 | 说明 |
| --- | --- |
| 布局 | 与销售 vs 采购趋势并排（右栏）；右上金额/净重分段 Tab |

| 排序 | 按金额合计降序；超过 8 类时 Top 7 +「其他」 |
| 图示 | 环形饼图 + 右侧图例（色点 / 货类名 / 占比）；中心默认合计，悬停显示货类与占比；图例悬停可看销售/采购分项 |
| 空态 | 「暂无数据」 |

### 3.5 客户往来 Top

| 属性 | 说明 |
| --- | --- |
| 标题 | 客户往来 Top |

| 展示 | 排名序号 + 客户名 + 金额 + 占区间往来占比 + 相对第一名的进度条；列表纵向均分填满卡片；底部 **Top 5 合计** / **占区间往来** |
| 空态 | 「暂无数据」 |

### 3.6 结算概况

| 属性 | 说明 |
| --- | --- |
| 标题 | 结算概况 |
| 主视觉 | 应收结清率环形图（0–100%） |
| 摘要 | 已结应收、应收总额（区间内） |
| 应付 | 应付结清率进度条（标签 + 百分比） |
| 余额 | **应收余额 / 应付余额**（底部分隔，自资金快览迁入） |

| 指标 | 公式 |
| --- | --- |
| 应收结清率 | 区间内应收 `settledAmount` 合计 / `amount` 合计 × 100%（分母 0 → 0%） |
| 已结应收 / 应收总额 | 区间内对应合计 |
| 应付结清率 | 区间内应付同上口径 |
| 应收 / 应付余额 | 区间内往来 `balance` 合计 |

### 3.8 资金快览

| 属性 | 说明 |
| --- | --- |
| 标题 | 资金快览 |
| 布局 | **结余主指标**（顶部强调）→ **区间收付 2×2**（已收/已付/杂项收入/杂项支出）；聚焦现金流，应收应付余额归结算概况 |

| 指标 | 计算口径 |
| --- | --- |

| 已付款 | 区间内 `type === "payment"` 合计 |
| 杂项收入 / 支出 | 区间内杂项收付款合计 |

## 4. 交互与布局

### 4.1 全局

- **加载**：`dynamic import` 懒加载 `DashboardView`，加载中 `PageSkeleton`；`ssr: false`
- **刷新**：随 Mock Store 变更自动重算，无手动刷新
- **布局**（xl 及以上）：

| 行 | 左侧（约 2.2） | 右侧（约 1） |
| --- | --- | --- |
| 1 | 销售 vs 采购趋势 | 货物类型购销（饼图，金额/净重 Tab） |
| 2 | 客户往来 Top | 结算概况 |
| 3 | 近日过磅摘要 | 资金快览 |

- 三行统一左宽右窄（约 2.2:1）；同行卡片等高拉伸；小屏纵向堆叠
- KPI 行：四列等分（小屏两列）

### 4.2 特殊交互

| 交互 | 说明 |
| --- | --- |
| 时间筛选 | 分段 + 自定义双月日历均驱动全看板重算 |
| 趋势稀疏补全 | 区间内有效数据日 ≤ 1 且天数 > 1 时演示分摊 |
| 环比 | KPI 基于当前区间日序列前后半段 |
| 同比 | KPI 对比去年同日起止区间合计 |
| 货类指标 Tab | 金额 / 净重切换同一饼图 |
| 只读看板 | 无钻取、无跳转业务详情、无行内编辑 |

## 5. 数据模型与计算依赖

### 5.1 输入数据源

| 数据源 | 用途 |
| --- | --- |
| `weighTickets` | KPI、趋势、活跃度、客户 Top、近日摘要 |
| `receivables` | 结算概况、应收余额 |
| `payables` | 应付结清率、应付余额 |
| `payments` | 已收/已付/杂项、现金结余 |
| `tenant.openingCash` | 现金结余 |

### 5.2 磅单口径

- 仅 `status === "normal"`
- 作废磅单不计入 KPI、图表、排行与摘要

### 5.3 与一期业务需求的对应

一期约定首页含：经营概览（销售/采购/毛利/车次/净重）与资金概览（收付/结余/应收应付余额）。

**当前原型在一期基础上增加 / 明确：**

- 时间范围筛选（默认本月）驱动经营与资金相关指标
- 趋势折线、客户 Top、结算结清率、近日磅单表、货类饼图
- 趋势/活跃度在稀疏数据下有演示分摊（非严格历史还原）
- i18n 存在「经营概览 / 资金概览」文案，页面未用该分组标题展示

## 6. 状态与异常场景

| 场景 | 表现 / 规则 |
| --- | --- |
| 首次加载 | `PageSkeleton` → 看板 |
| 区间内无正常磅单 | KPI 为 0；客户 Top 空态；趋势/活跃度按区间日轴展示（可能全 0 或演示分摊） |
| 无有效客户名 | 客户 Top「暂无数据」 |
| 区间内无应收/应付 | 结清率 0%；金额 0 |
| 修改期初现金 | 现金结余联动 |
| 权限不足 / 手动刷新 / 网络异常 | 演示环境未实现（Mock 本地） |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 时间范围：自定义 / 今日 / 本周 / 本月（默认本月）及双月区间选择
- 经营 KPI、趋势、活跃度、客户 Top、近日过磅、结算、资金随区间规则过滤
- 演示稀疏数据补全、看板动效、左右统一栅格布局
- Mock 本地数据自动重算

### 8.2 本期不包含

- 看板手动刷新、指标钻取、导出/打印/自定义布局
- 应付结清率独立图表
- 后端 API、角色级看板字段裁剪
- 真实日历「今日」（演示用业务锚点日）
