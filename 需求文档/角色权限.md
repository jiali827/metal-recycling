## 1. 引言

### 1.1 背景

角色权限页用于维护租户内系统角色定义，包括角色名称、**结构化功能权限**及启用状态，为员工分配角色提供主数据，并支撑登录鉴权与后续菜单/按钮级 RBAC。角色内部标识（`id`）由系统自动生成，**不对用户展示、不由用户填写**。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「角色权限」标题 |
| 页面头部 | 新建角色 | 打开「新建角色」弹窗 |
| 筛选区 | 筛选查询 | 未在页面或资料中体现 |
| 数据列表 | 角色列表 | 表格展示角色核心字段与审计时间，默认按创建时间倒序 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开角色详情/编辑弹窗 |
| 数据列表 | 行操作 | 支持「详情」「删除」 |
| 新建弹窗 | 角色录入 | 录入角色名、功能权限矩阵、启用状态 |
| 新建弹窗 | 启用切换确认 | 切换启用/停用时弹出确认框 |
| 新建弹窗 | 保存 | 校验必填项后保存，关闭弹窗并打开详情 |
| 详情弹窗 | 角色编辑 | 在弹窗内查看并编辑角色名、功能权限、启用状态 |
| 详情弹窗 | 功能权限矩阵 | 按模块勾选查看/新建/编辑/删除等功能权限 |
| 详情弹窗 | 启用切换确认 | 切换启用/停用时弹出确认框 |
| 详情弹窗 | 保存反馈 | 保存成功后展示「已保存」提示，弹窗不自动关闭 |
| 删除 | 删除确认 | 删除前二次确认，确认后从列表移除 |

## 3. 模块需求说明

### 3.1 筛选查询区

未在页面或资料中体现。列表直接展示全部角色记录，无关键词、状态等筛选控件。

### 3.2 数据列表

以表格形式展示角色记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 角色名 | 角色显示名称，加粗展示；内置角色按当前界面语言本地化 | 否 |
| 启用状态 | 启用/停用；启用为绿色标签，停用为红色标签 | 否 |
| 权限摘要 | 内置角色展示 i18n 本地化摘要；自定义角色展示「N 个模块可操作 · M 个模块只读」等统计文案 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 内置角色权限摘要（简体中文，列表展示用）

| 角色代码 | 角色名 | 权限摘要（列表展示） |
| --- | --- | --- |
| admin | 系统管理员 | 员工与角色 · 基础参数 · 全部列表只读 |
| contract | 合同管理员 | 合同 CRUD / 生效 · 客户/货物类型只读 |
| weigh | 过磅人员 | 过磅录入 / 作废申请 · 客户/货物类型只读 |
| finance | 财务 | 应收应付 · 收付款核销 · 首页资金 · 期初现金 |
| boss | 老板 | 全局总览 · 各模块只读 |

> 内置角色列表中的权限摘要来自 i18n 字典（`roles_permissions`），与弹窗内结构化矩阵展示并存；实际权限以 `access` 字段为准。

#### 默认排序

- 全部角色按 **创建时间倒序** 排列
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「角色详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含角色名），确认后删除；若详情弹窗正在展示同一角色则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建角色

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建角色」按钮 |
| 弹窗标题 | 新建角色 |
| 弹窗尺寸 | 加宽（`2xl`） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 角色名 | 文本输入 | 是 | 空 | 角色显示名称 |
| 功能权限 | 权限矩阵 | 否 | 各模块默认勾选「查看」 | 见 3.7 |
| 启用状态 | 开关 | 否 | 默认「启用」 | 切换前弹出确认框 |

#### 启用/停用确认

切换启用状态开关时，**不立即生效**，先弹出确认框：

| 操作 | 确认标题 | 确认说明（摘要） | 确认按钮 |
| --- | --- | --- | --- |
| 启用 | 确认启用角色 | 启用后，拥有此角色的员工可正常登录系统 | 启用 |
| 停用 | 确认停用角色 | 停用后，拥有此角色的员工将无法登录系统 | 停用（危险样式） |

角色名为空时，确认框以「此角色」代替名称。

#### 保存规则

- 角色内部 `id` 由系统自动生成（格式 `role-{随机串}`），界面不展示、不录入
- 保存时规范化 `access`（剔除无效权限项、推导菜单级别），并派生 `permissions` 摘要数组
- 保存成功后关闭弹窗，并自动打开该角色详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认标题 | 确认删除角色 |
| 确认内容 | 确定要删除角色「{名称}」吗？删除后不可恢复，拥有此角色的员工将无法登录系统。 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一角色则关闭 |

> 当前原型**允许删除**内置五类预置角色，**无**「不可删除系统内置角色」保护；删除后引用该角色的员工在下次登录校验时将因找不到角色而无法登录。

### 3.6 跨模块关联

| 关联模块 | 关系 |
| --- | --- |
| 员工管理（`/employees`） | 员工角色多选引用本页角色数据；新建时仅展示**已启用**角色，编辑时保留员工已选但已停用的角色 |
| 登录鉴权 | 员工须至少拥有一个**已启用**角色方可登录；多角色时权限取并集 |
| 会话同步 | 已登录员工若其角色被停用或删除，或员工记录与角色状态不再满足登录条件，系统将**自动登出** |
| 侧边栏菜单 | 已预留 `data-module-id`、`data-perm-level` 及只读样式；**过滤逻辑尚未启用**（见 3.8） |
| 各业务页面按钮 | 功能权限数据已结构化存储，**页面级按钮显隐/禁用尚未接入** |

### 3.7 功能权限矩阵（核心）

新建/编辑弹窗中的「功能权限」区域，以**两列矩阵**展示，**不提供**菜单实时预览，**不提供**独立的「菜单访问」分段控件（不可见/只读/可操作）。

#### 矩阵结构

| 列 | 说明 |
| --- | --- |
| 模块 | 与侧边栏菜单对应的业务模块名称，按「业务 / 主数据 / 系统」分组 |
| 功能权限 | 该模块可勾选的功能项（复选框） |

#### 可配置功能项（与当前原型页面能力对齐）

| 功能项 | 含义 | 适用说明 |
| --- | --- | --- |
| 查看 | 可进入模块、查看列表与详情 | 所有模块均有；未勾选时该模块侧边栏不可见 |
| 新建 | 可新建记录（打开新建弹窗等） | 列表类 CRUD 模块 |
| 编辑 | 可编辑记录 | 列表类 CRUD 模块；基础设置含此项 |
| 删除 | 可删除记录 | 列表类 CRUD 模块 |

#### 各模块可勾选功能项

| 分组 | 模块 | 可勾选功能项 |
| --- | --- | --- |
| 业务 | 首页总览 | 查看 |
| 业务 | 项目全景 | 查看 |
| 业务 | 合同管理 | 查看、新建、编辑、删除 |
| 业务 | 过磅台账 | 查看、新建、编辑、删除 |
| 业务 | 收付款 | 查看、新建、编辑、删除 |
| 主数据 | 客户 | 查看、新建、编辑、删除 |
| 主数据 | 货物类型 | 查看、新建、编辑、删除 |
| 系统 | 员工管理 | 查看、新建、编辑、删除 |
| 系统 | 角色权限 | 查看、新建、编辑、删除 |
| 系统 | 基础设置 | 查看、编辑 |

#### 勾选联动规则

| 规则 | 说明 |
| --- | --- |
| 取消「查看」 | 该模块其余功能项一并取消 |
| 勾选「新建/编辑/删除」 | 自动勾选「查看」 |
| 菜单可见性自动推导 | 未勾选查看 → 菜单**不可见**；仅查看 → **只读**；含新建/编辑/删除任一 → **可操作** |

#### 本期**不纳入**角色页配置的功能项

以下能力**不在**角色权限矩阵中单独配置，原因如下：

| 不配置项 | 原因 |
| --- | --- |
| **导出** | 当前各列表页**均无**导出按钮或导出逻辑，权限项与页面能力不一致 |
| **生效**（合同） | 合同生效属于详情/编辑页内的**业务状态操作**，非页面级独立功能 |
| **作废**（磅单） | 磅单作废属于详情/编辑页内的**业务状态操作**，非页面级独立功能 |
| **菜单访问分段**（不可见/只读/可操作） | 与功能权限勾选重复；由勾选结果自动推导，不在 UI 重复配置 |

> 若后续页面增加导出能力，或需在编辑页对生效/作废做更细粒度角色控制，应在对应模块单独扩展权限项或在编辑页按状态控制按钮，而非在角色页预置无页面支撑的权限。

#### 内置角色功能权限模板（存储层 `access`）

| 角色代码 | 可操作模块（write） | 只读模块（read） | 不可见 |
| --- | --- | --- | --- |
| admin | 客户、货物类型、员工管理、角色权限、基础设置 | 首页、项目全景、合同、过磅、收付款 | 其余 |
| contract | 合同管理 | 客户、货物类型 | 其余 |
| weigh | 过磅台账 | 客户、货物类型 | 其余 |
| finance | 收付款、基础设置 | 首页、项目全景 | 其余 |
| boss | — | 全部已列模块 | 其余 |

各「可操作」模块勾选：查看 + 新建 + 编辑 + 删除（基础设置为查看 + 编辑）。各「只读」模块仅勾选：查看。

| 子字段 | 类型 | 说明 |

| menu | `none` \| `read` \| `write` | 菜单可见性，由功能权限勾选**自动推导** |

`dashboard` | `transactions` | `contracts` | `weighTickets` | `payments` | `customers` | `materialTypes` | `employees` | `roles` | `settings`

### 内置角色 ID 枚举

`admin` | `contract` | `weigh` | `finance` | `boss`

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 预置五类角色：系统管理员、合同管理员、过磅人员、财务、老板
- 权限矩阵定义各角色对业务能力（员工与角色、基础参数、合同、过磅、往来收付、首页等）的操作/只读范围
- 角色可配置（租户维度）

**当前原型差异（须在验收时知晓）：**

- 已提供**结构化功能权限矩阵**，但**尚未**驱动侧边栏过滤与各页按钮显隐
- 列表「权限摘要」对内置角色仍用 i18n 文案，与矩阵并存
- 内置角色在详情中编辑保存后，会**覆盖**存储的 `name` / `access`，可能影响本地化回退逻辑
- 内置角色**可被删除**，无保护规则
- 角色内部 `id` 由系统生成，界面不展示、不录入；创建后不可变更
- **无**导出、生效、作废等当前页面未实现的权限项

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 角色列表为空 | 表格空态 | 可新建角色 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 角色名为空保存 | 浏览器原生校验 | 阻止提交 |
| 启用确认取消 | 切换启用状态后点取消 | 开关保持原状态 | 数据不变 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 停用角色 | 角色 `enabled` 设为 false | 列表显示停用标签 | 关联员工无法新登录；已登录符合条件的会话被登出 |
| 删除被引用角色 | 角色已分配给员工 | 允许删除 | 关联员工后续无法通过角色校验登录 |
| 权限不足 | 非系统管理员访问 | 未在页面或资料中体现 | 演示环境未实现 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏「角色权限」可进入 `/roles`，标题为「角色权限」 |
| 列表展示 | 正确展示角色名、启用状态、权限摘要、创建/更新时间（不展示角色代码） |
| 内置角色 | 五类内置角色名称与列表权限摘要按当前语言正确本地化 |
| 列表排序 | 默认按创建时间倒序 |
| 分页 | 超过 10 条时分页正常 |
| 新建默认值 | 角色名为空；各模块功能权限默认勾选「查看」；状态为启用 |
| 新建必填 | 角色名为空无法保存 |
| 内部 ID | 新建保存时系统自动生成唯一 `id`；界面不提供代码录入 |
| 功能权限矩阵 | 两列展示「模块 \| 功能权限」；无菜单预览、无菜单访问分段列 |
| 功能项范围 | 仅展示查看/新建/编辑/删除；**无**导出、生效、作废 |
| 勾选联动 | 取消查看清空该模块；勾选写操作自动勾选查看 |
| 内置模板 | 五类内置角色打开详情时矩阵与一期权限矩阵一致 |
| 启用确认 | 切换启用状态前弹出确认，取消则状态不变 |
| 新建保存 | 保存后自动打开详情 |
| 详情无代码字段 | 详情弹窗不展示角色代码/ID |
| 详情编辑 | 可修改角色名、功能权限、启用状态并保存 |
| 删除确认 | 删除前确认，确认后记录消失 |
| 登录联动 | 停用角色后，拥有该角色的员工登录被拒 |
| 菜单过滤 | 侧边栏仍展示全部菜单（过滤未启用，属预期） |
