## 1. 引言

### 1.1 背景

员工管理页用于维护租户内员工账号与角色分配，支持为一名员工分配**多个角色**，登录后拥有所选角色权限的并集，支撑多租户场景下管理员添加、编辑、停用员工。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「员工管理」标题 |
| 页面头部 | 新建员工 | 打开「新建员工」弹窗 |
| 筛选区 | 关键词筛选 | 按姓名、邮箱、角色名称（多个）模糊匹配 |
| 数据列表 | 员工列表 | 表格展示员工核心字段与审计时间，默认按创建时间倒序 |
| 数据列表 | 分页 | 底部分页：可选每页条数、页码点选、跳页；默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开员工详情/编辑弹窗 |
| 数据列表 | 行操作 | 支持「详情」「删除」 |
| 新建弹窗 | 员工录入 | 录入姓名、邮箱（登录账号）、角色（多选）、在职状态 |
| 新建弹窗 | 保存 | 校验必填项与邮箱唯一后保存；初始密码设为邮箱；关闭弹窗并打开详情 |
| 详情弹窗 | 员工编辑 | 可改姓名、角色、状态；**邮箱只读** |
| 详情弹窗 | 重置密码 | 二次确认后将密码重置为登录邮箱 |
| 详情弹窗 | 保存反馈 | 保存成功后展示「已保存」提示，弹窗不自动关闭 |
| 删除 | 删除确认 | 删除前二次确认，确认后从列表移除 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 关键词 | 文本输入 | 占位符：「姓名 / 邮箱 / 角色」 | 对「姓名 + 邮箱 + 全部角色显示名（本地化后拼接）」做不区分大小写的包含匹配 |

> 页面**无**按角色、在职状态等维度的独立筛选控件。

### 3.2 数据列表

以表格形式展示员工记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 姓名 | 员工显示名称，加粗展示 | 否 |
| 邮箱 | 登录邮箱（账号，创建后不可改） | 否 |
| 角色 | 已分配的全部角色，每个角色一个色块标签 | 否 |
| 状态 | 在职/停用；在职为绿色标签，停用为红色标签 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 状态枚举与展示

| 内部值 | 列表/表单展示 |
| --- | --- |
| `active` | 在职 |
| `disabled` | 停用 |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的员工排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：**10 / 20 / 50 / 100**
- 支持页码点选、上一页/下一页、输入页码跳转
- 分页控件位置：列表底部固定
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「员工详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含员工姓名），确认后删除；若详情弹窗正在展示同一员工则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建员工

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建员工」按钮 |
| 弹窗标题 | 新建员工 |
| 弹窗尺寸 | 默认尺寸（未指定 `size` 属性） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 姓名 | 文本输入 | 是 | 空 | 员工显示名称 |
| 邮箱 | 邮箱输入 | 是 | 空 | `type="email"`；登录账号；**租户内唯一**（不区分大小写）；字段下方小字提示「邮箱为登录账号，设置后不可修改」 |
| 角色 | 多选下拉 | 是 | 空（须手动选择） | 点击展开选项列表，可勾选多项；至少选择 1 项；选中项以标签展示在触发器上 |
| 状态 | 开关 | 否 | 默认「停用」 | 开关旁展示「在职」或「停用」 |

#### 角色多选规则

- 数据来源：`roles` 角色主数据列表
- 新建时仅展示 **已启用** 的角色
- 内置五类角色按当前界面语言展示本地化名称
- 保存时写入 `roleIds` 数组（去重，且仅保留有效角色 ID）
- 未选择任何角色时阻止保存，提示「请至少选择一个角色」

**内置角色与本地化名称：**

| 角色 ID | 简体中文显示名 |
| --- | --- |
| admin | 系统管理员 |
| contract | 合同管理员 |
| weigh | 过磅人员 |
| finance | 财务 |
| boss | 老板 |

#### 保存规则

- 邮箱保存前 `trim` 并转为小写存储
- 若邮箱已被其他员工占用，阻止保存并提示「该邮箱已被其他员工使用」
- 保存成功后，**初始登录密码自动设为与邮箱相同**（演示环境写入本地 `localStorage`）
- 保存成功后关闭弹窗，并自动打开该员工详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.4 弹窗：员工详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「详情」、新建保存后自动打开 |
| 弹窗标题 | `员工详情 · {员工姓名}` |
| 弹窗尺寸 | 默认尺寸 |
| 表单布局 | 双列网格（`FormFieldGrid`），角色区全宽 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 可编辑 | 说明 |
| --- | --- | --- | --- | --- |
| 姓名 | 文本输入 | 是 | 是 | 员工显示名称 |
| 邮箱 | 邮箱输入 | — | **否** | 登录账号；`disabled` / `readOnly`；下方小字「邮箱为登录账号，设置后不可修改」 |
| 角色 | 多选下拉 | 是 | 是 | 规则同新建；至少 1 项 |
| 状态 | 开关 | 否 | 是 | 在职 / 停用 |

| 差异点 | 说明 |
| --- | --- |
| 邮箱不可改 | 创建后邮箱固定；保存时 `updateEmployee` **忽略** `email` 字段 |
| 数据回填 | 从 `roleIds` 加载已选角色；邮箱展示原值 |
| 角色选项 | 展示已启用角色 + 员工当前已选但已停用的角色（保留历史勾选） |
| 保存行为 | 保存后不关闭弹窗，展示绿色「已保存」 |
| 重置密码 | 底部左侧「重置密码」按钮；二次确认后将密码设为当前邮箱，并展示「密码已重置为登录账号」 |

#### 底部按钮

| 按钮 | 位置 | 行为 |
| --- | --- | --- |
| 重置密码 | 左侧 | 弹出危险确认框；确认后将该员工登录密码重置为**邮箱**（与账号相同） |
| 关闭 | 右侧 | 关闭弹窗 |
| 保存 | 右侧 | 提交表单 |

#### 重置密码确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 详情弹窗底部「重置密码」 |
| 确认标题 | 确认重置密码 |
| 确认内容 | 含员工姓名与邮箱，说明重置后须使用邮箱作为密码登录 |
| 确认后 | 密码写入演示密码存储；表单区展示绿色「密码已重置为登录账号」 |

> 原「底部按钮」仅含关闭/保存；现采用**左重置、右关闭/保存**布局。

#### 底部按钮（记录不存在时）

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |

#### 记录不存在

当传入的员工 ID 不存在时，弹窗内容区展示「未找到记录」，底部仅保留「关闭」。

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 含员工姓名的危险确认框 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一员工则关闭 |

> 当前原型删除员工**未校验**是否为当前登录用户、是否为唯一管理员等。

### 3.6 跨模块关联

| 关联模块 | 关系 |
| --- | --- |
| 角色权限（`/roles`） | 员工角色多选引用角色主数据；自定义角色可在员工表单中勾选 |
| 登录鉴权 | 员工至少拥有一个**已启用**角色方可登录；多角色权限取并集；演示密码存于 `localStorage`（`baoxin-mock-passwords`）；种子账号若未重置可能仍用演示默认密码 `demo1234` |
| 个人设置 | 员工自行「修改密码」可改密；管理员「重置密码」可恢复为邮箱 |

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：当前为前端 Mock 数据，未体现独立 Loading
- **空状态**：筛选后无数据时表格展示统一空态
- **响应式**：详情弹窗内姓名字段等为双列布局，角色区全宽

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 即时筛选 | 关键词变更后立即过滤列表；全部角色名参与匹配 |
| 列表默认排序 | 按创建时间倒序 |
| 角色多选 | 下拉面板内勾选多项，选中后触发器展示已选角色名；至少保留一项 |
| 新建默认值 | 每次打开新建弹窗，角色与状态重置为空 / 停用 |
| 初始密码 | 新建员工保存后，登录密码 = 邮箱 |
| 重置密码 | 详情弹窗左下角；确认后密码恢复为邮箱 |
| 邮箱唯一 | 新建时校验邮箱不重复（忽略大小写） |
| 状态开关文案 | 开关旁实时展示「在职」或「停用」 |
| 角色名本地化 | 列表与表单中内置角色按当前界面语言显示 |
| 删除与详情联动 | 删除当前查看的员工后，详情弹窗自动关闭 |

## 5. 数据模型（页面涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 系统内部主键 |
| name | string | 员工显示名称 |
| email | string | 登录邮箱（账号）；**创建后不可修改**；**租户内唯一**（比较时忽略大小写） |
| avatarUrl | string? | 头像 Data URL；本页**不提供**编辑入口，由用户「修改资料」弹窗同步更新 |
| roleIds | RoleId[] | 角色 ID 列表（支持多个） |
| status | `"active"` \| `"disabled"` | 在职 / 停用 |
| createdAt | string | 创建时间（ISO 8601） |
| updatedAt | string | 更新时间（ISO 8601） |

### 登录密码（演示）

| 规则 | 说明 |
| --- | --- |
| 存储位置 | 浏览器 `localStorage`，键 `baoxin-mock-passwords`，按邮箱（小写）索引 |
| 新建默认 | 创建员工时写入 `password = email` |
| 管理员重置 | 详情「重置密码」确认后，再次写入 `password = email` |
| 员工自改 | 用户菜单「修改密码」可改为其他符合规则的密码（6～20 位可打印字符） |
| 种子账号 | 演示预置 5 名员工若从未重置，首次登录可能仍匹配演示默认密码；执行「重置密码」后与邮箱一致 |

### 登录与权限并集

- 登录条件：员工状态为在职，且 `roleIds` 中**至少一个**角色处于启用状态
- 权限并集：员工拥有所有已选角色权限的**并集**（演示环境尚未按并集裁剪菜单与按钮）

### 与业务需求文档的对应关系

**当前原型差异（须在验收时知晓）：**

- 多角色权限并集**已在数据层与登录校验体现**，菜单/按钮级 RBAC **尚未**按并集生效
- 密码为**演示级本地存储**，非服务端哈希；**无**邀请邮件、邮箱验证码等开通流程
- 删除员工无保护规则（未校验当前登录用户、唯一管理员等）

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无员工 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 新建时姓名或邮箱为空 | 浏览器原生校验 | 阻止提交 |
| 未选角色 | 角色全部取消后保存 | 红色「请至少选择一个角色」 | 阻止提交 |
| 邮箱格式错误 | 新建时邮箱不符合格式 | 浏览器原生校验 | 阻止提交 |
| 邮箱重复 | 新建时邮箱已被占用 | 红色「该邮箱已被其他员工使用」 | 阻止提交 |
| 尝试改邮箱 | 详情中邮箱只读 | 字段禁用，无法编辑 | `updateEmployee` 忽略 email |
| 重置密码取消 | 重置确认框点取消 | 弹窗关闭 | 密码不变 |
| 重置密码成功 | 详情弹窗确认重置 | 绿色「密码已重置为登录账号」 | 密码设为邮箱 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 全部角色停用 | 员工所有角色均被停用 | 登录被拒（关联模块） | 提示「所属角色已停用，无法登录」 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

| 重置密码 | 详情左下角按钮；二次确认后密码恢复为邮箱 |
| 邮箱只读 | 新建有小字说明；详情邮箱禁用；保存不写入邮箱变更 |
| 删除确认 | 删除前确认，确认后记录消失 |
| 登录联动 | 员工全部角色停用时无法登录 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 员工列表、关键词筛选、创建时间倒序、增强分页（条数/页码/跳页）
- 弹窗式新建 / 详情编辑
- 姓名、邮箱（登录账号，创建后不可改、**唯一**）、**多角色**、在职状态
- **新建初始密码 = 邮箱**；详情**重置密码**（确认后恢复为邮箱）
- 邮箱字段小字提示；详情弹窗邮箱只读；更新接口忽略邮箱变更
- 角色多选与至少一项校验
- 登录时多角色启用校验（至少一个启用角色）
- 单条删除与二次确认

### 8.2 本期不包含（页面或资料未体现）

- 多角色权限并集驱动菜单/按钮级 RBAC
- 服务端密码哈希、邀请注册、邮箱验证码
- 创建后修改登录邮箱 / 换绑流程
- 按角色/状态筛选列表
- 删除保护规则
- 导出、批量操作、列头排序
- 后端 API
