## 1. 引言

### 1.1 背景

货物类型页用于维护货物类型主数据，定义各类型在采购、销售场景下的可用范围及启用状态，为过磅等业务模块提供货物类型名称选择来源。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页面头部 | 页面标题 | 展示「货物类型」标题 |
| 页面头部 | 新建货物类型 | 打开「新建货物类型」弹窗 |
| 筛选区 | 材质 / 关键词 / 采购可用 / 销售可用 / 启用状态 | 即时组合筛选 |
| 数据列表 | 货物类型列表 | 表格展示货物类型核心字段与审计时间，默认按创建时间倒序 |
| 数据列表 | 分页 | 底部分页，默认每页 10 条 |
| 数据列表 | 行点击 | 点击行打开货物类型详情/编辑弹窗 |
| 数据列表 | 行操作 | 支持「详情」「删除」 |
| 新建弹窗 | 货物类型录入 | 先选材质（铁料/铝料），再填名称、用途、启用状态 |
| 新建弹窗 | 保存 | 校验必填项后保存，关闭弹窗并打开详情 |
| 详情弹窗 | 货物类型编辑 | 在弹窗内查看并编辑各字段 |
| 详情弹窗 | 保存反馈 | 保存成功后展示「已保存」提示，弹窗不自动关闭 |
| 删除 | 删除确认 | 删除前二次确认，确认后从列表移除 |

## 3. 模块需求说明

### 3.1 筛选查询区

筛选条件变更后**即时生效**，无需点击「查询」按钮；页面未提供独立的「重置」按钮。多条件为 **AND** 组合。

| 筛选字段 | 类型 | 输入限制 | 匹配规则 |
| --- | --- | --- | --- |
| 材质 | 分段 Tab | 全部 / 铁料 / 铝料；默认「全部」 | 精确匹配 `metalKind`（`iron` / `aluminum`）；位于关键词筛选项之前 |
| 关键词 | 文本输入 | 占位符：「货物类型名称」；默认空 | 对 `name` 做不区分大小写的包含匹配 |
| 采购可用 | 分段 Tab | 全部 / 是 / 否；默认「全部」 | 精确匹配 `forPurchase` |
| 销售可用 | 分段 Tab | 全部 / 是 / 否；默认「全部」 | 精确匹配 `forSale` |
| 启用状态 | 分段 Tab | 全部 / 启用 / 停用；默认「全部」 | 精确匹配 `enabled` |

### 3.2 数据列表

以表格形式展示货物类型记录，支持行点击与行内操作。

#### 列表字段

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 材质 | 铁料 / 铝料 | 否 |
| 货物类型名称 | 物料类型名称，加粗展示 | 否 |
| 采购可用 | 是否可用于采购场景；「是」为绿色标签，「否」为灰色标签 | 否 |
| 销售可用 | 是否可用于销售场景；「是」为绿色标签，「否」为灰色标签 | 否 |
| 启用状态 | 启用/停用；启用为蓝色标签，停用为红色标签 | 否 |
| 创建时间 | 系统记录创建时间，精确到秒 | 是（默认倒序，无列头切换） |
| 更新时间 | 系统记录最后更新时间，精确到秒 | 否 |
| 操作 | 详情、删除 | — |

#### 默认排序

- 筛选后的结果按 **创建时间倒序** 排列（最新创建的货物类型排在最前）
- 不支持列头点击切换排序

#### 分页规则

- 每页默认显示：**10 条**
- 可切换每页条数：未在页面或资料中体现
- 分页控件位置：列表底部
- 筛选结果变化时自动回到第 1 页

#### 批量操作

未在页面或资料中体现。

#### 行操作

| 行操作 | 行为说明 |
| --- | --- |
| 详情 | 打开「货物类型详情」弹窗 |
| 删除 | 弹出危险确认框（确认文案含货物类型名称），确认后删除；若详情弹窗正在展示同一货物类型则关闭详情 |

#### 交互说明

- **行点击**：点击除操作列外的行区域，等效于「详情」
- **导出**：未在页面或资料中体现

### 3.3 弹窗：新建货物类型

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 页面右上角「新建货物类型」按钮 |
| 弹窗标题 | 新建货物类型 |
| 弹窗尺寸 | 默认尺寸（未指定 `size` 属性） |
| 关闭方式 | 点击「取消」、弹窗关闭控件；保存成功后自动关闭 |

#### 表单字段

| 字段 | 控件类型 | 必填 | 默认值 / 限制 | 说明 |
| --- | --- | --- | --- | --- |
| 材质 | 分段按钮 | 是 | 默认「铁料」 | 枚举：铁料（`iron`）、铝料（`aluminum`） |
| 名称 Name | 文本输入 | 是 | 空 | 货物类型名称，如 AA、A、PNS、工字等 |
| 用途 | 复选框组 | 否 | 采购可用 ✓、销售可用 ✓ | 两项可独立勾选 |
| 采购可用 | 复选框 | — | 默认勾选 | 标识该货物类型是否可用于采购业务 |
| 销售可用 | 复选框 | — | 默认勾选 | 标识该货物类型是否可用于销售业务 |
| 启用状态 | 开关 | 否 | 默认「启用」 | 开关旁展示当前状态文案「启用」或「停用」 |

#### 字段顺序

表单自上而下顺序为：**材质 → 名称 → 用途（采购可用、销售可用）→ 启用状态**。

#### 校验规则

- 材质：默认「铁料」，可切换为铝料
- 名称：HTML5 `required`，为空时阻止提交
- 采购可用与销售可用：未强制要求至少勾选一项

#### 保存规则

- 保存成功后关闭弹窗，并自动打开该货物类型详情弹窗

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 取消 | 关闭弹窗，不保存 |
| 保存 | 提交表单 |

### 3.4 弹窗：货物类型详情 / 编辑

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行点击、行操作「详情」、新建保存后自动打开 |
| 弹窗标题 | `货物类型详情 · {货物类型名称}` |
| 弹窗尺寸 | 默认尺寸 |

#### 表单字段

与新建弹窗相同（材质、名称、用途、启用状态），无额外字段。

| 差异点 | 说明 |
| --- | --- |
| 数据回填 | 从已有货物类型记录加载各字段值 |
| 保存行为 | 保存后不关闭弹窗，展示绿色「已保存」 |

#### 底部按钮

| 按钮 | 行为 |
| --- | --- |
| 关闭 | 关闭弹窗 |
| 保存 | 提交表单 |

#### 记录不存在

当传入的货物类型 ID 不存在时，弹窗内容区展示「未找到记录」，底部仅保留「关闭」。

### 3.5 删除确认

| 属性 | 说明 |
| --- | --- |
| 触发方式 | 列表行操作「删除」 |
| 确认内容 | 含货物类型名称的危险确认框 |
| 确认后 | 从列表移除；若详情弹窗正在展示同一货物类型则关闭 |

> 当前原型删除货物类型**未校验**是否被合同、磅单等引用；一期需求未在本页体现级联处理规则。

---

### 3.6 跨页面引用

货物类型主数据被以下模块引用：

| 引用模块 | 用途 | 过滤规则（当前原型） |
| --- | --- | --- |
| 过磅台账 | 货物类型下拉选择（按名称） | **未**按 `enabled`、`forPurchase`、`forSale` 过滤，展示全部货物类型 |
| 合同管理 | 合同单价摘要中含货物类型名称 | 未直接绑定货物类型主数据下拉，由文本解析带出 |

过磅详情编辑时，若当前磅单的货物类型名称已不在主数据中，下拉会**额外追加**该名称选项以保留历史值。

## 5. 数据模型（页面涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 系统内部主键 |
| metalKind | `iron` \| `aluminum` | 材质大类：铁料 / 铝料 |
| name | string | 货物类型名称 |
| forPurchase | boolean | 采购可用 |
| forSale | boolean | 销售可用 |
| enabled | boolean | 是否启用 |
| createdAt | string | 创建时间（ISO 8601） |
| updatedAt | string | 更新时间（ISO 8601） |

### 演示种子数据示例

| 名称 | 采购可用 | 销售可用 | 启用 | 材质 |
| --- | --- | --- | --- | --- |
| AA | 是 | 是 | 是 | 铁料 |
| A | 是 | 是 | 是 |
| AB | 是 | 是 | 是 |
| B | 是 | 是 | 是 |
| PNS | 否 | 是 | 是 |
| 工字 | 是 | 是 | 是 |
| 圓通 | 是 | 否 | 是 |
| 圍街 | 是 | 否 | 是 |
| 角梯 | 否 | 是 | 是 |

### 与业务需求文档的对应关系

一期项目需求文档约定：

- 货物类型：AA、A、AB、B、PNS、工字等，租户可维护
- 区分采购/销售可用
- 作为基础参数，供合同、过磅等全业务链路引用

**当前原型差异（须在验收时知晓）：**

- **无**货物类型编码、计量单位、默认单价等扩展字段
- 列表页支持按采购/销售可用、启用状态筛选；过磅下拉**尚未**按该标记过滤
- 停用货物类型**仍会出现**在过磅货物类型下拉中
- 合同货物类型行未与主数据下拉强绑定
- 删除时**无**引用检查与级联保护

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 空数据 | 筛选后无货物类型 | 表格空态 | 可调整筛选或新建 |
| 记录不存在 | 详情 ID 无效 | 「未找到记录」 | 仅可关闭 |
| 必填校验失败 | 名称为空保存 | 浏览器原生校验 | 阻止提交 |
| 删除取消 | 确认框点取消 | 弹窗关闭 | 数据不变 |
| 保存成功（详情） | 详情弹窗保存 | 绿色「已保存」 | 数据更新，弹窗保持打开 |
| 用途均未勾选 | 采购、销售均不勾选 | 允许保存 | 未在页面或资料中体现业务拦截 |
| 权限不足 | 无编辑权限 | 未在页面或资料中体现 | 演示环境未实现 |
| 删除被引用货物类型 | 货物类型已被磅单等引用 | 未在页面或资料中体现 | 当前允许直接删除 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 页面入口 | 侧边栏「货物类型」可进入 `/material-types`，标题为「货物类型」 |

| 删除确认 | 删除前确认，确认后记录消失 |

## 8. 范围边界

### 8.1 本期包含（以当前原型为准）

- 货物类型列表、材质 + 关键词 + 采购可用 + 销售可用 + 启用状态筛选、创建时间倒序、分页
- 弹窗式新建 / 详情编辑
- 名称、材质（铁料/铝料）、采购可用、销售可用、启用状态
- 单条删除与二次确认
- 作为过磅模块货物类型下拉的名称数据源

### 8.2 本期不包含（页面或资料未体现）

- 货物类型编码、规格、计量单位、默认单价
- 业务模块按 `forPurchase` / `forSale` / `enabled` 过滤下拉选项
- 合同货物类型行与主数据的强关联校验
- 删除前引用检查
- 导出、批量操作、列头排序
- 后端 API、权限按钮级控制
