## 1. 引言

### 1.1 背景

登录用户通过头像菜单弹窗修改本人**显示姓名**与**头像**；邮箱为登录账号只读展示，避免误改账号。头像上传后居中裁切为方形，侧边栏用户区同步展示。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 入口 | 用户菜单 | 侧边栏头像菜单点击「修改资料」打开弹窗 |
| 弹窗 | 标题 | 展示「修改资料」 |
| 表单 | 头像 | 上传/更换/移除；居中裁切预览；见 3.1 |
| 表单 | 姓名 | 可编辑文本；必填；打开时回填当前会话姓名 |
| 表单 | 邮箱 | 只读展示当前登录邮箱；下方小字说明不可修改 |
| 操作区 | 保存 | 调用 `updateProfile` 更新姓名与头像；成功提示 |
| 操作区 | 取消 | 关闭弹窗，不保存本次未提交修改 |
| 操作区 | 关闭 | 弹窗右上角关闭 / Esc / 点击遮罩关闭 |
| 展示联动 | 侧边栏头像 | 保存成功后侧边栏圆形头像区展示自定义头像或首字母占位 |
| 旧路由 | 重定向 | 访问 `/settings/profile` 跳转至 `/dashboard` |

## 2. 页面菜单与权限规划

### 2.1 页面菜单

**菜单路径**：侧边栏头像用户菜单 / 修改资料

> 不在侧边栏主菜单中；无独立业务列表页。

### 2.2 权限规划

| 权限点 | 操作范围 | 数据范围 |
| --- | --- | --- |
| 查看 | 打开弹窗并查看当前姓名、头像、邮箱 | 仅当前会话用户 |
| 编辑 | 修改并保存显示姓名、头像（上传/移除） | 仅当前会话用户 |
| 导出 | 未在页面或资料中体现 | — |

> 当前原型：任意已登录用户均可打开本弹窗；未按角色做按钮级差异控制。

## 3. 修改资料弹窗需求说明

### 3.1 表单基础信息区

| 属性 | 说明 |
| --- | --- |
| 弹窗组件 | `Modal`，默认尺寸（`md`） |
| 标题 | 修改资料 |
| 打开时行为 | 回填 `user.name`、`user.avatarUrl`；清空错误与成功提示 |

| 字段名称 | 类型 | 输入限制 | 默认值 | 必填 | 编辑状态 | 字段说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 头像 | 图片上传区 | 见 3.1.1 | 打开时为当前会话 `user.avatarUrl`；无头像时为首字母圆形占位 | 否 | 可编辑 | 位于姓名之上；保存后写入会话并联动侧边栏 |
| 姓名 | 文本输入 | 非空（去首尾空格后不可为空） | 打开时为当前会话 `user.name` | 是 | 可编辑 | 侧边栏等处展示的显示名称；`autoComplete="name"` |
| 邮箱 | 邮箱输入（只读） | 不可输入 | 当前会话 `user.email` | 否 | **只读**（`disabled` + `readOnly`） | 登录账号；下方小字：「邮箱为登录账号，不可修改」 |

#### 3.1.1 头像上传规则

| 规则项 | 说明 |
| --- | --- |
| 支持格式 | JPG、PNG、WebP（`image/jpeg`、`image/png`、`image/webp`） |
| 文件大小 | 最大 **2MB** |
| 裁切方式 | 取图片较短边为边长，**居中裁切**为正方形 |
| 输出规格 | 256×256 像素，JPEG（质量约 0.88） |
| 存储方式 | 演示环境存为 **Data URL**（`user.avatarUrl`），写入本地会话 `localStorage` |
| 展示样式 | 圆形预览；`object-fit: cover` + `object-position: center`（居中剪裁显示） |
| 无头像时 | 圆形底色 + 姓名首字母（与侧边栏默认样式一致） |

#### 3.1.2 头像区交互

| 操作 | 行为 |
| --- | --- |
| 点击圆形预览 | 打开系统文件选择器 |
| 更换头像 | 按钮触发文件选择；选图后自动校验、裁切并更新预览 |
| 移除头像 | 有自定义头像时展示「移除头像」；点击后清除 `avatarUrl`，恢复首字母占位 |
| 悬停预览 | 圆形区域悬停显示相机图标遮罩，提示可点击更换 |
| 校验失败 | 表单下方红色错误文案（格式/大小/处理失败） |

| 错误场景 | 提示文案（简体中文） |
| --- | --- |
| 格式不符 | 仅支持 JPG、PNG、WebP 图片 |
| 超过大小 | 图片不能超过 2MB |
| 解码/裁切失败 | 图片处理失败，请换一张试试 |

### 3.2 表单分组 / 明细项

未在页面或资料中体现（无子表、附件、步骤表单等）。

### 3.3 校验规则

| 校验对象 | 校验规则 | 触发时机 | 错误提示 |
| :--- | :--- | :--- | :--- |
| 姓名 | HTML `required`；空值不可提交 | 提交 | 浏览器原生必填提示 |
| 姓名 | `trim` 后为空 | 提交（`updateProfile`） | 姓名不能为空 |
| 头像 | 格式须为 JPG/PNG/WebP | 选图后 | 仅支持 JPG、PNG、WebP 图片 |
| 头像 | 文件 ≤ 2MB | 选图后 | 图片不能超过 2MB |
| 头像 | 图片可解码且可绘制裁切 | 选图后 | 图片处理失败，请换一张试试 |
| 会话 | 无登录用户 | 提交（`updateProfile`） | 未登录 |
| 邮箱 | 不允许修改 | — | 控件禁用；保存不接受邮箱变更 |

### 3.4 操作按钮

| 按钮 | 展示条件 | 点击行为 | 成功反馈 | 失败处理 |
| :--- | :--- | :--- | :--- | :--- |
| 保存 | 弹窗打开 | 提交表单；`updateProfile({ name, avatarUrl })` 写入本地会话 | 绿色「资料已更新」；弹窗保持打开；侧边栏姓名与头像刷新 | 红色错误文案；保留已填内容 |
| 取消 | 弹窗打开 | 关闭弹窗 | — | — |
| 关闭（X）/ Esc / 遮罩 | 弹窗打开 | 关闭弹窗 | — | — |

### 3.5 保存与数据规则

| 规则 | 说明 |
| --- | --- |
| 可更新字段 | `name`、`avatarUrl`（传 `null` 表示移除头像） |
| 邮箱 | `updateProfile` 不接受邮箱；展示用会话只读值 |
| 持久化 | 写入 `localStorage` 会话（`baoxin-mock-session`） |
| 员工主数据 | 若当前用户邮箱匹配员工库记录，**同步更新**该员工的 `name`、`avatarUrl` |
| 演示账号 | `demo@baoxin.hk` 等未匹配员工的会话，仅更新本地会话 |
| 成功不关闭 | 保存成功后弹窗不自动关闭，便于确认结果 |

## 4. 交互设计

### 4.1 全局交互

- **加载状态**：本地会话数据，未在页面或资料中体现独立 Loading
- **表单保存**：当前实现未对保存按钮做防重复点击锁定；失败时保留输入
- **响应式**：弹窗居中；头像区居中排列，提示文案居中

### 4.2 特殊交互

| 交互名称 | 说明 |
| --- | --- |
| 打开回填 | 每次 `open` 时同步当前用户姓名与头像，并清空提示 |
| 邮箱只读 | 禁用态展示，不可聚焦编辑 |
| 关闭不保存 | 取消/关闭不提交未保存的修改 |
| 与侧边栏联动 | 保存成功后会话 `user.name`、`user.avatarUrl` 更新，侧边栏展示名与圆形头像同步变化 |
| 头像居中裁切 | 上传时裁切；展示时 `cover` 居中，避免拉伸变形 |

## 5. 数据模型

### 5.1 会话用户（User，本弹窗涉及字段）

| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| name | string | 显示姓名 |
| email | string | 登录邮箱（本弹窗不可改） |
| avatarUrl | string? | 头像 JPEG Data URL；无值时侧边栏用首字母占位 |

### 5.2 与业务需求文档的对应关系

一期项目需求文档未单独定义头像字段；本能力为演示环境个人资料扩展。

**当前原型差异（须在验收时知晓）：**

- 头像为本地 Data URL，**无**对象存储、CDN、图片审核
- **无**裁剪框手动调整，仅自动居中方形裁切
- 修改登录邮箱仍不支持

## 6. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| :--- | :--- | :--- | :--- |
| 初始化回填 | 打开弹窗 | 姓名、头像、邮箱展示当前会话值 | 无 Loading |
| 选图失败 | 格式/大小/解码错误 | 红色错误文案 | 不更新预览 |
| 表单校验失败 | 姓名为空等 | 红色错误或浏览器原生提示 | 阻止写入 |
| 保存成功 | 校验通过 | 绿色「资料已更新」 | 会话已更新；侧边栏联动 |
| 保存失败 | 未登录等 | 红色错误文案 | 保留填写内容，可重试 |
| 移除头像 | 点击「移除头像」后保存 | 侧边栏恢复首字母占位 | `avatarUrl` 从会话与员工记录清除 |
| 权限不足 | 非登录访问 | 未在页面或资料中体现独立拦截页 | 提交时报「未登录」 |
| 旧路由访问 | 打开 `/settings/profile` | 重定向至 `/dashboard` | 不展示独立资料页 |
| 网络异常 | 接口失败 | 未在页面或资料中体现 | 当前为 Mock 本地状态 |

## 7. 验收标准

| 验收点 | 验收标准 |
| :--- | :--- |
| 入口 | 头像菜单「修改资料」打开弹窗，不跳转独立设置页 |
| 回填 | 打开后姓名、头像、邮箱与当前登录用户一致 |
| 姓名可改 | 修改姓名并保存后，提示「资料已更新」，侧边栏名称更新 |
| 头像上传 | 可选择 JPG/PNG/WebP（≤2MB）；预览为圆形且居中裁切 |
| 头像展示 | 保存后侧边栏显示自定义头像；`object-fit: cover` 居中 |
| 移除头像 | 「移除头像」后保存，侧边栏恢复首字母圆形图标 |
| 头像校验 | 错误格式/超大文件/损坏图片有对应红色提示 |
| 姓名必填 | 姓名清空后无法成功保存 |
| 邮箱只读 | 无法编辑邮箱；有小字「邮箱为登录账号，不可修改」 |
| 员工同步 | 员工账号修改头像后，员工库对应记录 `avatarUrl` 同步（演示环境） |
| 取消关闭 | 取消 / 关闭后弹窗消失；未保存修改不生效 |
| 旧路由 | 访问 `/settings/profile` 进入首页 `/dashboard` |

## 8. 范围边界

### 8.1 本期包含

- 用户菜单弹窗修改显示姓名与头像
- 头像格式/大小校验、居中方形裁切、圆形预览
- 移除头像恢复默认占位
- 邮箱只读展示与说明文案
- 本地会话持久化；匹配员工时同步 `name` / `avatarUrl`
- 侧边栏头像与姓名联动
- 旧独立页路由重定向

### 8.2 本期不包含

- 修改登录邮箱 / 换绑 / 验证码
- 头像手动裁剪框、缩放、旋转
- 服务端对象存储、图片 CDN、内容审核
- 手机号等其余扩展资料字段
- 后端 API、真实鉴权服务端校验
- 未登录时的独立引导页（仅提交时报错）
