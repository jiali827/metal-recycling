## 1. 引言

### 1.1 背景

合同管理按真实单据拆为采购合同与销售合同两套模型与表单：采购对齐己方报价约定（价格/货类，不算约重履约）；销售对齐客户合同（多行约量与按行履约），统一入口便于业务与财务查阅。

### 1.2 功能清单

| 模块 | 功能点 | 功能描述 |
| --- | --- | --- |
| 页头 Tab | 采购 / 销售切换 | 标题级 Tab「采购合同」「销售合同」；记住上次停留；切换时清空筛选与打开中的详情 |
| 页头操作 | 新建 | 按当前 Tab 打开对应新建弹窗，不再二次选择采购/销售类型 |
| 筛选区 | 关键词 + 状态 | 即时过滤列表；采购/销售状态枚举不同 |
| 采购列表 | 列展示与行操作 | 编号、对方、货类、单价摘要、有效期、状态、报价日、附件、审计时间；详情/删除；行点击开详情 |
| 销售列表 | 列展示与行操作 | 编号、对方、货类、约量、已履约、进度、总价、截止日、状态、签订日、审计时间；详情/删除；有关联磅单禁止删合同 |
| 采购新建/编辑 | 头信息 + 多行明细 + 附件 | 无约量/已履约；计价方式与单价；**项目**为项目类型可搜索下拉（选填）；左侧扫描件预览 |
| 销售新建/编辑 | 共性头字段 + 多行约量 + 附件 | 仅编号/客户/日期/付款/截止/容差/总价/状态/履约情况 + 明细；异构条款看扫描件 |
| 附件预览 | 上传 / 缩放 / 下载 | PDF、JPG、PNG（代码亦接受 WEBP）；自定义预览无浏览器黑底工具栏；仅放大、缩小、下载（编辑时可清除） |
| 过磅联动 | 销售按行关联 | 可选销售合同 + 明细行；全量重算已履约；超容差提示不阻断；首笔关联可使生效→履约中 |
| 过磅联动 | 采购弱关联 | 可选填合同编号文本；不累计履约、无行级外键 |

## 3. 信息架构与产品约定

### 3.1 入口与导航

| 项 | 约定 |
| --- | --- |
| 菜单 | 单一「合同管理」，不拆两个一级菜单 |
| 页内 Tab | **采购合同** \| **销售合同** |
| Tab 记忆 | `localStorage` 键 `bx-contracts-tab`，取值 `purchase` / `sale` |
| 默认 Tab | 首次进入为采购合同；之后恢复上次 |
| 切换 Tab | 清空关键词、状态筛选、关闭详情；写入记忆 |
| 新建 | 当前 Tab 直接打开对应新建弹窗 |
| 命名 | 对外统一称「采购合同」（即便样例单据为 Quotation / 报价单） |
| 路由模式 | 一期以列表 + 弹窗为主；`/contracts/new`、`/contracts/[id]` 若保留则重定向到列表并打开对应弹窗（未在页面或资料中体现独立全页表单） |

### 3.2 方案结构（方案 A）

```
合同管理页
├── Tab: 采购合同
│   ├── 采购合同列表
│   ├── 新建采购合同弹窗
│   └── 编辑采购合同弹窗（标题不含合同编号）
└── Tab: 销售合同
    ├── 销售合同列表
    ├── 新建销售合同弹窗
    └── 编辑销售合同弹窗（标题不含合同编号）

过磅台账（关联能力）
├── 销售：saleContractId + saleContractLineId → 累计 SaleContractLine.fulfilledQty
└── 采购：contractNo 文本弱关联，不累计履约
```

### 3.3 一期明确不做

- OCR 自动识别填表
- 质量 / 杂质 / 尺寸罚则规则引擎
- 定金 / 分期与收付款自动核销（付款条件仅文本）
- 采购合同强制或结构化绑定过磅
- 将采购菜单改名为「报价」
- 列表分页、导出、批量操作、打印、电子签、审批流、合同版本

### 4.1 采购合同 `PurchaseContract`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 系统 | 主键 |
| no | string | 是 | 业务编号（如 `Q-YK-2026-002`） |
| customerId / customerName | string | 是 | 对方客户 |
| contactName | string? | 否 | 联系人 |
| project | string? | 否 | 项目名称快照；选项来自启用中的项目类型主数据（见 `需求文档/项目类型.md`）；不存 `projectId` |
| status | enum | 是 | 见 §5.1 |
| quotedOn | string | 是 | 报价日期 `YYYY-MM-DD` |
| validUntil | string? | 否 | 有效期至 |
| currency | string | 是 | 原型固定写入 `HKD` |
| lines | PurchaseContractLine[] | ≥1 | 明细 |
| remarks | string? | 否 | 条款备注 |
| attachmentName / attachmentDataUrl | string? | 否 | 扫描件文件名与预览地址（Data URL 或静态路径） |
| createdAt / updatedAt | string | 系统 | 审计时间 |

**`PurchaseContractLine`**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 系统 | 行主键 |
| materialTypeId | string? | 否 | 关联货类主数据；可空则用名称 |
| materialName | string | 是 | 展示名 |
| priceMode | enum | 是 | `ex_yard` 到场价 / `collect` 派车价 / `other` 其他 |
| unitPrice | number | 是 | 单价（与样例一致按吨价展示） |
| lineRemark | string? | 否 | 行备注（**类型存在，当前表单 UI 未暴露**） |

**明确不包含**：约量、已履约、合同总价强制字段。

### 4.2 销售合同 `SaleContract`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 系统 | 主键 |
| no | string | 是 | 业务编号 |
| customerId / customerName | string | 是 | 买方客户 |
| status | enum | 是 | 见 §5.2 |
| signedOn | string | 是 | 签订日期 `YYYY-MM-DD` |
| paymentTerms | string? | 否 | 付款条件摘要 |
| fulfillBy | string? | 否 | 履约 / 装运截止日 |
| tolerancePercent | number? | 否 | 容差 %；新建默认 `10`；空=不按容差提示 |
| currency | string | 是 | 原型固定写入 `HKD` |
| totalAmount | number? | 否 | 合同总价；可手填；列表优先展示该值否则明细汇总 |
| lines | SaleContractLine[] | ≥1 | 明细 |
| attachmentName / attachmentDataUrl | string? | 否 | 扫描件 |
| createdAt / updatedAt | string | 系统 | 审计时间 |

> **表单不展示、仅模型/样例可保留的异构字段**（一期 UI 隐藏，编辑保存不覆盖）：`priceTerms`、`origin`、`destination`、`packingSummary`、`bankAccountSummary`、`remarks`。细则见扫描件，不进录入表单。

**`SaleContractLine`**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 系统 | 行主键 |
| materialTypeId | string? | 否 | 关联货类主数据 |
| materialName | string | 是 | 品名 |
| plannedQty | number | 是 | 约量，**内部存 KG** |
| qtyUnit | enum | 是 | 一期固定 `"kg"` |
| unitPrice | number | 是 | **每吨**单价 |
| lineAmount | number? | 否 | `(plannedQty/1000) * unitPrice` |
| fulfilledQty | number | 系统 | 已履约量（KG），只读，由关联磅单累计 |
| lineRemark | string? | 否 | 行备注（**当前表单 UI 未暴露**） |

**单位口径（一期固定）**

| 项 | 规则 |
| --- | --- |
| 存储 | `plannedQty` / `fulfilledQty` 均为 KG |
| 录入 | 销售约量 UI 用「吨」，保存时 ×1000（四舍五入到整数 KG） |
| 列表展示 | 约量 / 已履约用全站 `formatKg` |
| 单价 | 按每吨录入与展示 |
| 行金额 | `(plannedQtyKg / 1000) * unitPricePerTon` |
| 回填磅单单价 | 合同吨价 / 1000 → 每 KG |

### 4.3 过磅 `WeighTicket` 扩展

| 字段 | 说明 |
| --- | --- |
| saleContractId? | 可选，关联销售合同 |
| saleContractLineId? | 可选；新关联须同时选合同与明细行 |
| contractNo | 保留兼容 / 展示；销售保存时可回填合同 `no`；采购仅用该文本弱关联 |

采购：**不**新增采购合同外键；不要求绑定；不累计履约。

### 4.4 删除与改行约束

| 场景 | 规则 |
| --- | --- |
| 删除采购合同 | 原型**不**校验磅单 `contractNo`，确认后直接删除 |
| 删除销售合同 | 若存在 `weighTickets.saleContractId === 合同id`：**禁止删除**，提示先解除磅单关联 |
| 删除销售明细行 | 若存在磅单 `saleContractLineId` 指向该行：**禁止删行** |
| 修改行约量 / 货类 | 允许；已履约只读；保存详情时强制写回原 `fulfilledQty`，避免被表单覆盖 |
| 编辑 / 删除磅单 | **全量重算**相关销售合同各行 `fulfilledQty` |

## 5. 状态机

合同拆成两套字段：**状态**（手工）与 **自动派生字段**（只读），避免用户忘记改自动态。

### 5.1 采购合同

**状态（手工）**：`draft` 草稿 → `active` 启用 → `closed` 已关闭  

**有效性（自动，只读）**：由 `validUntil` 相对当天派生  

| 取值 | 界面文案 | 规则 |
| --- | --- | --- |
| `in_force` | 有效期内 | 已填有效期且 ≥ 当天 |
| `expired` | 已过期 | 已填有效期且 &lt; 当天 |
| `no_expiry` | 未设有效期 | 未填有效期 |

列表与筛选分别提供「状态」「有效性」；详情中「有效性」为只读徽章。

### 5.2 销售合同

**状态（手工）**：`draft` 草稿 → `active` 生效 → `completed` 已完成 \| `closed` 已关闭  

**履约情况（自动，只读）**：由关联正常磅单净重与约量/容差派生（优先级：超容差 > 已达约量 > 履约中 > 未履约）  

| 取值 | 界面文案 | 规则 |
| --- | --- | --- |
| `none` | 未履约 | 合计已履约为 0 |
| `in_progress` | 履约中 | 已有履约且未达下沿 |
| `ready` | 已达约量 | 各行均达约量下沿（含容差）且已有履约 |
| `over` | 超容差 | 任一行超过约量上沿 |

- 「已完成」仍 **仅手工**；达约量时提示可改为已完成（不自动关单）。
- 「已关闭」始终手工。
- 系统 **不再** 把状态自动改为「履约中」（该语义已迁至履约情况）。
- 过磅可选关联的销售合同：手工状态为「生效」的合同（编辑时已关联的合同可继续展示）。

- **重置按钮**：未在页面或资料中体现（切换 Tab 等价清空）

### 6.3 采购合同列表

以表格展示采购合同，按 `createdAt` 降序。

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |

| 有效期至 | `validUntil`；空为「—」；过期红字 +「· 已过期」 | 否 |
| 状态 | 状态徽章 | 否 |

| 附件 | 有 `attachmentName` 显示「是」，否则「否」 | 否 |

- **行操作**：
  - **详情**：打开编辑弹窗；整行点击同等效果

### 6.4 销售合同列表

以表格展示销售合同，按 `createdAt` 降序。

| 列表字段 | 字段说明 | 排序 |
| --- | --- | --- |
| 合同编号 | 加粗 | 否 |
| 对方 | 买方名称 | 否 |
| 货类 | 明细品名「；」拼接 | 否 |
| 约重 KG | `Σ plannedQty`，`formatKg` | 否 |
| 已履约 KG | `Σ fulfilledQty` | 否 |
| 进度 | `Σfulfilled / Σplanned`，封顶 100%，整数百分比 | 否 |
| 合同总价 | 优先 `totalAmount`，否则行金额合计；带币种格式化 | 否 |
| 履约截止 | `fulfillBy`，空「—」 | 否 |
| 状态 | 状态徽章（草稿/生效/履约中/已完成/已关闭） | 否 |
| 签订日期 | `signedOn` | 否 |
| 创建时间 / 更新时间 | 审计列 | 否 |
| 操作 | 详情、删除 | — |

> 销售列表**无**附件列（与采购列表不同）。

- **行操作**：
  - **详情**：打开编辑弹窗；整行点击同等效果

#### 6.5.2 表单字段

**分区：合同详情**

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 合同编号 | 只读文本 | 是（系统生成） | 格式 `Q-{公司缩写}-{年份}-{3位流水}`；新建预览、保存时再取号；编辑不可改 |

| 对方客户 | 可搜索下拉 | 是 | 客户主数据；找不到客户时名称回退「未命名客户」 |

| 联系人 | 文本 | 否 | |
| 项目 | 可搜索下拉 | 否 | 数据源为启用中的项目类型；可清空；若当前名称已停用/已删则补入选项以免丢值 |
| 有效期至 | 日期 | 否 | |

#### 6.5.3 采购合同编号规则

```text
Q-{tenant.abbr}-{报价日期年份}-{3位流水号}
例：Q-YK-2026-010
```

| 规则 | 说明 |
| --- | --- |
| 公司缩写 | 取基础设置 `tenant.abbr`（大写字母/数字）；未配置时禁止保存并提示前往基础设置 |
| 年份 | 取报价日期的四位年；切换报价日期年份时预览编号随之更新 |
| 流水 | 同缩写、同年份下，匹配 `Q-{abbr}-{year}-*` 的现有编号最大值 +1；从 `001` 起；不足三位左侧补零 |
| 历史编号 | 不符合该格式的旧单号（如 `PO-2026-0715`）不参与流水计算，仍可只读展示 |
| 编辑 | 编号只读，不因改报价日期而重编号 |

> 实现：`web/src/entities/contract/purchase-no.ts`（`nextPurchaseContractNo`）。

**分区：明细行**

| 列 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| 货物类型 | 可搜索下拉 | 是 | 仅 `enabled && forPurchase`；历史不在列表中的货类可补入选项 |
| 计价方式 | 下拉 | 是 | 到场价 / 派车价 / 其他 |
| 单价 | 数字 | 是 | `min=0`，`step=0.01` |
| 删除 | 图标按钮 | — | 至少保留 1 行 |

- **添加明细行**：按钮追加空行
- **保存校验**：明细为 0 行，或任一行既无 `materialTypeId` 又无货类名称 → 不提交

**分区：补充信息**

| 字段 | 控件 | 必填 |
| --- | --- | --- |
| 条款备注 | 多行文本 | 否 |

### 6.8 过磅台账中的合同关联（关联需求）

本能力在过磅台账弹窗实现，合同进度依赖该关联，故纳入合同管理验收范围。

#### 6.8.1 销售方向

| 项 | 说明 |
| --- | --- |
| 字段 | 「销售合同」+「合同明细行」 |
| 可选合同 | 状态为生效或履约中的销售合同 |
| 明细行展示 | `货类 · 约量KG` |
| 锁定 | 选中合同与明细行后，方向 / 客户 / 货类 / 单价由合同带出且不可改 |
| 单价换算 | 合同吨价 / 1000 → 磅单每 KG 单价 |
| 保存后 | 全量重算该合同各行已履约；**履约情况**自动更新；不改写手工状态 |
| 超容差 | 保存前提示「已履约超过合同约量（含容差），仍可保存。」不拦截 |
| 未关联 | 不影响任何合同进度 |

| 项 | 说明 |
| --- | --- |
| 字段 | 「关联合同」下拉（采购合同 `编号 · 客户名`） |

### 6.9 项目全景追溯（边界说明）

`ContractTracePanel` 用于项目全景 `/transactions`，可展示合同→过磅→结算→收付款链路，**详情 Tab 均为只读**（不可在本页新建/编辑/删除）。**合同管理本页不内嵌该面板**；追溯交互以项目全景文档为准。

## 7. 履约计算规则（仅销售）

1. 仅统计同时满足以下条件的磅单净重 `netKg`：
   - 磅单状态为「正常」；
   - `saleContractLineId` 等于该明细行 id；
   - 且（`saleContractId` 等于该合同 id **或** `contractNo` 等于该合同编号）。
2. 行进度 = `fulfilledQty / plannedQty`；合同列表进度 = `Σfulfilled / Σplanned`（展示封顶 100%）。
3. 容差：下沿用于「可完成」提示，上沿用于「超约量」提示；`tolerancePercent` 为空则上下沿均退化为 `plannedQty`。
4. 采购合同不参与上述计算。
5. 系统**不会**自动将销售合同手工状态改为已完成或已关闭；履约进度写入只读「履约情况」。

## 9. 状态与异常场景

| 场景 | 触发条件 | 页面表现 | 处理规则 |
| --- | --- | --- | --- |
| 列表无匹配 | 筛选无结果 | 空表 | 调整筛选条件 |

| 网络异常 | 当前为本地 Mock | 未在页面或资料中体现 | — |

## 10. 验收标准

| 验收点 | 验收标准 |
| --- | --- |
| 单入口双 Tab | 仅一菜单「合同管理」；可切换采购/销售；刷新后 Tab 记忆正确 |
| 新建不二次选类型 | 当前 Tab 直接打开对应新建弹窗 |
| 编辑标题无编号 | 采购/销售编辑弹窗标题分别为「采购合同」「销售合同」，不含编号 |
| 采购合同编号 | 新建自动生成 `Q-{公司缩写}-{年}-{3位流水}`；只读；依赖基础设置公司缩写；编辑不可改号 |
| 采购无约重履约 | 采购表单无约量/已履约控件；列表无进度列 |
| 采购多行单价 | 可维护多行货类、计价方式、单价、有效期、附件 |
| 销售多行约量 | 可按吨录入约量与每吨单价；详情只读已履约；列表展示约量/已履约/进度 |
| 附件预览 | PDF/图片可预览；无浏览器 PDF 黑底完整工具栏；具备放大、缩小、下载 |
| 销售过磅关联 | 可选合同+明细行；保存后行与合计已履约变化正确 |
| 超容差 | 仅提示可保存，不拦截 |
| 首笔关联状态 | 生效合同关联正常磅单后，**履约情况**变为履约中（不改手工状态） |
| 可完成提示 | 达下沿时提示可手工改为已完成；不自动完成 |
| 状态字段拆分 | 手工「状态」与自动「有效性/履约情况」分列；用户无需手改自动态 |
| 销售删约束 | 有关联磅单不可删合同；有引用不可删对应明细行 |
| 采购过磅 | 无强制行级绑定；可不关联或仅弱关联编号 |
| 长条款 | 仅备注或附件承载，无罚则引擎 |
| 不做项 | OCR、定金核销、导出分页、打印审批等一期不出现 |

## 13. 已确认产品决策摘要

| 决策 | 结论 |
| --- | --- |
| 入口 | 单菜单 + 采购/销售 Tab |
| 命名 | 对外「采购合同」 |
| 实现结构 | 方案 A：两套实体 |
| 采购履约 | 不算约重履约；过磅不强制绑 |
| 销售履约 | 有约量与已履约；过磅可选关联到行 |
| 明细 | 采购与销售均支持多行 |
| 履约粒度 | 销售按明细行累计；磅单变更全量重算 |
| 编辑弹窗标题 | 不展示合同编号 |
| 采购合同编号 | 自动生成 `Q-{公司缩写}-{年}-{3位流水}`；只读；缩写来自基础设置 |
| 采购项目字段 | 可选主数据下拉（项目类型）；存名称快照；删除主数据不改合同 |
| 附件预览 | 自定义渲染；工具能力限放大、缩小、下载 |
| 定金 / OCR / 罚则引擎 | 一期不做 |
| 销售表单字段范围 | 仅共性字段（编号/客户/日期/付款/截止/容差/总价/状态/履约情况 + 明细行）；异构条款看扫描件 |
