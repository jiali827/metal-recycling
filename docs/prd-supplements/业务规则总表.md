## 1. 租户与账号

| 编号 | 规则 | 验收口径 |
|------|------|----------|
| T01 | 自助注册创建公司租户，注册人为该租户系统管理员 | 注册成功后仅能看到本租户数据 |

## 2. 合同状态机

### 2.1 状态集合

`draft`（草稿）→ `active`（生效）→ `fulfilling`（履约中）→ `completed`（已完成）  
旁路：`closed`（已关闭，未履约终止）

### 2.2 转换表

| 从 | 到 | 触发 | 角色 | 前置 | 后置 |
|----|----|------|------|------|------|
| draft | active | 手动「生效」 | 合同管理员（写） | 必填齐全、有对方与单价明细 | 可被过磅选用 |
| active | fulfilling | **首笔 status=normal 磅单保存成功** | 系统自动 | — | 累计履约净重开始累计 |
| fulfilling | completed | 累计净重 ≥ 约重，或手动「完成」 | 系统自动 / 合同管理员 | — | 不可再被新磅单选用（已有单可追溯） |
| active / fulfilling | closed | 手动「关闭」 | 合同管理员 | 无 normal 磅单，或全部已作废 | 不可再过磅 |
| closed / completed | * | 默认不可回退 | — | — | 需特批流程则二期 |

### 2.3 选用规则

| 编号 | 规则 |
|------|------|
| C01 | 仅 `active` / `fulfilling` 可在过磅「关联合同」中选用 |
| C02 | 无有效合同不得保存正式磅单；散户须先建当日价/临时合同 |
| C03 | 累计净重 ≥ 约重 × 90%：警告（可继续） |
| C04 | 累计净重 > 约重：默认警告不硬拦；租户可配置硬拦截（配置项二期可做，默认 off） |
| C05 | 单价与货类明细以合同为准；过磅页不可改单价 |

## 3. 过磅台账

### 3.1 计算

| 编号 | 公式 / 规则 |
|------|-------------|
| W01 | 净重 = 总重 − 皮重 − \|扣减\|；结果 ≥ 0，否则拒绝保存 |
| W02 | 一单多货类：各行净重之和 = 本单过磅净重（容差按 R12） |
| W03 | 行金额 = 行净重 × 行单价（单价来自合同） |
| W04 | 单据金额 = 各行金额之和 |

### 3.2 单号与双轨

| 编号 | 规则 |
|------|------|
| W05 | 租户内 BX 号唯一；与纸质单对齐 |
| W06 | 一期重量手录；打印仍走旧软件；Web 存电子台账 |
| W07 | 作废单**占号保留**；重录必须用**新 BX**（与新纸质单一致） |

### 3.3 保存后变更

| 编号 | 规则 |
|------|------|
| W08 | 正式保存后禁止改关键字段：重量、货类、单价来源、客户、合同、方向、金额、BX |
| W09 | 允许改非关键字段：备注等（须审计） |
| W10 | 纠错路径：作废 → 重录新单 |

### 3.4 作废与往来

| 编号 | 规则 |
|------|------|
| W11 | 销售磅单 → 生成应收；采购 → 生成应付（保存 normal 时） |
| W12 | 作废时：对应往来若**未核销** → 往来标记 void/关闭 |
| W13 | 若存在未冲销的核销收付款 → **拒绝作废**，须先冲销 |
| W14 | Mock 阶段若仍提供「删除」：投产应改为作废；物理删除仅限无副作用草稿（一期默认无草稿磅单） |

## 4. 往来（应收 / 应付）

| 编号 | 规则 |
|------|------|
| A01 | 状态：`open` / `partial` / `settled` / `void` |
| A02 | settledAmount ≤ amount；balance = amount − settledAmount |
| A03 | settledAmount=0 → open；0&lt;settled&lt;amount → partial；settled≥amount → settled |
| A04 | void 后不再参与余额汇总与核销 |
| A05 | 往来由磅单生成；一期不鼓励无磅单手工开往来（若原型有入口，投产默认关闭或仅管理员例外） |

## 5. 收付款与核销

| 编号 | 规则 |
|------|------|
| P01 | `category=settlement`：核销往来；`receipt`→应收，`payment`→应付 |
| P02 | `category=misc`：杂项收支；一期后半段完整进现金流水（首批可录但口径以 PRD 首页为准） |
| P03 | 核销金额合计不得超过往来 amount；允许部分核销 |
| P04 | 部分核销摘要：`部分核銷 BX{no}`；足额：`核銷 BX{no}`（可用 i18n） |
| P05 | **一期允许**一笔收/付款通过 `allocations[]` 核销多笔往来 |
| P06 | 冲销：生成反向核销或作废原核销记录，使往来 settled 回退；完成前方可作废磅单 |
| P07 | 收付方式：现金/支票/转账等枚举 + 凭证号 + 备注 |

## 6. 现金与首页口径

| 编号 | 规则 |
|------|------|
| D01 | 现金结余（简化）= 期初现金 + 区间内收款 − 区间内付款（是否含 misc 见 D04） |
| D02 | 销售额 = 区间内销售方向 normal 磅单金额合计 |
| D03 | 采购额 = 区间内采购方向 normal 磅单金额合计；毛利 = 销售 − 采购（概览口径） |
| D04 | 作废磅单、void 往来不计入经营额；核销类与 misc 收付均计入已收/已付与现金结余（见 D04'） |
| D05 | 应收/应付余额 = 非 void 往来的 balance 合计 |
| D06 | 时区：业务日按租户本地（香港）日历日；「今日」= 本地 00:00–23:59 |
| D07 | 期初现金：管理员/财务可调；每次调整记审计（投产） |

## 8. 删除 vs 作废（总原则）

| 对象 | 一期推荐 | 说明 |
|------|----------|------|
| 合同草稿 | 可删 | 无磅单 |
| 已生效及之后合同 | 关闭/完成，不物理删 | 留追溯 |
| 磅单 | 作废，不物理删 | 占号 |
| 往来 | 随磅单作废或 void | 不物理删已核销 |
| 收付款核销 | 冲销，不静默删 | 审计 |
| 客户/货类/角色/员工 | 停用优先于删除 | 有引用则禁删 |

## 11. 补强裁定（子代理复查 P0 · 2026-08-06）

> 以下条款关闭「总表 / 模块 PRD / 设计规格」冲突，投产与接口须以此为准。

### 11.1 冲销粒度

| 编号 | 规则 |
|------|------|
| P08 | 一笔收付若核销了多笔往来，冲销时**只解除指定往来的分配行**，不得默认整单作废该收付款 |
| P09 | 作废磅单前：仅需冲销**本磅单对应往来**上未冲销的分配；其它往来的核销不受影响 |

### 11.2 磅单 ↔ 往来 1:1

| 编号 | 规则 |
|------|------|
| A06 | 一张 normal 磅单对应且仅对应一笔往来（销售→应收 / 采购→应付） |
| A07 | 磅单作废成功后，对应往来必须 void，禁止残留可核销 open/partial |

### 11.3 货类约束

| 编号 | 规则 |
|------|------|
| C06 | 过磅明细行货类必须 ∈ 所选合同允许明细；否则拒绝保存（错误码建议 `MATERIAL_NOT_IN_CONTRACT`） |

### 11.4 作废后履约回滚

| 编号 | 规则 |
|------|------|
| C07 | 作废 normal 磅单：合同 `fulfilledKg` 减去该单净重（≥0） |
| C08 | 若回滚后无任何 normal 磅单：`fulfilling → active` |
| C09 | 已 `completed` 的合同：默认**禁止**因作废自动重开；若业务需要「完成后再作废」，须管理员特批流程（二期可配） |

### 11.5 BX 取号（双轨裁定）

| 编号 | 规则 |
|------|------|
| W15 | **一期首批：BX 由用户按纸质单手工录入**（可预填建议流水，但允许改成纸质同号） |
| W16 | 租户内唯一；与旧软件纸质单对齐是验收硬条件 |
| W17 | 模块 PRD 若写「系统自动且不可改」视为过时，以本条为准并回写模块 PRD |

### 11.6 多笔核销范围

| 编号 | 规则 |
|------|------|
| P05' | **一期允许**一笔收/付款核销多笔往来（`allocations[]`）；P05 原文「首批仅一笔」作废 |
| P10 | 各分配金额 > 0 且合计等于收付 amount；任一往来不可超核销 |

### 11.7 现金与 misc 口径（首页）

| 编号 | 规则 |
|------|------|
| D04' | **首批首页**：已收/已付/现金结余 = 核销类收付 + misc 杂项（与当前首页 PRD 一致） |
| D08 | 「一期后半段加强杂项」指报表与分类分析，不改变 D04' 已含 misc 的结余定义 |

### 11.8 租户停用

| 编号 | 规则 |
|------|------|
| T07 | 租户 `disabled`：拒绝登录；已登录会话下次请求返回 `TENANT_DISABLED` |
| T08 | 运营端停用/启用 API 可另册；企业端规则仍须 enforce |

### 11.9 作废协作路径

| 编号 | 规则 |
|------|------|
| W18 | 过磅员作废时若 `SETTLEMENT_BLOCKED`：提示「请财务先冲销本单核销」；财务完成冲销后过磅员再作废 |
| W19 | 系统不自动替过磅员冲销（职责分离） |

### 11.10 乐观锁与软警告

| 编号 | 规则 |
|------|------|
| W20 | 磅单关键写（含作废）须带 `version`；冲突返回 `CONFLICT` |
| C10 | 履约 90%/超约重为**可继续**的软警告；接口可用 `warnings[]` 返回，不阻断保存（硬拦开启时除外） |

## 14. 零头减免（抹零）

> 详见 `需求文档/零头减免.md`。散户现金实收与账面差几角时的处理口径。

| 编号 | 规则 |
|------|------|
| WV01 | 磅单、结算单、往来金额一律按计算金额入账；禁止因抹零调整账面金额或单价 |
| WV02 | 减免仅发生在收付款核销环节，记录于收付款单（`waiverAmount` + `waiverReason`，默认原因「抹零」） |
| WV03 | 有效核销额 = 实收实付金额 + 减免金额；不得超过往来余额；不得为负 |
| WV04 | 往来结清判定：Σ(核销实收 + 核销减免) ≥ 往来金额 → settled；不产生残差 partial |
| WV05 | 现金结余、已收/已付、销售额/采购额/毛利均**不含**减免；减免为独立披露指标（收付款摘要区 StatCard） |
| WV06 | 减免金额不设上限（v1.2 取消 HK$1.00 上限）；留痕（WV07）可追溯 |
| WV07 | 减免留痕：操作人、时间、原因（审计，投产口径） |
| WV08 | 删除/编辑/冲销核销时减免随分配一并回退；往来余额按「实收+减免」口径回滚 |
| WV09 | 采购方向（供应商少收）同样适用，规则对称 |

## 15. 合同价差调整

> 详见 `需求文档/合同价差调整.md`（v3.0）。带合同磅单实际成交价与合同价不同的处理口径。与 §14 零头减免机制严格分离。v3.0 确立**合同 = 价格正源**：一次性合同模型下挂合同磅单单价只读，价格谈变先走合同改价。

| 编号 | 规则 |
|------|------|
| PD01 | 价差是商业实质变更，禁止通过减免渠道处理；经营口径（销售额/采购额/毛利）必须含价差 |
| PD02 | 合同是价格正源：挂合同磅单单价只读、来源于合同明细（R02）；已保存磅单金额与单价不因价差修改（W08），价差在合同层或结算单层修正 |
| PD03 | 价差调整行 = 货类 + 原单价快照 + 实际单价 + 涉及净重 + 自动差额（可负）+ 必填原因；同货类唯一 |
| PD04 | 结算总额 = Σ磅单金额 + Σ价差差额；确认结算后往来目标金额 = 调整后总额 |
| PD05 | 经营口径修订：销售额/采购额 = normal 磅单金额 + 已确认结算单价差（价差在确认时点归属期间）；无价差时退化为 D02/D03 |
| PD06 | 已确认结算单调价差须先取消确认（无核销）或先冲销（有核销）；不得绕过结算单锁定 |
| PD07 | 未过磅时价格谈变 → 合同改价（变更留痕：前后单价、变更人、时间、原因）；改价后新磅单按新价带出，历史磅单金额不变 |
| PD08 | 价差调整与改价均留痕审计（投产口径） |
| PD09 | 价差与零头减免可叠加：往来金额（含价差）→ 核销时仍可按 §14 抹零；两层各自留痕、互不影响 |
| PD10 | 禁止在过磅环节修改挂合同磅单的单价（v3.0 撤回 v2.0 过磅改价方案）；价格变化一律先走合同改价 |
