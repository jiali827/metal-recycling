## 0. 约定

### 0.1 通用

| 项 | 约定 |
|----|------|
| 基址 | `/api/v1`（建议） |
| 鉴权 | Bearer Token 或 HttpOnly Session；每请求隐含当前用户 |
| 租户 | 由登录态解析 `tenant_id`，**禁止**客户端传其他租户 ID 覆盖 |
| 时间 | ISO-8601；业务日按租户时区（香港） |
| 分页 | `page`（1-based）+ `pageSize`；响应 `{ items, total, page, pageSize }` |
| 错误 | `{ code, message, details? }`；`message` 可 i18n key 或已本地化 |
| 幂等 | 写操作支持头 `Idempotency-Key`（创建磅单/收付强烈建议） |
| 审计 | 写操作记录 actor、at、action、resource、before/after 摘要 |

### 0.2 资源命名（与前端域对齐）

`/auth` `/tenants` `/employees` `/roles` `/customers` `/customer-categories` `/material-types` `/project-types` `/contracts` `/weigh-tickets` `/receivables` `/payables` `/payments` `/dashboard` `/files`

## 1. 认证与租户

### 1.1 登录

| 项 | 内容 |
|----|------|
| 场景 | 员工登录 |
| 方法 | `POST /auth/login` |
| 入参 | `email`, `password` |
| 出参 | `accessToken`（或 Set-Cookie）, `user{id,name,email,roleIds,avatarUrl}`, `tenant{id,name,...}` |
| 失败码 | `AUTH_INVALID`, `AUTH_USER_DISABLED`, `AUTH_NO_ENABLED_ROLE` |
| 副作用 | 写登录审计（可选） |

### 1.2 注册开户

| 项 | 内容 |
|----|------|
| 场景 | 自助创建公司租户 |
| 方法 | `POST /auth/register` |
| 入参 | 公司名、联系人、email、password… |
| 出参 | 同登录 + 新 `tenant` |
| 副作用 | 创建 tenant、admin 员工、预置五类角色模板 |
| 失败码 | `EMAIL_TAKEN`, `VALIDATION_ERROR` |

### 1.3 当前会话

| 方法 | `GET /auth/me` |
| 出参 | user + tenant + **合并后的 access 权限图** |

## 2. 合同 ` /contracts`

### 2.1 列表

| 项 | 内容 |
|----|------|
| 方法 | `GET /contracts` |
| 查询 | `type`, `status`, `keyword`, `dateFrom`, `dateTo`, `page`, `pageSize` |
| 出参 | 合同摘要（含 `fulfilledKg`, `plannedKg`, `unitPriceSummary`） |

### 2.2 创建 / 更新草稿

| 项 | 内容 |
|----|------|
| 方法 | `POST /contracts`，`PATCH /contracts/{id}` |
| 入参 | type, customerId, date, plannedKg, 明细行（货类+单价）, 附件 fileId?, projectTypeId? |
| 约束 | 仅 draft 可随意改关键字段 |
| 失败码 | `VALIDATION_ERROR`, `CUSTOMER_NOT_FOUND` |

### 2.3 生效 / 完成 / 关闭

| 动作 | 方法建议 | 前置（规则总表） | 失败码 |
|------|----------|------------------|--------|
| 生效 | `POST /contracts/{id}/activate` | draft→active | `INVALID_STATE` |
| 完成 | `POST /contracts/{id}/complete` | fulfilling/active | `INVALID_STATE` |
| 关闭 | `POST /contracts/{id}/close` | 无 normal 磅单或全作废 | `HAS_ACTIVE_TICKETS` |

### 2.4 追溯

| 方法 | `GET /contracts/{id}/trace` |
| 出参 | 合同 + 磅单列表 + 往来 + 收付 + summary（履约%、金额、余额） |

## 3. 过磅 ` /weigh-tickets`

### 3.1 列表

| 查询 | `keyword`, `direction`, `status`, `dateFrom`, `dateTo`, `contractNo`, `page`, `pageSize` |

### 3.2 创建（关键）

| 项 | 内容 |
|----|------|
| 方法 | `POST /weigh-tickets` |
| 入参 | `bxNo`（手录纸质同号，必填）, plate, contractId, grossKg, tareKg, deductionKg, `weighedAt`（过磅时间）, lines[{materialId/name, netKg}], containerNo?, sealNo?, gateInAt?, gateOutAt?, remarks?, `version` 不适用（新建） |
| 服务端计算 | netKg, amount, direction/customer/price from contract；校验货类 ∈ 合同明细 |
| 副作用 | 生成 1 笔 AR/AP；可能 active→fulfilling；更新 fulfilledKg |
| 出参附加 | `warnings[]`（如 `FULFILLMENT_90`, `OVER_PLANNED_KG`）可继续 |
| 失败码 | `CONTRACT_NOT_SELECTABLE`, `BX_DUPLICATE`, `NET_WEIGHT_INVALID`, `LINE_WEIGHT_MISMATCH`, `PRICE_TAMPERED`, `MATERIAL_NOT_IN_CONTRACT` |
| 幂等 | 强烈建议 Idempotency-Key |

### 3.3 更新非关键字段

| 方法 | `PATCH /weigh-tickets/{id}` |
| 允许 | remarks 等白名单 |
| 失败 | 改关键字段 → `IMMUTABLE_FIELD` |

### 3.4 作废

| 项 | 内容 |
|----|------|
| 方法 | `POST /weigh-tickets/{id}/void` |
| 入参 | `version`（乐观锁，必填） |
| 副作用 | 对应往来 void；`fulfilledKg` 回滚；若无剩余 normal 单则 `fulfilling→active`；已 completed 默认拒绝 |
| 失败码 | `ALREADY_VOID`, `SETTLEMENT_BLOCKED`（须先冲销本单分配）, `CONFLICT`, `CONTRACT_COMPLETED_LOCKED` |

## 5. 收付款 ` /payments`

### 5.1 列表

| 查询 | `type`, `category`, `keyword`, `dateFrom`, `dateTo`, `page`, `pageSize` |

### 5.2 创建核销收付

| 项 | 内容 |
|----|------|
| 方法 | `POST /payments` |
| 入参 | type, category, method, amount, date, counterparty, allocations: [{ arApId or ticketBxNo, amount }], miscKind?, voucherNo?, remark? |
| 副作用 | 回写往来 settled/balance/status |
| 失败码 | `OVER_ALLOCATE`, `ARAP_VOID`, `ARAP_TYPE_MISMATCH`, `VALIDATION_ERROR` |
| 幂等 | 建议 |

### 5.3 冲销

| 项 | 内容 |
|----|------|
| 方法 | `POST /payments/{id}/reverse` |
| 入参 | `allocationIds?: string[]` 或 `arApIds?: string[]`；**省略则冲销该收付全部未冲销分配** |
| 语义 | 默认按分配行解除；不得误伤未指定的其它往来核销 |
| 副作用 | 回退对应往来 settled/balance/status |
| 失败码 | `ALREADY_REVERSED`, `NOT_SETTLEMENT`, `ALLOCATION_NOT_FOUND` |

### 5.4 收付方式

一期：**固定枚举**（现金/支票/转账等），不提供 `/payment-methods` CRUD；若日后可配再单开资源。

## 9. 错误码汇总（最小集）

| code | 含义 |
|------|------|
| VALIDATION_ERROR | 字段校验失败 |
| UNAUTHORIZED | 未登录 |
| FORBIDDEN | 无权限 |
| NOT_FOUND | 资源不存在或非本租户 |
| INVALID_STATE | 状态机不允许 |
| BX_DUPLICATE | BX 冲突 |
| CONTRACT_NOT_SELECTABLE | 合同不可过磅 |
| SETTLEMENT_BLOCKED | 有核销未冲销 |
| OVER_ALLOCATE | 超核销 |
| IMMUTABLE_FIELD | 改了禁止字段 |
| IDEMPOTENCY_CONFLICT | 幂等键重放参数不一致 |
| MATERIAL_NOT_IN_CONTRACT | 货类不在合同明细 |
| TENANT_DISABLED | 租户已停用 |
| CONFLICT | 乐观锁冲突 |
| CONTRACT_COMPLETED_LOCKED | 已完成合同不可因作废自动重开 |
| ALLOCATION_NOT_FOUND | 冲销分配不存在 |
