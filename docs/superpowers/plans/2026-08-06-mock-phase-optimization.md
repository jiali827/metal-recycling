## 0. 目标

在暂不接 API 的前提下：

1. **产品侧**把投产规则与接口意图写清楚，降低日后前端返工；
2. **前端侧**在 Mock 上补齐可安全落地的工程能力（权限过滤、规则单测、数据访问边界预留、仓库卫生）；
3. 做完后用**子代理复查**，按缺口继续补。

**明确不做（本计划）：** 真实 HTTP、Token、对象存储上传、服务端分页、运营端 `ops/` 应用。
