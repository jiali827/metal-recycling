# 结算单签字附件备份设计

| 属性 | 内容 |
| --- | --- |
| 日期 | 2026-08-07 |
| 状态 | 待确认 → **已确认并实现** |
| 关联页面 | `/settlement-docs` |
| 关联文档 | `需求文档/结算单.md` |
| 方案 | A — 复用合同附件字段模式（`attachmentName` + `attachmentDataUrl`） |

---

## 1. 目标

财务线下签字后，用户可在结算单列表上传扫描件备份；之后可下载到本地。不做在线预览。

## 2. 已确认决策

| 决策点 | 结论 |
| --- | --- |
| 入口 | 列表「附件」列 |
| 数量 | 每单最多 1 个文件；再传替换；可删除后重传 |
| 类型 | 不限文件类型 |
| 预览 | 不支持 |
| 新建/编辑弹窗、打印页 | 不加附件区 |

## 3. 数据模型

在 `WeighSettlementDoc` 增加可选字段（与合同一致）：

| 字段 | 说明 |
| --- | --- |
| `attachmentName?: string` | 原始文件名，列表展示与下载文件名 |
| `attachmentDataUrl?: string` | 演示环境：本地文件读成 Data URL 写入 Mock store |

删除附件时两字段一并清空。成单/编辑磅单逻辑不改动附件字段（更新结算单其它字段时保留既有附件，除非用户在列表操作附件）。

## 4. 列表交互

列位置：建议在「状态」与「创建时间」之间，列头「附件」。

| 列表展示 | 说明 |
| --- | --- |
| 有附件 | 显示文件名（截断），点击打开附件弹窗 |
| 无附件 + 可编辑 | 显示「上传」，点击打开附件弹窗 |
| 无附件 + 仅查看 | `—` |

**附件弹窗**（所有上传 / 下载 / 替换 / 删除均在弹窗内完成）：

| 状态 | 操作 |
| --- | --- |
| 无附件 + 可编辑 | 「上传」选文件写入 |
| 有附件 | **下载**；可编辑时另有 **替换**、**删除**（删除二次确认） |
| 仅查看 + 有附件 | 仅下载 |

- 下载：触发浏览器下载，不预览。
- 列表行点击进入预览打印时，附件列入口需 `stopPropagation`。

## 5. 校验与限制

| 项 | 规则 |
| --- | --- |
| 文件数 | 1 |
| 类型 | 不限制扩展名 / MIME |
| 大小 | 建议上限 **10MB**；超限用统一确认/提示弹窗，不写入 |
| 读文件失败 | 提示失败，不写入 |

## 6. 权限

沿用 `weighTickets` 模块：

| 权限 | 上传 / 替换 / 删除 | 下载 |
| --- | --- | --- |
| `canEdit` | 是 | 是 |
| 仅 `canView` | 否 | 是（已有附件时） |
| 无 `canView` | — | — |

## 7. 非目标

- 多附件、版本历史
- 在线预览（PDF/图片）
- 新建/编辑弹窗内上传
- 打印页嵌入附件
- 真实对象存储 / 后端 API（一期 Mock）

## 8. 验收要点

1. 列表可见「附件」列；无文件时可上传（有编辑权）。
2. 上传任意类型单文件后显示文件名，可下载到本地且文件名正确。
3. 可替换、可删除（删除需确认）；再传仍为一份。
4. 超 10MB 被拒绝并提示。
5. 点击附件区操作不触发行跳转预览。
6. 仅查看权限可见下载、不可上传。
