# 结算单新建向导设计：侧栏入口 + 弹窗成单

| 属性 | 内容 |
| --- | --- |
| 日期 | 2026-08-07 |
| 状态 | 已确认（弹窗成单） |
| 前置规格 | `docs/superpowers/specs/2026-08-07-weigh-settlement-print-design.md`（打印版式与快照模型仍有效） |
| 实现范围 | 侧栏恢复结算单；弹窗新建（合同 → 磅单）；去掉过磅台账多选生成；确认后进预览打印 |
| 关联需求 | `需求文档/结算单.md`（实现时同步） |

---

## 1. 目标

过磅/业务人员从 **结算单** 菜单新建採購單或銷售單：在弹窗内选择类型、**一个**合同及其下未结算磅单（可部分勾选、可全选），确认后生成快照并进入预览打印页，供财务线下签字。

## 2. 非目标

- 应收/应付页增强、线上审批、自动核销（与既有规格一致）
- 无合同磅单进入结算单
- 一张结算单绑定多个合同
- 过磅台账多选生成结算单（本期移除）

## 3. 已确认产品决策

| 决策点 | 结论 |
| --- | --- |
| 侧栏 | 恢复「结算单」独立菜单项 |
| 成单交互 | **弹窗表单**，确认后跳转预览打印页 |
| 合同范围 | 一张结算单 **只绑一个合同** |
| 无合同磅单 | **不可**进入结算单 |
| 磅单勾选 | 可勾部分；支持 **全选** |
| 过磅台账快捷生成 | **去掉**（含多选栏与页头「结算单」跳转可改为仅导航或删除页头按钮） |

## 4. 信息架构

| 入口 | 说明 |
| --- | --- |
| 侧栏 `/settlement-docs` | 列表、筛选、删除、打开预览；**新建**打开弹窗 |
| `/settlement-docs/[id]` | 预览打印（沿用）；返回上一页 |
| `/weigh-tickets` | **不再**提供多选生成；可保留筛选与 CRUD |

权限：继续挂在 `weighTickets` 模块（与现网一致）；`canCreate` 控制新建，`canDelete` 控制列表删除，`canView` 控制列表/预览。

## 5. 数据模型调整

在既有 `WeighSettlementDoc` 上增加合同锚点（快照，删除合同后结算单仍可读）：

| 字段 | 说明 |
| --- | --- |
| `contractId` | 采购用采购合同 id；销售用销售合同 id |
| `contractNo` | 冗余合同编号，打印与列表可用 |
| `kind` / `customerName` / `ticketIds` / `lines` / … | 保持现有语义 |

生成规则相对 `buildSettlementDocInput` 增强：

1. 所选磅单非空、全部 `normal`、全部未占用。
2. 全部同 `direction`，且与弹窗所选 `kind` 一致。
3. 全部同客户，且与所选合同对方客户一致。
4. **全部属于所选合同**：
   - 采购：`ticket.contractNo === purchaseContract.no`（且 `direction === purchase`）
   - 销售：`ticket.saleContractId === saleContract.id`（且 `direction === sale`）
5. 磅单必须有合同关联：采购 `contractNo` 有效且非 `-`/空；销售必须有 `saleContractId`。
6. 单号、行快照、合计逻辑沿用现规格。

校验失败用统一提示弹窗（非 `window.alert`）。

## 6. 弹窗交互

**打开**：列表「新建」（需 `canCreate`）。

**字段（一页分区）**

1. **结算类型**：分段控件 — 采购单 / 销售单；切换类型时清空合同与磅单选择。
2. **合同**：可搜索下拉。选项 = 该方向下，存在 ≥1 张「可结算磅单」的合同。展示：`合同编号 · 客户名`。
3. **过磅日期区间**（可选）：仅过滤磅单候选列表，不写入单据除非需要（本期不写模型）。
4. **磅单多选表**：列为 BX、过磅时间、车牌、货类、净重、金额；支持行勾选 + **全选当前筛选结果**；空态文案区分「未选合同」与「该合同暂无未结算磅单」。
5. **单据日期**：默认今天，可改；用于单号日期段与打印抬头日期。
6. **汇总只读**：已选张数、总净重、总金额。

**确认**：校验通过 → `addWeighSettlementDoc` → 关弹窗 → `router.push(/settlement-docs/{id})`。

**取消**：关弹窗不写库。

### 6.1 「可结算磅单」定义

同时满足：

- `status === normal`
- 未出现在任一现存结算单的 `ticketIds`
- 已关联合同（见 §5）
- 方向与合同类型匹配

### 6.2 「可选合同」定义

该合同下至少存在一张可结算磅单（同上）。

## 7. 过磅台账变更

- 移除多选列、批量操作条、「生成採購單/銷售單」。
- 页头保留「结算单」按钮，仅跳转 `/settlement-docs` 列表（不生成）。

## 8. 列表与打印

- 列表筛选、删除、预览行为保持；列增加「合同编号」（`contractNo`，旧数据无锚点显示 `—`）。
- 打印页版式不改（不强制在纸质版式上新增合同号栏）；返回继续 `router.back()`，无历史则回 `/settlement-docs`。

## 9. 验收标准

1. 侧栏可见「结算单」，可进列表。
2. 新建弹窗可选采购/销售 → 仅列出有可结算磅单的合同 → 勾选部分或全选磅单 → 确认后进入预览且可打印。
3. 无合同磅单不出现在候选中；换合同会换磅单集；一张单不能跨合同。
4. 已入结算单的磅单不可再选；删除结算单后可再选。
5. 过磅台账无法再多选生成结算单。
6. 混方向/空选/未选合同等错误有统一弹窗提示。

## 10. 迁移与兼容

- 既有无 `contractId`/`contractNo` 的 Mock 结算单：列表合同列显示 `—`；不影响再打印。
- 新建一律写入合同锚点。
