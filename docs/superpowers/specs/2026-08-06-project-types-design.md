# 项目类型主数据设计

| 属性 | 内容 |
| --- | --- |
| 日期 | 2026-08-06 |
| 状态 | 已确认 |
| 关联 | 采购合同「项目」字段；对齐货物类型维护模式（字段更精简） |
| 实现范围 | `web/` 主数据页、Mock store、采购合同弹窗下拉、菜单/权限/i18n、需求文档同步 |

---

## 1. 背景与目标

### 1.1 背景

采购合同表单中的「项目」当前为自由文本（如「废料回收」），无法统一口径、无法复用，也不便停用历史值。用户要求做成与「货物类型」类似的可维护主数据，并在合同中下拉选择。

### 1.2 目标

1. 新增独立主数据 **项目类型**（名称 + 启用）。
2. 采购合同「项目」改为可搜索下拉，选项来自启用中的项目类型。
3. 合同侧仍存名称文本快照；删除主数据不改写合同历史值。

### 1.3 非目标

- 项目层级树 / 多级分类
- 销售合同增加「项目」字段
- 采购合同强制必填项目
- 删除主数据时拦截或清空合同字段
- OCR、排序号、备注等扩展字段（一期不做）

## 2. 已确认产品决策

| 决策 | 结论 |
| --- | --- |
| 字段粒度 | 方案 A：名称 + 启用/停用 |
| 删除策略 | 方案 B：允许删除；合同保留当时名称快照 |
| 实现结构 | 方案 1：独立主数据页，对齐货物类型壳子、字段更少 |
| 合同存储 | 继续 `project?: string`（名称），不引入 `projectId` |
| 销售合同 | 一期不加项目字段 |

## 4. 数据模型

### 4.1 `ProjectType`

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | string | 系统 | 主键 |
| name | string | 是 | 项目类型名称（列表与下拉展示） |
| enabled | boolean | 是 | 是否启用；默认 `true` |
| createdAt / updatedAt | string | 系统 | 审计时间 |

### 4.2 采购合同

| 字段 | 变更 |
| --- | --- |
| `project?: string` | **保持**；存选中名称快照；可选空 |
| `projectId` | **不新增** |

理由：删除主数据后合同仍能展示原名称，无需外键回填；与已确认删除策略 B 一致。

---

## 5. 项目类型维护页

对齐 `material-types` 列表壳，字段更少。

### 5.1 列表

| 列 | 说明 |
| --- | --- |
| 名称 | 加粗 |
| 启用状态 | 徽章：启用 / 停用 |
| 创建时间 / 更新时间 | 公共审计列 |
| 操作 | 详情、删除 |

筛选：

| 筛选 | 说明 |
| --- | --- |
| 关键词 | 模糊匹配名称 |
| 启用状态 | 全部 / 启用 / 停用 |

排序：按 `createdAt` 降序。无分页（与现网主数据列表一致）。

### 5.2 新建 / 详情弹窗

对齐货物类型：**新建弹窗** + **详情弹窗（内编辑）**，不另做独立「仅编辑」弹窗。

| 字段 | 控件 | 必填 | 默认 |
| --- | --- | --- | --- |
| 名称 | 文本 | 是 | 空 |
| 启用 | 开关或等价控件 | 是 | 启用 |

- 标题：新建「新建项目类型」；详情「项目类型」
- 底部：取消/关闭 + 保存

### 5.3 删除

- 二次确认（文案含名称）。
- **允许删除**，不校验采购合同引用，不清空合同 `project`。

### 5.4 名称唯一性

一期**不强制**数据库级唯一（与货物类型现网一致）。因合同下拉以 `name` 为 value/label，运营应避免创建同名；若出现同名，下拉可能出现重复项，由运营规避。实现计划可不做同名拦截，除非货物类型后续统一加校验再对齐。

## 6. 采购合同「项目」交互

| 项 | 规则 |
| --- | --- |
| 控件 | `SearchableSelect`（或与客户/货类同款可搜索下拉） |
| 选项源 | `projectTypes.filter(p => p.enabled)`，value/label 均为 `name` |
| 必填 | 否；可清空 |
| 历史值兜底 | 编辑时若当前 `project` 不在启用列表（已删或已停用），将该名称补入选项，保证可显示、可原样保存 |
| 销售 | 不加字段 |

## 10. 验收要点

1. 主数据菜单可见「项目类型」，可 CRUD 名称与启用状态。
2. 停用后的类型不出现在采购合同新建/编辑的可选列表中（历史已选值除外兜底）。
3. 采购合同「项目」为可搜索下拉且选填；保存后列表/详情展示名称正确。
4. 删除项目类型后，已引用该名称的采购合同仍显示原项目文本。
5. 销售合同无项目字段；无分页/导出/层级等本期不做能力。
