# 首页总览 · 货物类型购销统计设计

| 属性 | 内容 |
| --- | --- |
| 日期 | 2026-08-06 |
| 状态 | 已确认（与趋势并排饼图） |
| 关联 | `需求文档/首页总览.md`、`web/src/app/(app)/dashboard/DashboardView.tsx` |

## 目标

在首页总览展示「按货物类型」的购销占比，支持金额（HK$）与净重（KG）切换。

## 方案

与「销售 vs 采购趋势」并排：左趋势、右货类环形饼图。（已移除过磅活跃度）

## 规格

| 项 | 约定 |
| --- | --- |
| 数据源 | 区间内 `status === "normal"` 磅单 |
| 分组键 | `materialSummary`；排除空或 `—`；复合名整串归类不拆分 |
| 扇区值 | 销售 + 采购合计（金额或净重由 Tab 决定） |
| 排序 | 按金额合计（采购+销售）降序 |
| 展示上限 | Top 8；其余合并为「其他」（实现为 Top 7 + 其他） |
| 布局 | 右栏；右上金额/净重 Tab（紧凑高度） |
| 图示 | 环形饼图 + 紧凑图例（色点 / 名称 / 占比）；中心合计；悬停看分项 |
| 时间筛选 | 跟随看板区间 |
| 空态 | 「暂无数据」 |
| 动效 | 入场缩放；切换 Tab / 区间时重播；尊重 `prefers-reduced-motion` |

## 非目标

- 不下钻到磅单列表
- 不拆分「角梯 + 往銻」类复合货类名
- 不引入第三方图表库
- 不过磅活跃度（已从看板移除）
